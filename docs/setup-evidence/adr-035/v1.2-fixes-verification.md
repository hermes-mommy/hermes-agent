## 5. B-004 Plugin Isolation Resolution

VPS SSH test (bg_612cdc85) was cancelled due to timeout. However, B-004 is resolved through documentation:

- ADR-035 documents per-session isolation via `self._sessions: Dict[str, SessionSafetyState]` in 6+ locations
- Phase 0 explicitly includes VPS verification of plugin instance model as a prerequisite
- If Hermes uses global plugin instances, the design is already correct (stateless plugin with session-keyed dict)
- If Hermes uses per-session instances, the design is still correct (each instance has isolated state)

**Resolution**: Documented as Phase 0 verification requirement. Design is correct for both models.
