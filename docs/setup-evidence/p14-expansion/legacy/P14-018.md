## Goal

Integrate a health section into Guinevere's existing morning brief embed — displaying sleep summary (duration + quality + stages), overnight heart rate, GHI score with tier, and activity progress — with a delay mechanism: if sleep data shows less than 5 hours, delay the entire morning brief by 1 hour to let Faiz wake naturally.

---

## Context

### Why This Exists

The existing Guinevere morning brief (`src/discord/morning_brief.py` or similar APScheduler job) provides a daily summary. P14-018 adds a dedicated health section to this brief, giving Faiz a holistic morning overview without needing to run `/health-status` or `/sleep-report` separately.

### Health Section Content

| Element | Source | Display |
|---|---|---|
| Sleep summary | `health.sleep_sessions` (latest) | Duration (e.g. "7h 24m"), quality emoji, stages breakdown |
| Overnight HR | `health.heart_rate` (night window) | "Resting: 62 bpm | Overnight avg: 58 bpm" |
| GHI score + tier | `health.daily_summary` | "GHI: 78/100 — Good 💚" with tier color |
| Activity progress | `health.daily_activity` (today so far) | "0 steps (just woke up!)" or step count if already active |
| Care note | Generated template | One-sentence persona-flavored observation |

### Delay Logic

```
If sleep_hours < 5.0:
    - Log warning: "Sleep deprivation detected ({hours}h). Delaying morning brief by 1 hour."
    - APScheduler: reschedule or skip current tick + fire at +1 hour
    - After delay: fire as normal with health section included
else:
    - Fire at regular time (default ~07:00 WIB)
```

The delay is NOT skipped — it's deferred. The brief always fires, just at a later time if Faiz slept poorly.

### If Device Is Stale

If no health data is available (device stale > 2 hours per P14-024 monitoring):
- **Omit the health section entirely** from the morning brief
- **Log a warning:** "Health section omitted — no recent device data"
- Do NOT show "No data" fields — absence is better than empty placeholders

### Binding Decisions

1. **Extend existing morning brief module.** Do NOT create a separate health brief. The health section is a subsection of the existing embed.
2. **Delay is defer, not cancel.** The brief always fires — just potentially later.
3. **Health section is rich embed format.** Same color coding as P14-016 (green=Good+, yellow=Fair, red=Poor/Critical).
4. **NEVER confrontational.** The care note is gentle and observational. Examples: "You slept well last night, Darling. 🌟" or "Short night — take it easy today. 💜"
5. **If device stale, omit (don't show "no data").** Silence is better than empty fields that look like errors.
6. **Overnight HR is aggregate only.** Average and resting HR — never raw HR curve or min/max spikes.
7. **Activity shows steps so far today.** If < 100 steps: "just woke up!" instead of "0 steps."

**Care Note Generator (Template-Based):**

```python
def _care_note(sleep_hours: float, ghi_tier: str, steps: int) -> str:
    """Generate one-sentence care note. Observational, NEVER confrontational.

    Examples:
      "You slept well last night, Darling. 🌟"
      "Short night — take it easy today. 💜"
      "Great sleep and your GHI looks excellent! 💚"
    """
    if ghi_tier in ("Excellent", "Good") and sleep_hours >= 7:
        return "You slept well and your health looks great, Darling. 🌟"
    elif sleep_hours < DELAY_THRESHOLD_HOURS:
        return "Short night — take it easy today, Darling. Mommy's here. 💜"
    elif ghi_tier in ("Poor", "Critical"):
        return "Your health score is a bit low today. Please rest and stay hydrated. ❤️‍🩹"
    elif steps and steps < 100:
        return "Just waking up! Let's have a good day. ☀️"
    else:
        return "Good morning, Darling. Let's have a wonderful day. 💜"
```

**Main Builder:**

```python
async def build_health_section() -> HealthSection:
    """Build the health section for the morning brief.

    Returns HealthSection with action indicating whether to fire/delay/omit.
    """
    sleep_data = await _fetch_sleep_for_brief()

    if sleep_data is None:
        # No sleep data — device likely stale. Omit health section.
        return HealthSection(
            action=BriefAction.OMIT_HEALTH,
            fields=[],
            color=WARNING,
            care_note="",
        )

    sleep_hours = float(sleep_data.get("total_hours", 0))

    # Delay check
    if sleep_hours < DELAY_THRESHOLD_HOURS:
        import logging
        logging.getLogger(__name__).warning(
            "morning_brief_delay",
            extra={"sleep_hours": sleep_hours, "delay_minutes": DELAY_MINUTES},
        )
        return HealthSection(
            action=BriefAction.DELAY,
            fields=[],
            color=ALERT,
            care_note="",
        )

    # Fetch supplementary data
    hr_data = await _fetch_overnight_hr()
    ghi_data = await _fetch_ghi_for_brief()

    # Build embed fields
    fields: list[dict[str, str]] = []

    # Sleep field
    quality_emoji = sleep_data.get("quality_emoji", "💚")
    efficiency = sleep_data.get("efficiency", 0)
    stages_str = _format_stages_summary(sleep_data)
    fields.append({
        "name": f"😴 Sleep: {sleep_hours:.1f}h {quality_emoji}",
        "value": f"Quality: {sleep_data.get('quality_score', 0)}/100 · Efficiency: {efficiency:.0f}%\n{stages_str}",
        "inline": False,
    })

    # Overnight HR field
    if hr_data:
        resting = hr_data.get("resting_hr")
        avg_hr = hr_data.get("avg_hr")
        fields.append({
            "name": "💓 Heart Rate (overnight)",
            "value": f"Resting: {resting} bpm · Avg: {avg_hr:.0f} bpm",
            "inline": True,
        })

    # GHI field
    if ghi_data:
        ghi_score = ghi_data.get("ghi_score", 0)
        ghi_tier = ghi_data.get("ghi_tier", "Unknown")
        tier_emoji = _tier_emoji(ghi_tier)
        ghi_color = _tier_color(ghi_tier)
        fields.append({
            "name": "📊 Health Index (GHI)",
            "value": f"{tier_emoji} **{ghi_score}/100** — {ghi_tier}",
            "inline": True,
        })
    else:
        ghi_color = WARNING

    # Activity field
    if ghi_data and ghi_data.get("steps") is not None:
        steps = int(ghi_data.get("steps", 0))
        steps_display = f"{steps:,} steps" if steps >= 100 else "Just waking up! ☀️"
        fields.append({
            "name": "🏃 Activity",
            "value": steps_display,
            "inline": True,
        })

    # Care note
    steps_val = int(ghi_data.get("steps", 0)) if ghi_data else 0
    ghi_tier_val = ghi_data.get("ghi_tier", "Good") if ghi_data else "Good"
    care_note = _care_note(sleep_hours, ghi_tier_val, steps_val)

    return HealthSection(
        action=BriefAction.FIRE_NORMAL,
        fields=fields,
        color=ghi_color if ghi_data else SUCCESS,
        care_note=care_note,
    )


def _format_stages_summary(sleep_data: dict[str, object]) -> str:
    """Format sleep stages as a compact summary line.

    Example: "💤 Deep 45% · 🌙 Light 30% · 🎬 REM 20% · 👁️ Awake 5%"
    If stages not available: return "Stages not captured by device"
    """
    stage_keys = ["deep_pct", "light_pct", "rem_pct", "awake_pct"]
    stage_emojis = {"deep_pct": "💤", "light_pct": "🌙", "rem_pct": "🎬", "awake_pct": "👁️"}
    stage_labels = {"deep_pct": "Deep", "light_pct": "Light", "rem_pct": "REM", "awake_pct": "Awake"}

    parts = []
    for key in stage_keys:
        pct = sleep_data.get(key)
        if pct is not None:
            parts.append(f"{stage_emojis[key]} {stage_labels[key]} {pct:.0f}%")

    return " · ".join(parts) if parts else "Stages not captured by device"


def _tier_color(tier: str) -> int:
    return {"Excellent": SUCCESS, "Good": SUCCESS,
            "Fair": WARNING, "Poor": ALERT, "Critical": ALERT}.get(tier, WARNING)

def _tier_emoji(tier: str) -> str:
    return {"Excellent": "🌟", "Good": "💚", "Fair": "💛",
            "Poor": "🧡", "Critical": "❤️‍🩹"}.get(tier, "📊")
```

### 4.3 Extend the Morning Brief Module

Modify the existing morning brief job to call `build_health_section()`:

```python
from src.discord.morning_health_section import (
    build_health_section, BriefAction, DELAY_MINUTES
)
import asyncio
import logging

logger = logging.getLogger(__name__)

async def morning_brief_job():
    """Original morning brief job — extended with P14-018 health section."""
    # ... existing setup: create embed, fetch weather/calendar/system status ...

    # Build health section
    health = await build_health_section()

    if health.action == BriefAction.DELAY:
        logger.info(f"morning_brief_delaying: sleep < 5h, delay {DELAY_MINUTES}min")
        # Re-fire this job after DELAY_MINUTES
        await asyncio.sleep(DELAY_MINUTES * 60)
        # Re-evaluate health section (sleep data may have updated)
        health = await build_health_section()
        # If still DELAY (edge case: no new data), fire anyway with OMIT_HEALTH
        if health.action == BriefAction.DELAY:
            logger.warning("morning_brief_delay_still_active: firing without health section")
            health = HealthSection(action=BriefAction.OMIT_HEALTH, fields=[], color=WARNING, care_note="")

    if health.action == BriefAction.FIRE_NORMAL:
        # Add health section header
        embed.add_field(
            name="━━━━━━━━━━━━━━━━━━━━━━",
            value=f"**❤️ Health** *(as of {_now_wib_str()})*",
            inline=False,
        )

        # Add health fields
        for field in health.fields:
            embed.add_field(
                name=field["name"],
                value=field["value"],
                inline=field.get("inline", False),
            )

        # Add care note
        if health.care_note:
            embed.add_field(
                name="💜 Mommy's Note",
                value=f"*{health.care_note}*",
                inline=False,
            )
    elif health.action == BriefAction.OMIT_HEALTH:
        logger.warning("morning_brief_no_health_data: health section omitted")

    # Send embed as usual
    await send_to_channel(morning_channel, embed=embed)
```

## Troubleshooting

| Symptom | Likely Cause | Fix |
|---|---|---|
| Morning brief fires twice (07:00 and 08:00) | Delay logic re-fires but original job also fires | Use job pause/resume in APScheduler instead of asyncio.sleep: `scheduler.pause_job('morning_brief'); await asyncio.sleep(delay); scheduler.resume_job('morning_brief')` |

| Brief always omits health section | `_fetch_sleep_for_brief()` returns None — query filter too strict | Widen the time window; check device is syncing; verify SQL WHERE clause |
| Delay triggers every day | Faiz consistently sleeps < 5h — this is concerning but correct behavior | The delay IS the feature. If chronic, escalation engine (P14-015) should fire sleep_deprivation trigger |

| Existing morning brief sections broken | Health section builder throws exception that crashes the job | Add try/except wrapper: health section failure should OMIT_HEALTH, not crash the whole brief |
| APScheduler job conflicts | Multiple morning-brief jobs registered | Consolidate: one job that calls `build_health_section()` internally |

## Notes

### Safety Boundaries

1. **NEVER confrontational.** Care notes are template-based with pre-approved phrases. All are observational ("short night") or encouraging ("great sleep"). Zero instances of "you should," "why didn't you," or any corrective language.
2. **Sleep delay is care, not punishment.** Delaying the brief when sleep < 5h is a kindness — letting Faiz wake naturally. It is NOT a penalty for poor sleep.
3. **Stale device = silence.** When health data is unavailable, the section is omitted entirely. No "No data available" placeholder that could cause concern or confusion.
4. **Overnight HR is aggregate only.** Avg + resting — never raw continuous readings, min/max spikes, or HR curves.
5. **Activity "just waking up" is neutral.** It's an observation, not an expectation.

### Delay Implementation Choice

Use APScheduler's `pause_job` / `resume_job` or `modify_job` for cleaner APScheduler integration:

```python
if health.action == BriefAction.DELAY:
    scheduler.pause_job('morning_brief')
    await asyncio.sleep(DELAY_MINUTES * 60)
    scheduler.resume_job('morning_brief')
    # Re-trigger: call morning_brief_job() directly or wait for next tick
```

Alternative (simpler): fire at 07:00 with delay check, use `asyncio.sleep(3600)`, then continue. The scheduler's misfire_grace_time should be > 3600 to tolerate the delay.
