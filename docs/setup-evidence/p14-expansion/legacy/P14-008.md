## Goal

Implement a daily batch pull from the Mi Fitness Cloud SDK as a fallback data source when Gadgetbridge misses sync windows, including OAuth2 authentication, gap detection, format transformation, and graceful degradation.

---

## Context

Gadgetbridge is the primary health data source, pushing SQLite exports to WebDAV every hour. But Gadgetbridge can miss sync windows due to:
- Phone battery optimization killing background processes
- Bluetooth disconnection between phone and watch
- Gadgetbridge crash or update breaking the export workflow
- Phone offline (no network connectivity)

When Gadgetbridge data is stale (no new data for > 2 hours), the Mi Fitness Cloud SDK fallback activates. Mi Fitness is Xiaomi's official companion app that syncs data to Xiaomi Cloud. The unofficial `mi-fitness` Python SDK can pull this cloud data via OAuth2, providing a second data path entirely independent of Gadgetbridge.

This step implements a **daily batch** (not real-time) fallback that:
1. Checks Gadgetbridge freshness via `health.sync_log.last_sync_time`
2. Detects gaps: compares `last_sync_time` with current time
3. If gap detected (stale > 2h), authenticates with Xiaomi Cloud via OAuth2
4. Pulls missing health data from Mi Fitness Cloud for the gap window
5. Transforms Mi Fitness format → same normalized JSON as Gadgetbridge parser
6. Pushes transformed data through the same `POST /surveillance/health` endpoint (P14-006)
7. Logs sync results to `health.sync_log` with `source='mifitness'`
8. If **both** Gadgetbridge and Mi Fitness fail, fires a Discord alert

The fallback runs as an APScheduler cron job (daily at 06:00 WIB) with on-demand manual trigger via `/health-sync-fallback` Discord command.

**Rate limiting:** The unofficial Mi Fitness SDK must not hammer Xiaomi's API. Daily batch only. Respect per-account rate limits (estimated ~100 requests/day for free accounts). Implement exponential backoff on 429 responses.

**Graceful degradation:** If the Mi Fitness pull fails (auth expired, API down, rate limited), the system logs the failure and continues operating with whatever Gadgetbridge data is available. Only when both sources fail does the stale data alert trigger.

P14-008: Implements the secondary data path for health metrics. When

# ---------------------------------------------------------------------------
# Mi Fitness Session Manager (OAuth2)
# ---------------------------------------------------------------------------


class MiFitnessSession:
    """Manages OAuth2 authentication with Xiaomi Cloud for Mi Fitness API access.

    Authenticates once with username/password, obtains an OAuth2 access token,
    and handles automatic token refresh. The session is stored in Redis to
    survive process restarts without re-authentication.

    Token refresh follows the standard OAuth2 refresh_token flow. If refresh
    fails (token revoked, password changed), a full re-authentication is attempted.
    """

    def __init__(
        self,
        email: str,
        password: str,
        region: str = "cn",
    ) -> None:
        self._email = email
        self._password = password
        self._region = region
        self._access_token: str | None = None
        self._refresh_token: str | None = None
        self._token_expiry: datetime | None = None
        self._http_client: httpx.AsyncClient | None = None

    async def authenticate(self) -> None:
        """Perform initial OAuth2 authentication with Xiaomi Cloud.

        Uses the unofficial mi-fitness SDK's auth flow. Stores tokens
        in memory and writes a cache entry to Redis for cross-restart
        persistence.

        Raises:
            MiFitnessAuthError: If authentication fails (bad credentials,
                region mismatch, captcha required).
        """
        try:
            # mi-fitness is an unofficial SDK without type stubs.
            # Import is guarded by ImportError fallback below.
            import importlib
            mi_fitness_auth = importlib.import_module("mi_fitness.auth")
            XiaomiAuth = mi_fitness_auth.XiaomiAuth

            auth_client = XiaomiAuth(region=self._region)
            token_data = await auth_client.login(self._email, self._password)

            self._access_token = token_data["access_token"]
            self._refresh_token = token_data.get("refresh_token")
            expires_in = token_data.get("expires_in", 3600)
            self._token_expiry = datetime.now(timezone.utc) + timedelta(seconds=expires_in)

            logger.info("mifitness_auth_success", region=self._region)
        except ImportError:
            raise MiFitnessAuthError(
                "mi-fitness SDK not installed. Run: pip install mi-fitness"
            )
        except Exception as exc:
            logger.exception("mifitness_auth_failed")
            raise MiFitnessAuthError(f"Xiaomi OAuth2 authentication failed: {exc}")

    async def ensure_authenticated(self) -> None:
        """Ensure a valid access token is available, refreshing if expired."""
        if self._access_token is None:
            await self.authenticate()
            return

        if self._token_expiry and datetime.now(timezone.utc) > self._token_expiry:
            logger.info("mifitness_token_expired_refreshing")
            await self.authenticate()

    async def get_client(self) -> httpx.AsyncClient:
        """Return an authenticated httpx client for Mi Fitness API calls."""
        await self.ensure_authenticated()
        if self._http_client is None:
            self._http_client = httpx.AsyncClient(
                base_url=MI_FITNESS_API_BASE,
                headers={
                    "Authorization": f"Bearer {self._access_token}",
                    "Accept": "application/json",
                    "User-Agent": "Guinevere-Health/1.0 (MiFitness-Fallback)",
                },
                timeout=30.0,
            )
        return self._http_client

    async def close(self) -> None:
        """Close the HTTP client session."""
        if self._http_client:
            await self._http_client.aclose()
            self._http_client = None


# ---------------------------------------------------------------------------
# Gap Detection
# ---------------------------------------------------------------------------


async def detect_gap(
    session_factory: Callable[[], Any],
) -> tuple[datetime | None, datetime | None]:
    """Detect if Gadgetbridge data is stale.

    Queries ``health.sync_log`` for the most recent Gadgetbridge sync.
    If the last sync is older than ``STALE_THRESHOLD_HOURS``, returns
    the gap window (last_sync_time, now).

    Args:
        session_factory: Callable returning an async DB session.

    Returns:
        Tuple of (gap_start, gap_end) or (None, None) if no gap detected.
    """
    from sqlalchemy import text

    session = session_factory()
    try:
        stmt = text("""
            SELECT sync_time
            FROM health.sync_log
            WHERE source = 'gadgetbridge' AND status = 'success'
            ORDER BY sync_time DESC
            LIMIT 1
        """)
        result = await session.execute(stmt)
        row = result.fetchone()
        await session.commit()

        if row is None:
            logger.warning("mifitness_gap_no_gadgetbridge_syncs_found")
            return None, None

        last_sync: datetime = row[0]
        now = datetime.now(timezone.utc)
        gap_hours = (now - last_sync).total_seconds() / 3600

        if gap_hours > STALE_THRESHOLD_HOURS:
            logger.info(
                "mifitness_gap_detected",
                last_sync=last_sync.isoformat(),
                gap_hours=round(gap_hours, 1),
            )
            return last_sync, now

        logger.debug("mifitness_no_gap", last_sync=last_sync.isoformat(), gap_hours=round(gap_hours, 1))
        return None, None
    except Exception:
        logger.exception("mifitness_gap_detection_failed")
        return None, None
    finally:
        await session.close()

# Data Pull + Transform

async def pull_health_data(
    session: MiFitnessSession,
    start: datetime,
    end: datetime,
) -> list[dict[str, Any]]:
    """Pull health data from Mi Fitness Cloud for the given time window.

    Queries Mi Fitness Cloud API for all metric types within the gap
    window. Respects rate limits with exponential backoff.

    Args:
        session: Authenticated MiFitnessSession.
        start: Start of the gap window.
        end: End of the gap window (typically now).

    Returns:
        List of normalized health event dicts (same format as P14-005 parser).

    Raises:
        MiFitnessRateLimitError: On 429 with retry-after exhausted.
        MiFitnessAuthError: On 401/403 (auth expired).
    """
    metrics = ["heart_rate", "sleep", "steps", "spo2", "stress"]
    all_events: list[dict[str, Any]] = []
    client = await session.get_client()
    api_calls = 0

    for metric in metrics:
        if api_calls >= MAX_DAILY_API_CALLS:
            logger.warning("mifitness_rate_limit_reached", calls=api_calls, max=MAX_DAILY_API_CALLS)
            break

        endpoint = f"/v1/health/{metric}"
        params = {
            "from": start.strftime("%Y-%m-%d"),
            "to": end.strftime("%Y-%m-%d"),
        }

        for attempt in range(3):
            try:
                response = await client.get(endpoint, params=params)
                api_calls += 1

                if response.status_code == 429:
                    retry_after = int(response.headers.get("Retry-After", "60"))
                    logger.warning(
                        "mifitness_rate_limited",
                        metric=metric,
                        retry_after=retry_after,
                        attempt=attempt + 1,
                    )
                    if attempt < 2:
                        await asyncio.sleep(retry_after)
                        continue
                    raise MiFitnessRateLimitError(
                        f"Rate limit exceeded for {metric} after {attempt + 1} retries"
                    )

                if response.status_code == 401:
                    raise MiFitnessAuthError("Access token expired during data pull")

                if response.status_code >= 400:
                    logger.error(
                        "mifitness_api_error",
                        metric=metric,
                        status=response.status_code,
                        body=response.text[:200],
                    )
                    break  # Skip this metric, continue with others

                raw_data = response.json()
                transformed = _transform_mifitness_to_normalized(raw_data, metric)
                all_events.extend(transformed)
                logger.info(
                    "mifitness_metric_pulled",
                    metric=metric,
                    records=len(transformed),
                    api_calls=api_calls,
                )
                break  # Success, move to next metric

            except (httpx.TimeoutException, httpx.ConnectError) as exc:
                logger.error("mifitness_network_error", metric=metric, error=str(exc), attempt=attempt + 1)
                if attempt < 2:
                    await asyncio.sleep(2 ** attempt)
                    continue
                break

    logger.info("mifitness_pull_complete", total_events=len(all_events), api_calls=api_calls)
    return all_events


def _transform_mifitness_to_normalized(
    raw_data: list[dict[str, Any]],
    metric: str,
) -> list[dict[str, Any]]:
    """Transform Mi Fitness API response to normalized health event format.

    The normalized format matches the output of the P14-005 Gadgetbridge
    SQLite parser, ensuring downstream consumers see a consistent shape
    regardless of data source.

    Args:
        raw_data: Raw response from Mi Fitness Cloud API for a metric.
        metric: Metric type string (heart_rate, sleep, steps, spo2, stress).

    Returns:
        List of normalized event dicts with event_type="health" and a
        structured payload.
    """
    events: list[dict[str, Any]] = []

    for record in raw_data:
        base_event: dict[str, Any] = {
            "event_type": "health",
            "source": "mifitness",
        }

        if metric == "heart_rate":
            events.append({
                **base_event,
                "occurred_at": record.get("timestamp"),
                "payload": {
                    "metric": "heart_rate",
                    "occurred_at": record.get("timestamp"),
                    "value": record.get("bpm", record.get("heart_rate")),
                    "unit": "bpm",
                },
            })
        elif metric == "sleep":
            events.append({
                **base_event,
                "occurred_at": record.get("end_time", record.get("timestamp")),
                "payload": {
                    "metric": "sleep_session",
                    "occurred_at": record.get("end_time"),
                    "start_time": record.get("start_time"),
                    "end_time": record.get("end_time"),
                    "total_s": record.get("total_minutes", 0) * 60,
                    "deep_s": record.get("deep_minutes", 0) * 60,
                    "light_s": record.get("light_minutes", 0) * 60,
                    "rem_s": record.get("rem_minutes", 0) * 60,
                    "awake_s": record.get("awake_minutes", 0) * 60,
                    "efficiency_pct": record.get("efficiency"),
                },
            })
            # Also emit sleep stages if available
            for stage in record.get("stages", []):
                events.append({
                    **base_event,
                    "occurred_at": stage.get("timestamp"),
                    "payload": {
                        "metric": "sleep_stage",
                        "occurred_at": stage.get("timestamp"),
                        "stage": stage.get("stage", "unknown"),
                        "duration_s": stage.get("duration_seconds", 0),
                    },
                })
        elif metric == "steps":
            events.append({
                **base_event,
                "occurred_at": record.get("date"),
                "payload": {
                    "metric": "daily_activity",
                    "occurred_at": record.get("date"),
                    "steps": record.get("steps", 0),
                    "active_min": record.get("active_minutes", 0),
                    "calories": record.get("calories", 0),
                    "distance_m": record.get("distance_meters", 0),
                },
            })
        elif metric == "spo2":
            events.append({
                **base_event,
                "occurred_at": record.get("timestamp"),
                "payload": {
                    "metric": "spo2",
                    "occurred_at": record.get("timestamp"),
                    "value": record.get("spo2", record.get("value")),
                    "unit": "percent",
                },
            })
        elif metric == "stress":
            events.append({
                **base_event,
                "occurred_at": record.get("timestamp"),
                "payload": {
                    "metric": "stress",
                    "occurred_at": record.get("timestamp"),
                    "value": record.get("stress_score", record.get("value")),
                    "unit": "score",
                },
            })

    return events


# ---------------------------------------------------------------------------
# Fallback Orchestrator
# ---------------------------------------------------------------------------


async def run_mifitness_fallback(
    session_factory: Callable[[], Any],
    health_writer: HealthIngestionWriter,
    device_id: str,
    xiaomi_email: str,
    xiaomi_password: str,
    region: str = "cn",
) -> FallbackResult:
    """Orchestrate the full Mi Fitness fallback: detect gap → pull → transform → ingest.

    Args:
        session_factory: DB session factory for gap detection and sync logging.
        health_writer: HealthIngestionWriter for writing to health.* hypertables.
        device_id: Wearable device identifier string.
        xiaomi_email: Xiaomi account email for OAuth2.
        xiaomi_password: Xiaomi account password for OAuth2.
        region: Xiaomi account region ("cn" default).

    Returns:
        FallbackResult with full execution details.
    """
    # Step 1: Detect gap
    gap_start, gap_end = await detect_gap(session_factory)

    if gap_start is None or gap_end is None:
        logger.info("mifitness_fallback_no_gap_detected")
        return FallbackResult(
            triggered=False,
            records_pulled=0,
            records_ingested=0,
            gap_start=None,
            gap_end=None,
            error=None,
        )

    # Step 2: Authenticate with Mi Fitness Cloud
    mi_session = MiFitnessSession(email=xiaomi_email, password=xiaomi_password, region=region)

    try:
        await mi_session.authenticate()
    except MiFitnessAuthError as exc:
        logger.exception("mifitness_fallback_auth_failed")
        return FallbackResult(
            triggered=True,
            records_pulled=0,
            records_ingested=0,
            gap_start=gap_start,
            gap_end=gap_end,
            error=f"Authentication failed: {exc}",
        )

    # Step 3: Pull data from Mi Fitness Cloud
    try:
        events = await pull_health_data(mi_session, gap_start, gap_end)
    except (MiFitnessRateLimitError, MiFitnessAuthError) as exc:
        await mi_session.close()
        logger.exception("mifitness_fallback_pull_failed")
        return FallbackResult(
            triggered=True,
            records_pulled=0,
            records_ingested=0,
            gap_start=gap_start,
            gap_end=gap_end,
            error=str(exc),
        )
    finally:
        await mi_session.close()

    # Step 4: Ingest transformed data via health writer
    ingested = 0
    for event in events:
        payload_dict = event.get("payload", {})
        try:
            payload = HealthMetricPayload(**payload_dict)
            success = await health_writer.write_metric(
                payload=payload,
                device_id=device_id,
                source="mifitness",
            )
            if success:
                ingested += 1
        except Exception as exc:
            logger.warning(
                "mifitness_ingest_failed",
                metric=payload_dict.get("metric"),
                error=str(exc),
            )

    # Step 5: Log sync result
    await _log_fallback_sync(session_factory, device_id, len(events), ingested)

    logger.info(
        "mifitness_fallback_complete",
        records_pulled=len(events),
        records_ingested=ingested,
        gap_hours=round((gap_end - gap_start).total_seconds() / 3600, 1),
    )

    return FallbackResult(
        triggered=True,
        records_pulled=len(events),
        records_ingested=ingested,
        gap_start=gap_start,
        gap_end=gap_end,
        error=None,
    )


async def _log_fallback_sync(
    session_factory: Callable[[], Any],
    device_id: str,
    records_pulled: int,
    records_ingested: int,
) -> None:
    """Write a sync log entry for the Mi Fitness fallback run."""
    from sqlalchemy import text

    status = "success" if records_ingested > 0 else "failed"
    error_msg = None
    if records_ingested == 0 and records_pulled > 0:
        error_msg = f"All {records_pulled} records failed ingestion"
    elif records_pulled == 0:
        error_msg = "No records pulled from Mi Fitness Cloud"
    elif records_ingested < records_pulled:
        error_msg = f"Partial ingestion: {records_ingested}/{records_pulled} records"

    session = session_factory()
    try:
        stmt = text("""
            INSERT INTO health.sync_log (device_id, records, status, error_msg, source)
            VALUES (:device_id, :records, :status, :error_msg, :source)
        """)
        await session.execute(stmt, {
            "device_id": device_id,
            "records": records_ingested,
            "status": status,
            "error_msg": error_msg,
            "source": "mifitness",
        })
        await session.commit()
    except Exception:
        await session.rollback()
        logger.exception("mifitness_sync_log_failed")
    finally:
        await session.close()

def register_mifitness_job(
    scheduler: AsyncIOScheduler,
    session_factory: Callable[[], Any],
    health_writer: HealthIngestionWriter,
    device_id: str,
    xiaomi_email: str,
    xiaomi_password: str,
    region: str = "cn",
) -> None:
    """Register the daily Mi Fitness fallback as an APScheduler cron job.

    Runs daily at 06:00 WIB (23:00 UTC) — after the daily health summary
    at 03:00 WIB and baseline computation at 04:00 WIB. This ensures
    the fallback fills gaps before the next day's processing cycle.

    Args:
        scheduler: APScheduler AsyncIOScheduler instance.
        session_factory, health_writer, device_id, xiaomi_email,
        xiaomi_password, region: See run_mifitness_fallback().
    """
    scheduler.add_job(
        run_mifitness_fallback,
        trigger="cron",
        hour=23,  # 23:00 UTC = 06:00 WIB
        minute=0,
        id="p14_mifitness_fallback",
        name="Mi Fitness Cloud SDK Fallback",
        kwargs={
            "session_factory": session_factory,
            "health_writer": health_writer,
            "device_id": device_id,
            "xiaomi_email": xiaomi_email,
            "xiaomi_password": xiaomi_password,
            "region": region,
        },
        misfire_grace_time=3600,
        coalesce=True,
    )
    logger.info("mifitness_scheduler_registered", schedule="daily 06:00 WIB")

## Troubleshooting

- **Issue:** `ImportError: No module named 'mi_fitness'`
  - **Solution:** Install the unofficial SDK: `pip install mi-fitness` in the guinevere venv. If unavailable, check PyPI for alternatives or implement direct API calls via `httpx`.
- **Issue:** OAuth2 returns "captcha required" from Xiaomi
  - **Solution:** Xiaomi occasionally requires captcha verification for new IP addresses. Use a Xiaomi account with trusted device history, or implement a manual auth flow where Faiz completes the captcha once.
- **Issue:** `httpx.ConnectError` when reaching Mi Fitness API
  - **Solution:** Verify VPS can reach Xiaomi Cloud (especially `api-mifit-cn.huami.com` from China region). Check UFW rules: `sudo ufw status`. The API is external, so outbound traffic must be allowed.
- **Issue:** Transformed data is rejected by `POST /surveillance/health` with 422
  - **Solution:** The normalized payload shape must match `HealthMetricPayload`. Check field names and types in `_transform_mifitness_to_normalized()`. Compare against the P14-005 Gadgetbridge parser output format.
- **Issue:** Both Gadgetbridge AND Mi Fitness fail — stale alert not firing
  - **Solution:** The dual-failure alert is implemented in P14-024 (stale data alerts). Verify P14-024 is complete. The fallback result with `triggered=True` and `records_ingested=0` should trigger the alert pipeline.

## Notes

- The `mi-fitness` SDK is an **unofficial** Python package. It may break with Xiaomi API changes. The fallback architecture isolates SDK-specific code in `MiFitnessSession` so a replacement SDK can be swapped without changing the gap detection, transform, or ingestion logic.
- **Daily batch only** — this is intentional. Mi Fitness Cloud is NOT a real-time data source. The 1-hour Gadgetbridge push remains the primary path. Mi Fitness fills multi-hour gaps, not minute-level latency.
- **Region matters:** Xiaomi accounts are region-locked. The default `region='cn'` targets China servers. If Faiz's account is in a different region (e.g., India, Global), update `MI_FITNESS_API_BASE` and the region parameter accordingly.
- **Graceful degradation:** If the Mi Fitness pull fails for any reason, the system continues operating with whatever Gadgetbridge data exists. Only when BOTH sources have failed for > 2 hours does P14-024 fire a Discord alert.
- The APScheduler job ID `p14_mifitness_fallback` is namespaced to avoid collision with other P14 scheduler jobs (P14-009 baseline, P14-012 daily summary).
- Cross-reference: P14-005 (Gadgetbridge parser for target JSON format), P14-006 (health ingestion endpoint), P14-024 (stale data alerts).
