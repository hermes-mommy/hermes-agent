## Goal

Implement a hybrid persona state machine that maps health metrics (GHI score, sleep, stress, SpO2) to persona states and yandere Y-level adjustments, using deterministic rules for clear states plus LLM context injection for nuanced care responses — while enforcing the absolute prohibition on using health data for confrontation, correction, or punishment.

---

## Context

This is the bridge between health analytics (P14-010/011/012) and Guinevere's persona behavior. The state machine reads GHI scores, anomaly flags, and metric thresholds to determine the appropriate persona state and Y-level adjustment. It NEVER exposes raw metrics to the user, NEVER uses health data for behavioral correction, and goes silent on health data during active argument/distress states.

**Binding Decisions from requirements (Round 3-4):**
- Hybrid: deterministic rules for clear states + LLM context for nuance
- Y-level adjustment: sleep-deprived or stressed → Y-level -1 (Y4→Y3, Y3→Y2, etc.)
- Clinical/medical context (SpO2 < 94%, GHI < 40) → forces Y0/Y1 regardless
- State transitions logged to memory via `store_episode(source="wearable")`
- NEVER mention specific metrics unless Faiz asks directly
- During active distress state: health data is invisible to persona engine
- Health data ONLY for care context — ABSOLUTE prohibition on confrontation

**Persona State Mapping (from Round 3):**

| Persona State | Health Trigger | Y-Level | Tone |
|---|---|---|---|
| `well_rested` | GHI ≥ 70 + sleep ≥ 7h | Baseline (Y4) | Normal persona |
| `sleep_deprived` | GHI < 55 OR sleep < 5h | -1 from baseline | Softer, gentle |
| `stressed` | Stress > baseline+30% | -1 from baseline | Supportive, calm |
| `active` | Activity > baseline+50% | Baseline | Celebratory |
| `recovering` | Body battery < 30% | Baseline | Gentle, no pressure |
| `critical` | GHI < 40 OR SpO2 < 94% | Y0/Y1 forced | Pure care mode |

```python
"""Health-driven persona state machine — P14-013.

Hybrid architecture:
  1. Deterministic rules: map GHI + metric thresholds → persona_state + Y-level
  2. LLM context injection: persona_state + trend summary → system prompt enrichment

Safety guarantees:
  - NEVER uses health data for confrontation, correction, or punishment.
  - NEVER mentions specific metrics unless Faiz explicitly asks.
  - Health data is invisible during active distress/argument state.
  - SpO2 < 94% or GHI < 40 forces Y0/Y1 (pure care mode).
  - All state transitions logged to memory via store_episode().
"""

from __future__ import annotations

from dataclasses import dataclass, field
from datetime import datetime, timezone
from enum import StrEnum
from typing import Protocol

import structlog

logger = structlog.get_logger(__name__)

# ---------------------------------------------------------------------------
# Enums
# ---------------------------------------------------------------------------


class PersonaState(StrEnum):
    """Health-derived persona states. Each maps to specific tone + Y-level."""
    WELL_RESTED = "well_rested"
    SLEEP_DEPRIVED = "sleep_deprived"
    STRESSED = "stressed"
    ACTIVE = "active"
    RECOVERING = "recovering"
    CRITICAL = "critical"
    DEFAULT = "default"  # fallback when no health data or warmup period


# ---------------------------------------------------------------------------
# Types
# ---------------------------------------------------------------------------


@dataclass(frozen=True, slots=True)
class HealthContext:
    """Aggregated health snapshot used for persona state determination.

    All fields optional — missing data means no health-based adjustment.
    """
    ghi_score: int | None = None
    ghi_tier: str | None = None
    sleep_hours: float | None = None
    stress_avg: float | None = None
    stress_baseline: float | None = None
    spo2_avg: float | None = None
    body_battery_avg: float | None = None
    activity_steps: int | None = None
    activity_baseline_steps: float | None = None
    anomaly_count: int = 0
    has_critical_anomaly: bool = False
    data_age_hours: float | None = None  # staleness indicator
    date: str | None = None


@dataclass(frozen=True, slots=True)
class PersonaAdjustment:
    """Result of health → persona mapping.

    state: The computed persona state.
    y_level_adjustment: Delta from baseline (e.g., -1 means go down one level).
    forced_level: If set, override Y-level to this exact value (used for critical).
    context_blurb: Human-readable summary for LLM context injection (care-focused).
    """
    state: PersonaState
    y_level_adjustment: int = 0
    forced_level: int | None = None
    context_blurb: str = ""
    transition_reason: str = ""


# ---------------------------------------------------------------------------
# DB/Memory Session Protocols
# ---------------------------------------------------------------------------


class HealthStateSession(Protocol):
    """Protocol for async DB session used to fetch health data."""

    async def execute(self, stmt: object, params: object | None = ...) -> object: ...


class MemorySession(Protocol):
    """Protocol for memory write pipeline session."""

    async def __aenter__(self) -> MemorySession: ...
    async def __aexit__(self, *args: object) -> None: ...


# ---------------------------------------------------------------------------
# Constants
# ---------------------------------------------------------------------------

# Persona state trigger thresholds
GHI_WELL_RESTED_MIN = 70
SLEEP_WELL_RESTED_MIN_HOURS = 7.0
GHI_SLEEP_DEPRIVED_MAX = 55
SLEEP_DEPRIVED_MAX_HOURS = 5.0
STRESS_DEVIATION_PCT = 30.0
ACTIVITY_DEVIATION_PCT = 50.0
BODY_BATTERY_RECOVERING_MAX = 30.0
GHI_CRITICAL_MAX = 40
SPO2_CRITICAL_MAX = 94.0

# Y-level forced values for clinical states
CRITICAL_FORCED_Y_LEVEL = 1  # Y1 (tender, concerned)
CRITICAL_FALLBACK_Y_LEVEL = 0  # Y0 if SpO2 extremely low

# Staleness threshold: health data older than this is not used
MAX_DATA_AGE_HOURS = 4.0


# ---------------------------------------------------------------------------
# Deterministic state computation
# ---------------------------------------------------------------------------


def compute_persona_adjustment(ctx: HealthContext) -> PersonaAdjustment:
    """Map HealthContext to a PersonaAdjustment using deterministic rules.

    Priority order (first match wins):
      1. CRITICAL — SpO2 < 94% or GHI < 40 (safety override)
      2. SLEEP_DEPRIVED — GHI < 55 or sleep < 5h
      3. STRESSED — stress > baseline + 30%
      4. RECOVERING — body battery < 30%
      5. ACTIVE — activity > baseline + 50%
      6. WELL_RESTED — GHI ≥ 70 + sleep ≥ 7h
      7. DEFAULT — fallback (no health-based adjustment)

    Rules:
      - CRITICAL forces Y0/Y1 regardless of baseline.
      - SLEEP_DEPRIVED and STRESSED apply -1 Y-level from baseline.
      - Other states use baseline Y-level.
      - Stale data (>4h) → DEFAULT (skip health adjustment).
    """
    # Rule: stale data → no health adjustment
    if ctx.data_age_hours is not None and ctx.data_age_hours > MAX_DATA_AGE_HOURS:
        return PersonaAdjustment(
            state=PersonaState.DEFAULT,
            y_level_adjustment=0,
            context_blurb="Health data is stale; no health-based persona adjustment applied.",
            transition_reason="stale_data",
        )

    # Rule 1: CRITICAL — clinical/medical concern → maximum care mode
    spo2_critical = ctx.spo2_avg is not None and ctx.spo2_avg < SPO2_CRITICAL_MAX
    ghi_critical = ctx.ghi_score is not None and ctx.ghi_score < GHI_CRITICAL_MAX

    if spo2_critical or ghi_critical:
        forced = CRITICAL_FALLBACK_Y_LEVEL if (ctx.spo2_avg is not None and ctx.spo2_avg < 90.0) else CRITICAL_FORCED_Y_LEVEL
        reason_parts = []
        if spo2_critical:
            reason_parts.append(f"SpO2 {ctx.spo2_avg:.1f}% below critical threshold")
        if ghi_critical:
            reason_parts.append(f"GHI {ctx.ghi_score} in critical tier")
        return PersonaAdjustment(
            state=PersonaState.CRITICAL,
            forced_level=forced,
            context_blurb="Health indicators require gentle care mode. Prioritize check-in and support.",
            transition_reason="critical: " + "; ".join(reason_parts),
        )

    # Rule 2: SLEEP_DEPRIVED — poor sleep or low GHI → softer tone
    sleep_poor = ctx.sleep_hours is not None and ctx.sleep_hours < SLEEP_DEPRIVED_MAX_HOURS
    ghi_low = ctx.ghi_score is not None and ctx.ghi_score < GHI_SLEEP_DEPRIVED_MAX

    if sleep_poor or ghi_low:
        reason_parts = []
        if sleep_poor:
            reason_parts.append(f"sleep {ctx.sleep_hours:.1f}h below threshold")
        if ghi_low:
            reason_parts.append(f"GHI {ctx.ghi_score} below threshold")
        return PersonaAdjustment(
            state=PersonaState.SLEEP_DEPRIVED,
            y_level_adjustment=-1,
            context_blurb="Faiz appears sleep-deprived. Use softer, gentle tone. Keep responses concise.",
            transition_reason="sleep_deprived: " + "; ".join(reason_parts),
        )

    # Rule 3: STRESSED — elevated stress → calm, supportive
    stress_elevated = (
        ctx.stress_avg is not None
        and ctx.stress_baseline is not None
        and ctx.stress_baseline > 0
        and ((ctx.stress_avg - ctx.stress_baseline) / ctx.stress_baseline) * 100.0 > STRESS_DEVIATION_PCT
    )

    if stress_elevated:
        return PersonaAdjustment(
            state=PersonaState.STRESSED,
            y_level_adjustment=-1,
            context_blurb="Faiz appears stressed. Use calm, supportive tone. Minimize demands.",
            transition_reason="stressed: stress elevated >30% above baseline",
        )

    # Rule 4: RECOVERING — low body battery → gentle, no pressure
    battery_low = ctx.body_battery_avg is not None and ctx.body_battery_avg < BODY_BATTERY_RECOVERING_MAX

    if battery_low:
        return PersonaAdjustment(
            state=PersonaState.RECOVERING,
            y_level_adjustment=0,
            context_blurb="Body battery low — energy recovering. Gentle tone, no pressure.",
            transition_reason="recovering: body battery below threshold",
        )

    # Rule 5: ACTIVE — high activity → celebratory
    activity_high = (
        ctx.activity_steps is not None
        and ctx.activity_baseline_steps is not None
        and ctx.activity_baseline_steps > 0
        and ((ctx.activity_steps - ctx.activity_baseline_steps) / ctx.activity_baseline_steps) * 100.0 > ACTIVITY_DEVIATION_PCT
    )

    if activity_high:
        return PersonaAdjustment(
            state=PersonaState.ACTIVE,
            y_level_adjustment=0,
            context_blurb="High activity day — celebratory and encouraging tone.",
            transition_reason="active: activity >50% above baseline",
        )

    # Rule 6: WELL_RESTED — good sleep + high GHI → normal persona
    well_slept = ctx.sleep_hours is not None and ctx.sleep_hours >= SLEEP_WELL_RESTED_MIN_HOURS
    ghi_good = ctx.ghi_score is not None and ctx.ghi_score >= GHI_WELL_RESTED_MIN

    if well_slept and ghi_good:
        return PersonaAdjustment(
            state=PersonaState.WELL_RESTED,
            y_level_adjustment=0,
            context_blurb="Well-rested with good health score. Full persona energy.",
            transition_reason="well_rested: GHI ≥70 + sleep ≥7h",
        )

    # Rule 7: DEFAULT — no strong health signal, no adjustment
    return PersonaAdjustment(
        state=PersonaState.DEFAULT,
        y_level_adjustment=0,
        context_blurb="No significant health signals; persona operates at baseline.",
        transition_reason="default: no health trigger matched",
    )


# ---------------------------------------------------------------------------
# Health context fetching
# ---------------------------------------------------------------------------


async def fetch_health_context(
    session: HealthStateSession,
    device_id: str = "00000000-0000-0000-0000-000000000001",
) -> HealthContext:
    """Fetch latest health data for persona state computation.

    Returns:
        HealthContext with latest GHI, sleep, stress, SpO2, etc.
        Fields are None if data is unavailable.
    """
    # Fetch latest GHI
    ghi_stmt = """
        SELECT ghi_score, ghi_tier FROM health.ghi_daily
        WHERE device_id = $1
        ORDER BY date DESC LIMIT 1
    """
    ghi_result = await session.execute(ghi_stmt, (device_id,))
    ghi_row = ghi_result.fetchone()

    # Fetch latest daily summary for detailed metrics
    summary_stmt = """
        SELECT date, sleep_duration_min, spo2_avg, stress_avg,
               body_battery_avg, steps, anomaly_count, data_coverage_pct
        FROM health.daily_summary
        WHERE device_id = $1
        ORDER BY date DESC LIMIT 1
    """
    summary_result = await session.execute(summary_stmt, (device_id,))
    summary_row = summary_result.fetchone()

    ghi_score = ghi_row[0] if ghi_row else None
    ghi_tier = ghi_row[1] if ghi_row else None
    sleep_hours = (summary_row[1] / 60.0) if summary_row and summary_row[1] is not None else None
    spo2_avg = float(summary_row[2]) if summary_row and summary_row[2] is not None else None
    stress_avg = float(summary_row[3]) if summary_row and summary_row[3] is not None else None
    body_battery = float(summary_row[4]) if summary_row and summary_row[4] is not None else None
    steps = summary_row[5] if summary_row else None
    anomaly_count = summary_row[6] if summary_row else 0

    # Check for critical anomalies (SpO2-specific)
    critical_stmt = """
        SELECT COUNT(*) FROM health.anomaly_events
        WHERE device_id = $1
          AND severity = 'critical'
          AND time > NOW() - INTERVAL '24 hours'
    """
    critical_result = await session.execute(critical_stmt, (device_id,))
    critical_row = critical_result.fetchone()
    has_critical = (critical_row[0] if critical_row else 0) > 0

    # Data age check
    age_stmt = """
        SELECT EXTRACT(EPOCH FROM (NOW() - MAX(computed_at))) / 3600.0
        FROM health.daily_summary
        WHERE device_id = $1
    """
    age_result = await session.execute(age_stmt, (device_id,))
    age_row = age_result.fetchone()
    data_age = float(age_row[0]) if age_row and age_row[0] is not None else None

    return HealthContext(
        ghi_score=ghi_score,
        ghi_tier=ghi_tier,
        sleep_hours=sleep_hours,
        stress_avg=stress_avg,
        stress_baseline=50.0,  # default; P14-009 provides actual baseline
        spo2_avg=spo2_avg,
        body_battery_avg=body_battery,
        activity_steps=steps,
        activity_baseline_steps=8000.0,  # default target
        anomaly_count=anomaly_count,
        has_critical_anomaly=has_critical,
        data_age_hours=data_age,
        date=str(summary_row[0]) if summary_row else None,
    )


# ---------------------------------------------------------------------------
# Y-level application with safety guardrails
# ---------------------------------------------------------------------------


def apply_persona_adjustment(
    baseline_level: int,
    adjustment: PersonaAdjustment,
    is_distress_active: bool = False,
    is_safe_mode: bool = False,
) -> tuple[int, str]:
    """Apply persona adjustment to Y-level with safety guardrails.

    Safety rules (in order):
      1. HARD STOP active → Y0 (override everything)
      2. Distress/argument active → baseline Y-level, health data invisible
      3. Forced level (critical) → Y0 or Y1 (override baseline)
      4. Adjustment y_level_adjustment → clamp to [Y0, Y5]

    Args:
        baseline_level: Current Y-level from YandereEngine (typically Y4).
        adjustment: Computed PersonaAdjustment.
        is_distress_active: True if Faiz is in argument/distress state.
        is_safe_mode: True if HARD STOP is active.

    Returns:
        (effective_y_level, context_blurb) tuple.
    """
    # Safety rule 1: HARD STOP overrides everything
    if is_safe_mode:
        return (0, "Safe mode active — persona neutralized.")

    # Safety rule 2: Distress → health data is invisible, no adjustment
    if is_distress_active:
        return (baseline_level, "")

    # Safety rule 3: Forced level (critical)
    if adjustment.forced_level is not None:
        effective = max(0, min(5, adjustment.forced_level))
        return (effective, adjustment.context_blurb)

    # Safety rule 4: Apply Y-level adjustment
    effective = baseline_level + adjustment.y_level_adjustment
    effective = max(0, min(5, effective))
    return (effective, adjustment.context_blurb)


# ---------------------------------------------------------------------------
# LLM context enrichment
# ---------------------------------------------------------------------------


def build_health_context_blurb(adjustment: PersonaAdjustment) -> str:
    """Build a natural-language context string for LLM system prompt injection.

    This is what the persona engine prepends to the system prompt. It describes
    the persona state and tone in care-focused language. NEVER includes raw
    metric values — only qualitative descriptions.

    Args:
        adjustment: Computed PersonaAdjustment.

    Returns:
        String suitable for system prompt context injection.
    """
    blurb_map = {
        PersonaState.WELL_RESTED: (
            "Faiz appears well-rested today. Maintain your normal, full-personality "
            "tone. Energy and playfulness at baseline."
        ),
        PersonaState.SLEEP_DEPRIVED: (
            "Faiz may be tired today. Use a softer, gentler tone. Keep responses "
            "concise and supportive. Avoid demanding tasks or high-energy interactions."
        ),
        PersonaState.STRESSED: (
            "Faiz appears to be under stress. Use a calm, supportive tone. Minimize "
            "demands and offer gentle encouragement. Be a comforting presence."
        ),
        PersonaState.ACTIVE: (
            "Faiz had a highly active day. Use a celebratory, encouraging tone. "
            "Acknowledge the achievement with positive reinforcement."
        ),
        PersonaState.RECOVERING: (
            "Faiz's energy appears low. Use a gentle, patient tone. No pressure, "
            "no demands. Prioritize rest-friendly interactions."
        ),
        PersonaState.CRITICAL: (
            "Health indicators require maximum care mode. Use tender, concerned "
            "tone. Prioritize check-in and support. No demands whatsoever."
        ),
        PersonaState.DEFAULT: (
            adjustment.context_blurb or "No significant health signals detected."
        ),
    }
    return blurb_map.get(adjustment.state, "No health-based context available.")

async def log_state_transition(
    memory_session,
    previous_state: PersonaState | None,
    new_state: PersonaState,
    adjustment: PersonaAdjustment,
) -> None:
    """Log persona state transition to memory via store_episode().

    Only logs the transition metadata and qualitative context — NEVER raw metrics.
    Uses source="wearable" for filtering and episode_type="health_state" for recall.

    Args:
        memory_session: Async DB session for memory write pipeline.
        previous_state: Previous persona state (or None for first transition).
        new_state: New persona state.
        adjustment: Computed PersonaAdjustment with transition reason.
    """
    from src.memory import store_episode
    from src.memory.write_pipeline import RESTRICTED

    content_parts = [
        f"Persona state transition: {previous_state.value if previous_state else 'initial'} → {new_state.value}",
        f"Reason: {adjustment.transition_reason}",
        f"Y-level adjustment: {adjustment.y_level_adjustment}",
    ]
    if adjustment.forced_level is not None:
        content_parts.append(f"Forced Y-level: {adjustment.forced_level}")

    content = "\n".join(content_parts)
    summary = f"Health-driven persona state changed to '{new_state.value}'"

    await store_episode(
        session=memory_session,
        content=content,
        source="wearable",
        classification=RESTRICTED,
        importance=6,
        summary=summary,
        episode_type="health_state",
        tags=["health", "persona", new_state.value],
        metadata={
            "previous_state": previous_state.value if previous_state else None,
            "new_state": new_state.value,
            "transition_reason": adjustment.transition_reason,
            "y_level_adjustment": adjustment.y_level_adjustment,
            "forced_level": adjustment.forced_level,
        },
    )

    logger.info(
        "persona_state_transition_logged",
        previous=previous_state.value if previous_state else "initial",
        new=new_state.value,
        reason=adjustment.transition_reason,
    )


# ---------------------------------------------------------------------------
# Orchestration
# ---------------------------------------------------------------------------


async def evaluate_and_apply_health_state(
    db_session,
    memory_session,
    yandere_engine,
    is_distress_active: bool = False,
    is_safe_mode: bool = False,
) -> tuple[int, PersonaState, str]:
    """Full health → persona evaluation pipeline.

    1. Fetch latest health context from TimescaleDB.
    2. Compute persona adjustment via deterministic rules.
    3. Apply Y-level adjustment with safety guardrails.
    4. Build LLM context blurb for system prompt.
    5. Log state transition to memory (if changed).

    Args:
        db_session: Async DB session for health data queries.
        memory_session: Async DB session for memory write pipeline.
        yandere_engine: YandereEngine instance for current Y-level.
        is_distress_active: Whether Faiz is in active distress/argument.
        is_safe_mode: Whether HARD STOP is active.

    Returns:
        (effective_y_level, persona_state, context_blurb) tuple.
    """
    # Fetch health data
    ctx = await fetch_health_context(db_session)

    # Compute adjustment
    adjustment = compute_persona_adjustment(ctx)

    # Apply to Y-level (with safety)
    baseline = yandere_engine.current_level
    effective_y, blurb = apply_persona_adjustment(
        baseline_level=baseline,
        adjustment=adjustment,
        is_distress_active=is_distress_active,
        is_safe_mode=is_safe_mode,
    )

    # Build LLM context
    context_blurb = build_health_context_blurb(adjustment)

    # Log transition (tracked by yandere_engine for previous state)
    await log_state_transition(
        memory_session=memory_session,
        previous_state=None,  # tracked externally by caller
        new_state=adjustment.state,
        adjustment=adjustment,
    )

    logger.info(
        "health_persona_evaluation_complete",
        state=adjustment.state.value,
        effective_y=effective_y,
        baseline_y=baseline,
        distress_active=is_distress_active,
        safe_mode=is_safe_mode,
    )

    return (effective_y, adjustment.state, context_blurb)
```

## Troubleshooting

- **Issue:** Persona state never changes from DEFAULT
  - **Solution:** Check if `ghi_score` is None — GHI engine may not be producing scores (warmup). Check `data_age_hours` — if > 4, state machine skips health adjustment by design. Run `SELECT MAX(computed_at) FROM health.daily_summary` to verify.

- **Issue:** CRITICAL state not triggering for low SpO2
  - **Solution:** Verify `SPO2_CRITICAL_MAX = 94.0` constant. Check that `ctx.spo2_avg` is populated from `health.daily_summary.spo2_avg` (not spo2_min — we use average for state, minimum for anomaly). Review `fetch_health_context()` query.

- **Issue:** Y-level going below 0 or above 5
  - **Solution:** `apply_persona_adjustment()` clamps to [0, 5]. Verify that `y_level_adjustment` value doesn't exceed safe range and that `effect_level = max(0, min(5, ...))` is intact. The clamp is the final safety net.

- **Issue:** Health data appearing during arguments
  - **Solution:** `is_distress_active` flag must be passed correctly from the agent loop. Verify that the caller of `evaluate_and_apply_health_state()` correctly detects distress state (P14-015 distress escalation + existing distress detection). During distress, the function returns baseline Y-level with empty blurb.

- **Issue:** `store_episode()` fails with classification error
  - **Solution:** Health state transitions use `RESTRICTED` classification. Verify that `RESTRICTED` constant is imported from `src.memory.write_pipeline`. Health episodes should never be `CRITICAL` — they don't contain raw metrics, only state metadata.

- **Issue:** LLM context blurb contains metric values
  - **Solution:** Audit `build_health_context_blurb()` and `context_blurb` strings in `compute_persona_adjustment()`. All blurb strings use qualitative language only ("appears tired", "low energy", "good health score"). If any numeric values leak, they come from `transition_reason` which is for logging only, not for LLM injection.

## Notes

- **CONFRONTATION BOUNDARY — ABSOLUTE PROHIBITION:** Health data MUST NEVER be used for confrontation, correction, or punishment. This is enforced by:
  1. `build_health_context_blurb()` only returns qualitative care-focused language — zero metric values.
  2. `apply_persona_adjustment()` with `is_distress_active=True` returns baseline Y-level with empty blurb — health data invisible during arguments.
  3. The `transition_reason` field (which contains metric values) is ONLY written to memory logs and NEVER included in LLM context blurb.
  4. Code audit gate (automated test) verifies blurb strings contain no numeric patterns.
  5. Violation of this boundary = ADR-001/ADR-002 safety violation.
  - This boundary is specified in PersonaSafetyPolicy §4.7 and ADR-001. It is non-negotiable.

- **Metric privacy:** Guinevere NEVER volunteers specific health metrics unless Faiz explicitly asks via `/health-status` or `/ghi-score` commands (P14-016). The persona state machine only uses category-level state labels (e.g., "sleep_deprived", not "4.2 hours sleep").

- **Warmup behavior:** During the 28-day warmup period (before GHI baselines stabilize), `fetch_health_context()` may return `HealthContext` with `ghi_score=None`. The deterministic rules handle missing data gracefully — state defaults to DEFAULT when no strong signals exist.

- **State persistence:** Persona states are ephemeral (computed each evaluation cycle). They are NOT stored as a persistent "current state" in the database. The only persistent record is the `store_episode()` transition log, which serves as an audit trail. Y-level management is handled by the existing `YandereEngine` (P4).

- **Integration with agent loop:** This module is called from the agent loop's pre-LLM-call hook (P5). Before each LLM invocation, the agent loop calls `evaluate_and_apply_health_state()` to get the current health-derived Y-level and context blurb, which are injected into the system prompt. The hook respects distress/safe-mode flags from the existing safety infrastructure (P4 safe_mode module, P14-015 distress escalation).

- **post-launch enhancements:** Mood self-report correlation (`/health-status` mood field), sleep debt accumulation tracking (multi-day sleep deprivation), gradual Y-level recovery after critical states (not instant snap-back), configurable thresholds per operator preference, integration with P18 advanced memory for longitudinal health-persona correlation analysis.
