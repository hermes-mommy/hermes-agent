## Goal

Inject health anomalies and trend summaries into Guinevere's episodic memory pipeline via `store_episode()` with `source="wearable"`, providing care-context awareness while enforcing strict boundaries: **summary data ONLY — never raw metrics, never for behavioral correction**.

---

## Context

### Why This Exists

P14-013 computes persona state from the GHI engine and anomaly detection. But the persona engine needs persistent memory of health trends for conversation context — not just a transient state flag. When Faiz asks "how have I been sleeping lately?", Guinevere must be able to reference stored episodes, not re-compute from TimescaleDB at query time.

### Binding Decisions

1. **Summary only, never raw metrics.** Pitch values, HR curves, SpO2 time-series stay in TimescaleDB `health.*` hypertables. Memory entries contain derived summaries: "GHI dropped from 72→45 over 3 days" — NOT raw vitals.
2. **`source="wearable"`** for all health memory episodes. Distinct from `"surveillance"`, `"discord"`, `"agent-loop"`.
3. **`episode_type="health_trend"`** for trend shifts; `"health_anomaly"` for flagged events.
4. **Classification = `"Critical"`** with mandatory `summary` parameter (fail-closed per `_guard_critical`).
5. **NEVER for confrontation.** The memory bridge hardcodes a gate: if `persona_state` indicates `unwell` or `stressed`, no health episodes are recalled to prevent weaponized health data. During active argument/distress state, health memory is invisible.
6. **Retention: 365 days** — long enough for year-over-year health trend context.

### 4.2 Write the Health Memory Bridge

Create `src/persona/health_memory_bridge.py`:

```python
"""Health memory injection bridge — P14-014.

Injects health anomaly and trend summaries into Guinevere's episodic
memory pipeline via ``store_episode()`` with ``source="wearable"``.

Rules (HARD):
  - Summary data ONLY — NEVER raw vitals, pitch values, or time-series.
  - All episodes classified ``Critical`` with mandatory sanitized summary.
  - NEVER inject during active argument/distress state (confrontation gate).
  - NEVER inject health data usable for behavioral correction.
  - Cooldown: 60 minutes between same-metric trend injections.
  - 365-day retention per health data retention policy.

Binding to P14-013:
  Reads ``persona_state`` to determine if injection is suppressed
  during ``unwell``/``stressed``/argument states.

Binding to P3 Memory Pipeline:
  Uses ``store_episode(session, content=summary, source="wearable",
  episode_type="health_trend", classification=CRITICAL, summary=sanitized,
  importance=8, tags=[...], metadata=episode_dict)``.
"""

from __future__ import annotations

import logging
from dataclasses import dataclass
from datetime import datetime, timedelta, timezone
from typing import Final

from src.memory.write_pipeline import (
    CRITICAL,
    store_episode,
)

_logger = logging.getLogger(__name__)

# ---------------------------------------------------------------------------
# Constants
# ---------------------------------------------------------------------------

WIB: Final[timezone] = timezone(timedelta(hours=7))

# Cooldown: don't inject the same metric+trend combination within this window
_COOLDOWN_MINUTES: Final[int] = 60

# States where health memory injection is BLOCKED
_BLOCKED_STATES: Final[frozenset[str]] = frozenset(
    {"unwell", "stressed", "argument"}
)

# Episode type constants
TYPE_HEALTH_TREND: Final[str] = "health_trend"
TYPE_HEALTH_ANOMALY: Final[str] = "health_anomaly"

# Source label
SOURCE_WEARABLE: Final[str] = "wearable"

# Importance: health context above default (8/10)
HEALTH_IMPORTANCE: Final[int] = 8

# ---------------------------------------------------------------------------
# Data Types
# ---------------------------------------------------------------------------


@dataclass(frozen=True)
class HealthEpisode:
    """Structured health episode for memory injection.

    All fields are summary-level. Raw vitals stay in TimescaleDB.
    """

    episode_type: str  # "health_trend" | "health_anomaly"
    metric: str  # "sleep", "ghi", "heart_rate", "spo2", "activity"
    direction: str  # "improving", "declining", "stable", "spike"
    severity: str  # "info", "moderate", "high", "critical"
    context: str  # Human-readable summary (≤ 280 chars)
    timestamp: datetime
    ghi_snapshot: dict[str, object] | None = None
    baseline_reference: dict[str, object] | None = None

    def as_metadata_dict(self) -> dict[str, object]:
        """Serialize to JSONB-compatible dict for store_episode metadata."""
        return {
            "type": self.episode_type,
            "metric": self.metric,
            "direction": self.direction,
            "severity": self.severity,
            "context": self.context,
            "timestamp": self.timestamp.isoformat(),
            "ghi_snapshot": self.ghi_snapshot,
            "baseline_reference": self.baseline_reference,
        }

    def as_sanitized_summary(self) -> str:
        """Produce a one-line summary safe for Critical classification."""
        direction_arrow = {
            "improving": "↑",
            "declining": "↓",
            "stable": "→",
            "spike": "⚠",
        }.get(self.direction, "—")
        return (
            f"[{self.severity.upper()}] {self.metric} {direction_arrow} "
            f"{self.context}"
        )


# ---------------------------------------------------------------------------
# Injection Gate — Confrontation Boundary
# ---------------------------------------------------------------------------


def _injection_blocked(persona_state: str) -> bool:
    """Return True if health memory injection is blocked by confrontation boundary.

    Per requirements §4.7: health data is NEVER injected during active
    argument/distress state. During unwell or stressed persona states,
    health memory is invisible to the persona engine.
    """
    return persona_state in _BLOCKED_STATES


# ---------------------------------------------------------------------------
# Cooldown Tracker (in-memory; single-process model)
# ---------------------------------------------------------------------------

_last_injection: dict[str, datetime] = {}
"""Tracks last injection time per metric+direction key for cooldown."""


def _cooldown_key(episode: HealthEpisode) -> str:
    """Generate cooldown key from metric + direction."""
    return f"{episode.metric}:{episode.direction}"


def _check_cooldown(episode: HealthEpisode) -> bool:
    """Return True if still within cooldown window for this metric+direction."""
    key = _cooldown_key(episode)
    last = _last_injection.get(key)
    if last is None:
        return False
    elapsed = datetime.now(timezone.utc) - last
    return elapsed < timedelta(minutes=_COOLDOWN_MINUTES)


def _record_injection(episode: HealthEpisode) -> None:
    """Record last injection time for cooldown tracking."""
    key = _cooldown_key(episode)
    _last_injection[key] = datetime.now(timezone.utc)


# ---------------------------------------------------------------------------
# Episode Builders — Domain-Specific Summaries
# ---------------------------------------------------------------------------


def build_sleep_trend_episode(
    current_hours: float,
    baseline_hours: float,
    current_quality: float | None = None,
    consecutive_bad_nights: int = 0,
    ghi_score: int | None = None,
    ghi_tier: str | None = None,
) -> HealthEpisode:
    """Build a sleep trend episode from daily summary data.

    Example output context:
      "Faiz slept 4.5h last night (baseline 7.2h, -37.5%)"
      "Sleep recovered to 7.8h after 3 poor nights"
    """
    deviation_pct = (
        ((current_hours - baseline_hours) / baseline_hours) * 100
        if baseline_hours > 0
        else 0.0
    )

    if abs(deviation_pct) < 10 and consecutive_bad_nights == 0:
        direction = "stable"
        severity = "info"
    elif deviation_pct <= -20:
        direction = "declining"
        severity = "high" if consecutive_bad_nights >= 3 else "moderate"
    elif deviation_pct >= 20:
        direction = "improving"
        severity = "info"
    else:
        direction = "stable"
        severity = "info"

    context = (
        f"Faiz slept {current_hours:.1f}h last night "
        f"(baseline {baseline_hours:.1f}h, {deviation_pct:+.1f}%)"
    )
    if consecutive_bad_nights >= 3:
        context += f" — {consecutive_bad_nights} consecutive short nights"
    elif current_quality is not None:
        quality_label = (
            "excellent" if current_quality >= 85
            else "good" if current_quality >= 70
            else "fair" if current_quality >= 55
            else "poor"
        )
        context += f" — quality: {quality_label}"

    ghi_snapshot: dict[str, object] | None = None
    if ghi_score is not None and ghi_tier is not None:
        ghi_snapshot = {"score": ghi_score, "tier": ghi_tier}

    return HealthEpisode(
        episode_type=TYPE_HEALTH_TREND,
        metric="sleep",
        direction=direction,
        severity=severity,
        context=context,
        timestamp=datetime.now(timezone.utc),
        ghi_snapshot=ghi_snapshot,
        baseline_reference={
            "metric": "sleep_hours",
            "baseline_28d": round(baseline_hours, 1),
            "current": round(current_hours, 1),
            "deviation_pct": round(deviation_pct, 1),
        },
    )


def build_ghi_trend_episode(
    current_score: int,
    previous_score: int,
    current_tier: str,
    previous_tier: str,
) -> HealthEpisode | None:
    """Build a GHI trend episode.

    Returns None if no meaningful change (same tier, <5 point delta).
    """
    delta = current_score - previous_score

    if abs(delta) < 5 and current_tier == previous_tier:
        return None  # No meaningful change

    if delta >= 10:
        direction = "improving"
        severity = "info"
    elif delta <= -10:
        direction = "declining"
        severity = "moderate"
    else:
        direction = "stable"
        severity = "info"

    # Detect tier transition
    tier_note = ""
    if current_tier != previous_tier:
        tier_note = f" ({previous_tier}→{current_tier} transition)"

    context = (
        f"GHI {direction} to {current_score} "
        f"(prev: {previous_score}, delta: {delta:+d}){tier_note}"
    )

    return HealthEpisode(
        episode_type=TYPE_HEALTH_TREND,
        metric="ghi",
        direction=direction,
        severity=severity,
        context=context,
        timestamp=datetime.now(timezone.utc),
        ghi_snapshot={
            "score": current_score,
            "tier": current_tier,
            "previous_score": previous_score,
            "previous_tier": previous_tier,
            "delta": delta,
        },
    )


def build_anomaly_episode(
    metric: str,
    description: str,
    severity: str,
    current_value: float,
    baseline_value: float,
    deviation_pct: float,
    ghi_score: int | None = None,
    ghi_tier: str | None = None,
) -> HealthEpisode:
    """Build a health anomaly episode from anomaly detection.

    Example: SpO2 dropped to 93%, HR sustained elevation, GHI critical.
    """
    context = (
        f"{metric} anomaly: {description} "
        f"(current: {current_value}, baseline: {baseline_value}, "
        f"deviation: {deviation_pct:+.1f}%)"
    )

    ghi_snapshot: dict[str, object] | None = None
    if ghi_score is not None and ghi_tier is not None:
        ghi_snapshot = {"score": ghi_score, "tier": ghi_tier}

    return HealthEpisode(
        episode_type=TYPE_HEALTH_ANOMALY,
        metric=metric,
        direction="spike",
        severity=severity,
        context=context,
        timestamp=datetime.now(timezone.utc),
        ghi_snapshot=ghi_snapshot,
        baseline_reference={
            "metric": metric,
            "baseline_28d": baseline_value,
            "current": current_value,
            "deviation_pct": round(deviation_pct, 1),
        },
    )


# ---------------------------------------------------------------------------
# Main Injection Function
# ---------------------------------------------------------------------------


async def inject_health_episode(
    session: object,  # SQLAlchemy AsyncSession protocol
    episode: HealthEpisode,
    persona_state: str,
    *,
    embedding_service: object | None = None,
) -> str | None:
    """Inject a health episode into episodic memory.

    Enforces:
      - Confrontation boundary gate (no injection during unwell/stressed/argument)
      - Cooldown window for same metric+direction
      - Critical classification with sanitized summary
      - Structured metadata for query-time filtering

    Args:
        session: SQLAlchemy AsyncSession bound to guinevere DB.
        episode: Structured HealthEpisode to inject.
        persona_state: Current persona state from P14-013.
        embedding_service: Optional embedding service for vector storage.

    Returns:
        Episode UUID string on success, None if blocked/suppressed.

    Raises:
        WritePipelineCriticalError: If sanitized summary generation fails.
    """
    # ---- Gate 1: Confrontation Boundary --------------------------------
    if _injection_blocked(persona_state):
        _logger.info(
            "health_episode_blocked",
            extra={
                "reason": "confrontation_boundary",
                "persona_state": persona_state,
                "metric": episode.metric,
            },
        )
        return None

    # ---- Gate 2: Cooldown ------------------------------------------------
    if _check_cooldown(episode):
        _logger.debug(
            "health_episode_cooldown",
            extra={
                "metric": episode.metric,
                "direction": episode.direction,
                "cooldown_minutes": _COOLDOWN_MINUTES,
            },
        )
        return None

    # ---- Build sanitized summary for Critical classification ------------
    sanitized = episode.as_sanitized_summary()
    if not sanitized.strip():
        _logger.error("health_episode_empty_summary", extra={"episode": repr(episode)})
        return None

    # ---- Inject via memory pipeline -------------------------------------
    episode_id = await store_episode(
        session,
        content=sanitized,  # Summary only — NO raw vitals
        source=SOURCE_WEARABLE,
        classification=CRITICAL,
        importance=HEALTH_IMPORTANCE,
        summary=sanitized,  # Required for Critical classification
        episode_type=episode.episode_type,
        tags=[episode.metric, episode.severity, f"ghi:{episode.ghi_snapshot.get('tier', 'unknown')}" if episode.ghi_snapshot else f"metric:{episode.metric}"],
        metadata=episode.as_metadata_dict(),
        embedding_service=embedding_service,
    )

    _record_injection(episode)

    _logger.info(
        "health_episode_stored",
        extra={
            "episode_id": str(episode_id),
            "metric": episode.metric,
            "severity": episode.severity,
            "episode_type": episode.episode_type,
        },
    )

    return str(episode_id)


# ---------------------------------------------------------------------------
# Batch Injection — Scheduled Runner (APScheduler-friendly)
# ---------------------------------------------------------------------------


async def inject_daily_health_summaries(
    session: object,
    daily_summary_row: object,  # health.daily_summary ORM instance
    persona_state: str,
    *,
    embedding_service: object | None = None,
) -> list[str]:
    """Inject sleep + GHI + activity trend episodes from daily summary.

    Called by APScheduler daily at ~07:00 WIB after daily_summary computation.
    Only injects episodes with meaningful changes (cooldown + thresholds).
    """
    import uuid as _uuid  # noqa: F811

    injected_ids: list[str] = []

    # Ideally you read these from the ORM row. Shown as keyword params for clarity.
    # In production: row.sleep_total_h, row.ghi_score, row.activity_score, etc.
    sleep_hours = getattr(daily_summary_row, "sleep_total_h", None)
    ghi_score = getattr(daily_summary_row, "ghi_score", None)
    steps = getattr(daily_summary_row, "steps", None)

    # Sleep trend
    if sleep_hours is not None:
        sleep_episode = build_sleep_trend_episode(
            current_hours=float(sleep_hours),
            baseline_hours=7.2,  # Replace with actual baseline lookup
            # baseline_hours=await _get_baseline(session, "sleep_hours"),
            ghi_score=ghi_score,
        )
        ep_id = await inject_health_episode(
            session, sleep_episode, persona_state,
            embedding_service=embedding_service,
        )
        if ep_id:
            injected_ids.append(ep_id)

    # Activity trend (simplified — steps delta)
    if steps is not None and ghi_score is not None:
        activity_context = (
            f"Faiz walked {steps:,} steps today "
            f"(GHI activity pillar contributing to score {ghi_score})"
        )
        activity_episode = HealthEpisode(
            episode_type=TYPE_HEALTH_TREND,
            metric="activity",
            direction="stable",
            severity="info",
            context=activity_context,
            timestamp=datetime.now(timezone.utc),
            ghi_snapshot={"score": ghi_score} if ghi_score else None,
        )
        ep_id = await inject_health_episode(
            session, activity_episode, persona_state,
            embedding_service=embedding_service,
        )
        if ep_id:
            injected_ids.append(ep_id)

    return injected_ids
```

```python
from sqlalchemy.ext.asyncio import create_async_engine, AsyncSession
```

## Notes

### Safety Boundaries (ABSOLUTE)

1. **NEVER use health data for confrontation, correction, or punishment.** This is hardcoded via `_injection_blocked()` and reinforced by the memory read pipeline's confrontation block (P3 recall gate).
2. **NEVER mention specific health metrics unless Faiz asks directly.** The memory bridge stores episodes for care-context awareness, not unsolicited health commentary.
3. **During active argument/distress state:** `_injection_blocked()` returns `True` — zero health episodes are written during these states. The persona engine receives no health context when arguing with Faiz.
4. **Contravention of any boundary = safety violation per ADR-001 and ADR-002.** Triggers `ConfrontationBlockLog` entry in `surveillance.confrontation_block_log`.
