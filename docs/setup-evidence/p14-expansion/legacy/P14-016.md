## Goal

Implement two Discord slash commands that display Guinevere Health Index scores, pillar breakdowns, and optional mood self-report in rich embed format with color-coded tiers — **ALL responses ephemeral (private)**, Faiz-only access.

---

## Context

### Command Specifications

| Command | Description | Parameters |
|---|---|---|
| `/health-status` | Current GHI score, all pillar summaries, optional mood self-report | `mood_rating` (optional, 1-10), `mood_notes` (optional, text) |
| `/ghi-score` | Detailed GHI breakdown: Sleep 40% + Cardio 20% + Activity 20% + Recovery 20% with individual pillar scores and contribution weights | None |

### Embed Color Coding

| Tier | Score Range | Color | Hex | Constant |
|---|---|---|---|---|
| Excellent | >= 85 | Green | `0x16A34A` | `SUCCESS` |
| Good | 70-84 | Green | `0x16A34A` | `SUCCESS` |
| Fair | 55-69 | Yellow/Gold | `0xCA8A04` | `WARNING` |
| Poor | 40-54 | Red | `0xDC2626` | `ALERT` |
| Critical | < 40 | Red | `0xDC2626` | `ALERT` |

### Warm-Up Period

If < 28 days of data: display "Building baseline — X days remaining before clinical validity" with a yellow embed and progress field.

### Binding Decisions

1. **ALL responses are ephemeral.** `defer_ephemeral(interaction)` + `followup_send(interaction, embed=embed)` — health data NEVER visible to others.
2. **Faiz-only.** `is_faiz_interaction(interaction)` check — denied users get ephemeral "Hanya Faiz" message.
3. **NEVER confrontational.** Embed descriptions use observational language: "Here's how you're doing today, Darling." — no judgment.
4. **Mood self-report is optional.** If `mood_rating` is None, the mood field is omitted entirely (not shown as "No input").
5. **No raw vitals in embed.** Only scores and summaries. Precise HR/SpO2/body battery values stay in TimescaleDB.
6. **Data source:** `health.daily_summary` (P14-012) for current; `health.ghi_daily` (P14-011) for previous day trend.

### Integration Points

| System | Interaction |
|---|---|
| `health.daily_summary` | Source of GHI + pillar scores (1 row query: `ORDER BY date DESC LIMIT 2`) |

**Core Builder — `build_health_status_embed`:**

```python
def build_health_status_embed(
    ghi_score: int | None = None,
    ghi_tier: str = "Unknown",
    sleep_score: int | None = None,
    cardio_score: int | None = None,
    activity_score: int | None = None,
    recovery_score: int | None = None,
    sleep_hours: float | None = None,
    resting_hr: int | None = None,
    steps: int | None = None,
    mood_rating: int | None = None,
    mood_notes: str | None = None,
    days_of_data: int = 0,
    now: datetime | None = None,
) -> EmbedData:
    """Build deterministic embed for /health-status.

    Warm-up guard: if days_of_data < 28, return warmup embed.
    Otherwise: GHI tier emoji + score + pillar fields + quick stats + optional mood.
    """
    ref = now or datetime.now(timezone.utc)
    ts = _format_wib_timestamp(ref)

    if days_of_data < 28:
        return _build_warmup_embed(28 - days_of_data)

    color = GHI_TIER_COLORS.get(ghi_tier, WARNING)
    tier_emoji = GHI_TIER_EMOJI.get(ghi_tier, "📊")

    # Description: "🌟 GHI: 88/100 — Excellent\nHere's how you're doing today, Darling."
    desc = f"{tier_emoji} **GHI: {ghi_score}/100** — *{ghi_tier}*\nHere's how you're doing today, Darling."

    fields: list[EmbedField] = []

    # Pillar fields: "😴 Sleep (40%): **82/100** ████████░░"
    pillar_scores = {"sleep_score": sleep_score, "cardio_score": cardio_score,
                     "activity_score": activity_score, "recovery_score": recovery_score}
    for pillar in PILLAR_INFO:
        score = pillar_scores.get(pillar["key"])
        if score is not None:
            bar = "█" * (score // 10) + "░" * (10 - score // 10)
            fields.append(EmbedField(
                name=f"{pillar['emoji']} {pillar['label']} ({pillar['weight']})",
                value=f"**{score}/100** {bar}", inline=True))

    # Quick stats: "😴 7.2h sleep · 💓 68 bpm resting · 🏃 8,420 steps"
    stats = []
    if sleep_hours is not None: stats.append(f"😴 {sleep_hours:.1f}h sleep")
    if resting_hr is not None: stats.append(f"💓 {resting_hr} bpm resting")
    if steps is not None: stats.append(f"🏃 {steps:,} steps")
    if stats:
        fields.append(EmbedField(name="📊 Quick Stats", value=" · ".join(stats), inline=False))

    # Mood self-report (if provided): "🎭 Your Mood: **7/10** `███████░░░`\n*"Feeling good!"*"
    if mood_rating is not None:
        mood_bar = "█" * mood_rating + "░" * (10 - mood_rating)
        mood_value = f"**{mood_rating}/10** `{mood_bar}`"
        if mood_notes:
            mood_value += f"\n*\"{mood_notes}\"*"
        fields.append(EmbedField(name="🎭 Your Mood (self-reported)", value=mood_value, inline=False))

    return EmbedData(title="❤️ Health Status", description=desc, color=color,
                     fields=tuple(fields), footer_icon="❤️ Health", timestamp=ts)
```

## Notes

### Safety Boundaries

1. **ALL responses are ephemeral `True`.** No exception — health data is private. Verified by checking `ephemeral=True` in all `defer` and `followup.send` calls.
2. **Faiz-only enforcement.** `is_faiz_interaction()` is called BEFORE any DB query — denied users never trigger health data access.
3. **NEVER confrontational.** Embed descriptions say "Here's how you're doing today" — never "You're doing poorly" or any judgmental language. Pillar scores are neutral observations.
4. **No raw vitals.** The embed builders accept scores/aggregates only. There is no code path to inject raw bpm, SpO2%, or HRV values into embed fields.

### Pattern Compliance

Both files follow the exact same pattern as existing commands:
- `cmd_mood.py` — dataclass pattern, `build_mood_embed_data()`, `mood_callback()`
- `cmd_status.py` — 11-field embed, `build_status_embed_data()`, `status_callback()`
- `cmd_health_check.py` — async data fetch, `_fetch_health()`, enrich + build

### Cross-References

- **P14-011** (GHI Engine): Computes `health.ghi_daily` rows — `/ghi-score` shows previous day for trend.
- **P14-012** (Daily Summary): `health.daily_summary` is the primary data source.
- **P2** (Discord Bot): Command tree registration, `is_faiz_interaction`, embed helpers.
- **P14-018** (Morning Brief): Uses same GHI tier colors and pillar labels — consistency.

### Post-Launch Enhancements

- **7-day trend chart:** ASCII sparkline in `/health-status` embed showing GHI trajectory over last week.
- **/health-history command:** Paginated GHI history with date range picker.
- **Interactive mood tracking:** Button components for quick mood logging (1-5 emoji scale).
- **Multi-week comparison:** `/ghi-score` with optional `compare_week` parameter.

### Cost Impact

$0 — pure code, no new infrastructure. DB queries are lightweight (2 rows from `daily_summary`, 1 aggregation query). No additional API calls.
