## Context

Faiz must be able to export all health data on demand and delete it if desired. This implements data portability and erasure rights for health surveillance data. Two Discord slash commands serve as the interface: `/health-export` triggers an async export job and DMs a download link; `/health-delete` initiates a confirmation flow before executing deletion.

Export capabilities: full export of all 7 metrics, daily summaries, GHI history, and anomaly events as JSON or CSV. Selective export filters by date range (from/to YYYY-MM-DD) and/or metric type.

Deletion capabilities: selective deletion by date range or full wipe with explicit confirmation. Every export and deletion action writes to `health.audit_log` with timestamp, action type, scope, and outcome.

This step produces `src/surveillance/health_data_management.py`, two Discord command files (`src/discord/cmd_health_export.py`, `src/discord/cmd_health_delete.py`), and adds the `health.audit_log` table.

                rows = await self._fetch_metric(conn, metric, req.date_from, req.date_to)

        else:
            self._write_csv(file_path, records, metrics)

        async with self._pool.acquire() as conn:
            await self._update_audit(conn, req.file_id, total, \"completed\")

        return ExportResult(
            file_id=req.file_id, file_path=str(file_path),
            record_count=total, size_bytes=size,
        )

        total = 0
        affected: list[str] = []

        async with self._pool.acquire() as conn:
            if req.full_wipe:
                for table in ALL_TABLES:
                    cnt = await self._delete_all(conn, table)
                    if cnt > 0:
                        total += cnt
                        affected.append(table)
            else:
                for table in ALL_TABLES:
                    cnt = await self._delete_range(conn, table, req.date_from, req.date_to)
                    if cnt > 0:
                        total += cnt
                        affected.append(table)

            await self._insert_audit(
                conn, ActionType.DELETE,
                ExportRequest(
                    file_id=str(uuid.uuid4()),
                    date_from=req.date_from, date_to=req.date_to,
                ),
                total,
                initial_status=\"completed\",
            )

        return DeleteResult(record_count=total, tables_affected=affected)

        params: list[Any] = [OWNER_ID]
        param_idx = 1

        query = \"SELECT * FROM health.\" + metric + \" WHERE owner_id = $1::uuid\"

        if date_from:
            param_idx += 1
            query += \" AND \" + time_col + \" >= $\" + str(param_idx)
            params.append(date_from)
        if date_to:
            param_idx += 1
            query += \" AND \" + time_col + \" < $\" + str(param_idx) + \"::date + interval '1 day'\"
            params.append(date_to)

        query += \" ORDER BY \" + time_col + \" DESC LIMIT 500000\"

        rows = await conn.fetch(query, *params)
        return [dict(r) for r in rows]

    async def _delete_all(self, conn, table: str) -> int:
        query = \"DELETE FROM health.\" + table + \" WHERE owner_id = $1::uuid\"
        result = await conn.execute(query, OWNER_ID)
        cnt_str = result.split()[-1] if \"DELETE\" in result else \"0\"
        return int(cnt_str) if cnt_str.isdigit() else 0

        if date_from:
            param_idx += 1
            query += \" AND \" + time_col + \" >= $\" + str(param_idx)
            params.append(date_from)
        if date_to:
            param_idx += 1
            query += \" AND \" + time_col + \" < $\" + str(param_idx) + \"::date + interval '1 day'\"
            params.append(date_to)

        cnt_str = result.split()[-1] if \"DELETE\" in result else \"0\"
        return int(cnt_str) if cnt_str.isdigit() else 0

"""Discord slash command: /health-export — triggers async health data export.

Flow: defer → spawn async export job → DM download link to Faiz.
"""
from __future__ import annotations

import asyncio
import logging
import uuid
from datetime import datetime, timezone, timedelta

import discord

from src.discord._embed_helpers import (
    EmbedData, EmbedField, to_discord_embed, format_wib_timestamp,
    defer_ephemeral, followup_send, is_faiz_interaction, send_denied,
)
from src.discord.colors import SUCCESS, PRIMARY
from src.surveillance.health_data_management import (
    HealthDataManager, ExportRequest, ExportFormat, ALL_METRICS,
)

logger = logging.getLogger(__name__)
WIB = timezone(timedelta(hours=7))

async def cmd_health_export(
    interaction: discord.Interaction,
    health_manager: HealthDataManager,
    fmt: str = "json",
    date_from: str = "",
    date_to: str = "",
    metrics_filter: str = "",
) -> None:
    if not is_faiz_interaction(interaction):
        await send_denied(interaction)
        return

    await defer_ephemeral(interaction)

    file_id = str(uuid.uuid4())[:12]
    export_fmt = ExportFormat.CSV if fmt.lower() == "csv" else ExportFormat.JSON

    metrics = None
    if metrics_filter:
        metrics = [m.strip() for m in metrics_filter.split(",")]

    from_date = None
    to_date = None
    try:
        from datetime import date
        if date_from:
            from_date = date.fromisoformat(date_from)
        if date_to:
            to_date = date.fromisoformat(date_to)
    except ValueError as exc:
        await followup_send(
            interaction,
            embed=to_discord_embed(EmbedData(
                title="Invalid date format",
                description=str(exc),
                color=0xDC2626,
            )),
        )
        return

    await followup_send(
        interaction,
        embed=to_discord_embed(EmbedData(
            title="Health Export Started",
            description=f"Export job {file_id} is running. You will receive a DM when ready.",
            color=PRIMARY,
            fields=(
                EmbedField(name="Format", value=export_fmt.value, inline=True),
                EmbedField(name="Job ID", value=file_id, inline=True),
            ),
            timestamp=format_wib_timestamp(datetime.now(WIB)),
        )),
    )

    try:
        result = await health_manager.export_data(ExportRequest(
            file_id=file_id,
            metrics=metrics,
            date_from=from_date,
            date_to=to_date,
            fmt=export_fmt,
        ))

        user = await interaction.client.fetch_user(interaction.user.id)
        dm = await user.create_dm()
        await dm.send(
            content=f"Health export ready: {result.record_count} records, {result.size_bytes} bytes",
            file=discord.File(result.file_path),
        )
    except Exception as exc:
        logger.error("Health export failed: %s", exc)
        user = await interaction.client.fetch_user(interaction.user.id)
        dm = await user.create_dm()
        await dm.send(content=f"Health export failed: {exc}")

"""Discord slash command: /health-delete — confirmation-gated health data deletion.

Flow: defer → show confirmation prompt → wait for "CONFIRM" → execute deletion → audit log.
"""
from __future__ import annotations

import asyncio
import logging
from datetime import datetime, timezone, timedelta, date

import discord

from src.discord._embed_helpers import (
    EmbedData, EmbedField, to_discord_embed, format_wib_timestamp,
    defer_ephemeral, followup_send, is_faiz_interaction, send_denied,
)

from src.surveillance.health_data_management import HealthDataManager, DeleteRequest

logger = logging.getLogger(__name__)
WIB = timezone(timedelta(hours=7))

DELETE_CONFIRM_WORD = "CONFIRM-DELETE"

async def cmd_health_delete(
    interaction: discord.Interaction,
    health_manager: HealthDataManager,
    date_from: str = "",
    date_to: str = "",
    full_wipe: bool = False,
    confirm: str = "",
) -> None:
    if not is_faiz_interaction(interaction):
        await send_denied(interaction)
        return

    await defer_ephemeral(interaction)

    if confirm != DELETE_CONFIRM_WORD:
        scope = "ALL health data" if full_wipe else f"data from {date_from or 'beginning'} to {date_to or 'now'}"
        await followup_send(
            interaction,
            embed=to_discord_embed(EmbedData(
                title="Confirm Health Data Deletion",
                description=(
                    f"**WARNING**: This will delete {scope}.\n"
                    f"To confirm, run the command again with confirm=\"{DELETE_CONFIRM_WORD}\"."
                ),
                color=ALERT,
                fields=(
                    EmbedField(name="Scope", value=scope, inline=False),
                    EmbedField(name="Confirm Word", value=DELETE_CONFIRM_WORD, inline=False),
                ),
                timestamp=format_wib_timestamp(datetime.now(WIB)),
            )),
        )
        return

    try:
        from_date = date.fromisoformat(date_from) if date_from else None
        to_date = date.fromisoformat(date_to) if date_to else None
    except ValueError as exc:
        await followup_send(
            interaction,
            embed=to_discord_embed(EmbedData(
                title="Invalid date format",
                description=str(exc),
                color=0xDC2626,

        )

    result = await health_manager.delete_data(DeleteRequest(
        date_from=from_date, date_to=to_date, full_wipe=full_wipe,

        interaction,

            title="Health Data Deleted",
            description=f"Successfully deleted {result.record_count} records.",
            color=SUCCESS,

                EmbedField(name="Records", value=str(result.record_count), inline=True),

## Troubleshooting

- **Issue:** `asyncpg` connection pool not available
  - **Solution:** The `HealthDataManager` requires an `asyncpg.Pool` instance. Create one: `pool = await asyncpg.create_pool(dsn="postgresql://guinevere:***@localhost/guinevere")`. Pass to constructor.

- **Issue:** Export file too large (> 1GB)
  - **Solution:** The 500000 row LIMIT per metric prevents unbounded exports. For date-filtered exports, the actual row count may be lower. If exports consistently exceed 1GB, increase `/tmp` space or add compression (`gzip` the output file).

- **Issue:** DM fails to send file
  - **Solution:** Discord has an 8MB file size limit for bot DMs. If export exceeds 8MB, split into chunks or add a note in the DM to use selective export. Check: `ls -lh /tmp/guinevere-health-exports/`.

- **Issue:** Full wipe deletes data but audit_log row also deleted
  - **Solution:** `health.audit_log` is excluded from ALL_TABLES — the audit log survives deletion. ALL_TABLES only contains metric tables (heart_rate, sleep_sessions, etc.) plus sync_log and anomaly_events.

- **Issue:** Delete confirmation word rejected
  - **Solution:** The confirmation word is `CONFIRM-DELETE` (exact match, case-sensitive). Must be passed as the `confirm` parameter: `/health-delete full_wipe:true confirm:CONFIRM-DELETE`.

## Notes

- **Audit log schema**: The table uses `file_id` to correlate export records. For deletions, a random UUID is generated. Consider adding an explicit `action_id` column post-launch.
- **CSV export**: Multi-metric CSV writes a comment header (`# metric_name`) before each metric's data. This keeps all data in one file while allowing metric disambiguation.
- **JSON export**: Uses `default=str` fallback for any non-serializable types. datetime/date are converted to ISO format explicitly.
- The export uses string concatenation for dynamic table/column names. This is safe because table names come from the controlled ALL_METRICS list (not user input). Date values use parameterized placeholders (`$N`).
- Post-launch enhancement: add `/health-export` option for S3/cloud storage instead of local `/tmp`.
- Post-launch enhancement: add retention-based auto-deletion (cleanup exports older than 7 days from `/tmp`).
