## Context

Before any health data collection begins, 7 preconditions must be verified. The Wearable Activation Checklist formalizes these as named gates (WAC-001 through WAC-007), each with an automated check and a manual confirmation step. This is a safety gate — it prevents partial/broken pipelines from ingesting health data without full infrastructure readiness.

The 7 gates map directly to P14-001 through P14-007:

| Gate | Name | Dependency | Automated Check | Manual Confirmation |
|------|------|-----------|-----------------|---------------------|
| WAC-001 | Device Paired | P14-001 | Ping Gadgetbridge WebDAV for device serial | Faiz confirms watch is on wrist |
| WAC-002 | WebDAV Operational | P14-002 | HTTP 200 from WebDAV health endpoint | Faiz confirms WebDAV UI accessible |
| WAC-003 | DB Schema Verified | P14-003 | Query all 7 health.* hypertables exist | Faiz reviews schema migration log |
| WAC-004 | HMAC Key Provisioned | P14-004 | HMAC sign+verify round-trip test | Faiz confirms SOPS decrypts key |
| WAC-005 | Consent Registered | P14-007 | Query consent ledger for `surveillance.wearable.health.explicit` | Faiz confirms consent flow completed |
| WAC-006 | Ingestion E2E | P14-005 + P14-006 | POST mock health event → verify it appears in DB | Faiz confirms mock data looks correct |
| WAC-007 | 24h Data Verified | P14-005 + P14-006 | Check >0 records in all hypertables after 24h | Faiz confirms data looks realistic |

Gate state is stored in Redis DB2 under hash key `p14:activation:gates` with fields `wac_001` through `wac_007`. Each field holds a JSON object: `{"auto": true/false, "manual": true/false, "timestamp": "ISO8601", "notes": "..."}`. A gate is considered PASSED only when both `auto` and `manual` are `true`.

The module exposes a `WearableActivationChecklist` class with two primary methods: `check_gate(gate_id)` for automated verification and `confirm_gate(gate_id, notes)` for manual confirmation. A convenience method `all_gates_passed()` returns True only when all 7 gates are in PASSED state.

This step produces `src/surveillance/activation/wearable_checklist.py` and its `__init__.py`. No modifications to existing files.

"""Wearable Activation Checklist — 7 gates blocking health data collection.

Each gate requires BOTH automated verification AND manual Faiz confirmation.
State is stored in Redis DB2 hash key `p14:activation:gates`.
"""
from __future__ import annotations

import json
import logging
from dataclasses import dataclass, field
from datetime import datetime, timezone, timedelta
from enum import StrEnum
from typing import Any

import httpx
import redis.asyncio as aioredis
import asyncpg

logger = logging.getLogger(__name__)

WIB = timezone(timedelta(hours=7))
REDIS_GATES_KEY = "p14:activation:gates"
WEBDAV_HEALTH_URL = "https://localhost:8443/health"
INGESTION_ENDPOINT = "http://localhost:8000/surveillance/events"
REQUIRED_HYPERTABLES = [
    "heart_rate", "sleep_sessions", "sleep_stages",
    "daily_activity", "spo2", "hrv", "daily_summary",
]

# ── Enums ───────────────────────────────────────────────

class GateId(StrEnum):
    DEVICE_PAIRED = "wac_001"
    WEBDAV_OPERATIONAL = "wac_002"
    DB_SCHEMA_VERIFIED = "wac_003"
    HMAC_KEY_PROVISIONED = "wac_004"
    CONSENT_REGISTERED = "wac_005"
    INGESTION_E2E = "wac_006"
    DATA_24H_VERIFIED = "wac_007"

GATE_ORDER: list[GateId] = list(GateId)

# ── Models ──────────────────────────────────────────────

@dataclass
class GateState:
    gate_id: GateId
    auto_passed: bool = False
    manual_confirmed: bool = False
    timestamp: str = ""
    notes: str = ""

    def is_passed(self) -> bool:
        return self.auto_passed and self.manual_confirmed

    def to_dict(self) -> dict[str, Any]:
        return {
            "auto": self.auto_passed,
            "manual": self.manual_confirmed,
            "timestamp": self.timestamp or datetime.now(WIB).isoformat(),
            "notes": self.notes,
        }

    @classmethod
    def from_dict(cls, gate_id: GateId, data: dict[str, Any]) -> GateState:
        return cls(
            gate_id=gate_id,
            auto_passed=data.get("auto", False),
            manual_confirmed=data.get("manual", False),
            timestamp=data.get("timestamp", ""),
            notes=data.get("notes", ""),
        )

@dataclass
class ChecklistReport:
    gates: list[GateState]
    all_passed: bool
    passed_count: int
    total_count: int = 7
    generated_at: str = field(default_factory=lambda: datetime.now(WIB).isoformat())

# ── Main Class ──────────────────────────────────────────

class WearableActivationChecklist:
    """7-gate wearable activation verification engine."""

    def __init__(
        self,
        redis_client: aioredis.Redis,
        pg_pool: asyncpg.Pool | None = None,
        *,
        webdav_health_url: str = WEBDAV_HEALTH_URL,
        ingestion_endpoint: str = INGESTION_ENDPOINT,
    ) -> None:
        self._redis = redis_client
        self._pg = pg_pool
        self._webdav_url = webdav_health_url
        self._ingestion_url = ingestion_endpoint

    # ── Public API ──────────────────────────────────

    async def check_gate(self, gate_id: GateId) -> bool:
        """Run automated verification for a single gate.

        Returns True if the automated check passes.
        Updates Redis with the result.
        """
        passed = await self._run_auto_check(gate_id)
        await self._update_gate(gate_id, auto_passed=passed)
        logger.info("WAC gate %s auto check: %s", gate_id.value, "PASS" if passed else "FAIL")
        return passed

    async def confirm_gate(
        self, gate_id: GateId, notes: str = "",
    ) -> None:
        """Record manual Faiz confirmation for a gate."""
        await self._update_gate(gate_id, manual_confirmed=True, notes=notes)
        logger.info("WAC gate %s manually confirmed by Faiz", gate_id.value)

    async def all_gates_passed(self) -> bool:
        """Check if ALL 7 gates have both auto + manual pass."""
        states = await self.get_all_states()
        return all(s.is_passed() for s in states)

    async def get_all_states(self) -> list[GateState]:
        """Return current state of all 7 gates."""
        raw = await self._redis.hgetall(REDIS_GATES_KEY)
        states: list[GateState] = []
        for gid in GATE_ORDER:
            gid_str = gid.value
            if gid_str.encode() in raw:
                data = json.loads(raw[gid_str.encode()].decode())
                states.append(GateState.from_dict(gid, data))
            else:
                states.append(GateState(gate_id=gid))
        return states

    async def get_report(self) -> ChecklistReport:
        """Generate a full activation checklist report."""
        states = await self.get_all_states()
        passed = sum(1 for s in states if s.is_passed())
        return ChecklistReport(
            gates=states,
            all_passed=(passed == 7),
            passed_count=passed,
        )

    async def reset_all(self) -> None:
        """Reset all gates to initial state (for re-testing)."""
        await self._redis.delete(REDIS_GATES_KEY)
        logger.warning("All WAC gates reset to initial state")

    # ── Auto-Check Implementations ──────────────────

    async def _run_auto_check(self, gate_id: GateId) -> bool:
        checks: dict[GateId, Any] = {
            GateId.DEVICE_PAIRED: self._check_wac_001,
            GateId.WEBDAV_OPERATIONAL: self._check_wac_002,
            GateId.DB_SCHEMA_VERIFIED: self._check_wac_003,
            GateId.HMAC_KEY_PROVISIONED: self._check_wac_004,
            GateId.CONSENT_REGISTERED: self._check_wac_005,
            GateId.INGESTION_E2E: self._check_wac_006,
            GateId.DATA_24H_VERIFIED: self._check_wac_007,
        }
        handler = checks.get(gate_id)
        if handler is None:
            logger.error("Unknown gate: %s", gate_id)
            return False
        try:
            return await handler()
        except Exception as exc:
            logger.error("Auto check failed for %s: %s", gate_id.value, exc)
            return False

    async def _check_wac_001(self) -> bool:
        """WAC-001: Device paired and verified.

        Check that at least one sync_log entry exists with status='success'.
        """
        if self._pg is None:
            logger.warning("WAC-001: no DB pool, skipping")
            return False
        async with self._pg.acquire() as conn:
            row = await conn.fetchrow(
                "SELECT COUNT(*) AS cnt FROM health.sync_log WHERE status = 'success'"
            )
            return row is not None and row["cnt"] > 0

    async def _check_wac_002(self) -> bool:
        """WAC-002: WebDAV endpoint operational.

        HTTP GET to WebDAV health endpoint, expect 2xx response.
        """
        async with httpx.AsyncClient(verify=False) as client:
            try:
                resp = await client.get(self._webdav_url, timeout=10.0)
                return resp.status_code < 300
            except httpx.RequestError as exc:
                logger.warning("WAC-002 WebDAV check failed: %s", exc)
                return False

    async def _check_wac_003(self) -> bool:
        """WAC-003: Database schema created and verified.

        Check that all 7 health.* hypertables exist.
        """
        if self._pg is None:
            logger.warning("WAC-003: no DB pool, skipping")
            return False
        async with self._pg.acquire() as conn:
            for table in REQUIRED_HYPERTABLES:
                row = await conn.fetchrow(
                    "SELECT EXISTS (SELECT 1 FROM information_schema.tables "
                    "WHERE table_schema = 'health' AND table_name = $1)",
                    table,
                )
                if row is None or not row[0]:
                    logger.warning("WAC-003: missing table health.%s", table)
                    return False
        return True

    async def _check_wac_004(self) -> bool:
        """WAC-004: HMAC key provisioned and tested.

        Attempt a sign-then-verify round-trip using the health HMAC secret.
        """
        try:
            from src.surveillance.auth import sign_payload, verify_signature
            import os
            secret = os.getenv("P14_HMAC_SECRET")
            if not secret:
                logger.warning("WAC-004: P14_HMAC_SECRET not set")
                return False
            test_payload = b'{"test": "wac-004"}'
            sig = sign_payload(test_payload, secret.encode())
            return verify_signature(test_payload, sig, secret.encode())
        except ImportError as exc:
            logger.warning("WAC-004: auth module not available: %s", exc)
            return False
        except Exception as exc:
            logger.error("WAC-004 HMAC round-trip failed: %s", exc)
            return False

    async def _check_wac_005(self) -> bool:
        """WAC-005: Consent scope registered and consent flow tested.

        Check consent ledger for an explicit grant of the health scope.
        """
        if self._pg is None:
            logger.warning("WAC-005: no DB pool, skipping")
            return False
        async with self._pg.acquire() as conn:
            row = await conn.fetchrow(
                "SELECT COUNT(*) AS cnt FROM consent_ledger "
                "WHERE scope = 'surveillance.wearable.health.explicit' "
                "AND status = 'granted'"
            )
            return row is not None and row["cnt"] > 0

    async def _check_wac_006(self) -> bool:
        """WAC-006: Ingestion pipeline end-to-end test passed.

        POST a mock health event to the ingestion endpoint with HMAC auth,
        then verify it appears in health.heart_rate.
        """
        try:
            from src.surveillance.auth import sign_payload
            import os, uuid, json as json_mod
            secret = os.getenv("P14_HMAC_SECRET")
            if not secret:
                logger.warning("WAC-006: P14_HMAC_SECRET not set")
                return False

            mock_payload = json_mod.dumps({
                "events": [{
                    "owner_id": "00000000-0000-0000-0000-000000000001",
                    "event_ts": datetime.now(WIB).isoformat(),
                    "event_type": "surveillance.wearable.health.explicit",
                    "device_id": str(uuid.uuid5(uuid.NAMESPACE_DNS, "wac-test-device")),
                    "data": {"timestamp": int(datetime.now(WIB).timestamp()), "bpm": 72},
                }],
            }).encode()

            sig = sign_payload(mock_payload, secret.encode())
            headers = {
                "X-Signature": sig,
                "Content-Type": "application/json",
            }

            async with httpx.AsyncClient() as client:
                resp = await client.post(
                    self._ingestion_url,
                    content=mock_payload,
                    headers=headers,
                    timeout=15.0,
                )
                if resp.status_code >= 300:
                    logger.warning("WAC-006 ingestion POST returned %d", resp.status_code)
                    return False

            # Verify in DB
            if self._pg is not None:
                await asyncio.sleep(2)  # allow consumer to process
                async with self._pg.acquire() as conn:
                    row = await conn.fetchrow(
                        "SELECT COUNT(*) AS cnt FROM health.heart_rate "
                        "WHERE device_id = $1",
                        str(uuid.uuid5(uuid.NAMESPACE_DNS, "wac-test-device")),
                    )
                    if row is None or row["cnt"] == 0:
                        logger.warning("WAC-006: mock event not found in DB")
                        return False

            return True
        except Exception as exc:
            logger.error("WAC-006 E2E test failed: %s", exc)
            return False

    async def _check_wac_007(self) -> bool:
        """WAC-007: First 24h data collection verified.

        Check that all hypertables have > 0 records in the last 24 hours.
        """
        if self._pg is None:
            logger.warning("WAC-007: no DB pool, skipping")
            return False
        cutoff = datetime.now(WIB) - timedelta(hours=24)
        async with self._pg.acquire() as conn:
            for table in ["heart_rate", "sleep_sessions", "spo2", "hrv"]:
                # Skip sleep_sessions (uses start_time not time column)
                col = "start_time" if table == "sleep_sessions" else "time"
                row = await conn.fetchrow(
                    f"SELECT COUNT(*) AS cnt FROM health.{table} WHERE {col} > $1",
                    cutoff,
                )
                if row is None or row["cnt"] == 0:
                    logger.warning("WAC-007: no data in health.%s for 24h", table)
                    return False
        return True

    # ── Redis Persistence ────────────────────────────

    async def _update_gate(
        self,
        gate_id: GateId,
        *,
        auto_passed: bool | None = None,
        manual_confirmed: bool | None = None,
        notes: str = "",
    ) -> None:
        """Update a single gate's state in Redis."""
        current = await self._redis.hget(REDIS_GATES_KEY, gate_id.value)
        if current:
            data = json.loads(current.decode())
        else:
            data = {"auto": False, "manual": False, "timestamp": "", "notes": ""}

        if auto_passed is not None:
            data["auto"] = auto_passed
        if manual_confirmed is not None:
            data["manual"] = manual_confirmed
        data["timestamp"] = datetime.now(WIB).isoformat()
        if notes:
            data["notes"] = notes

        await self._redis.hset(REDIS_GATES_KEY, gate_id.value, json.dumps(data))

import asyncio  # noqa: E402 — needed for WAC-006 sleep
PYEOF

## Troubleshooting

- **Issue:** `from src.surveillance.auth import sign_payload, verify_signature` fails
  - **Solution:** WAC-004 auto-check uses dynamic import with fallback. If the auth module path has changed, update the import in `_check_wac_004`. The check returns False gracefully if import fails.

- **Issue:** PostgreSQL pool is None, all DB checks skip
  - **Solution:** The `WearableActivationChecklist` constructor accepts an optional `pg_pool` parameter. Pass an `asyncpg.Pool` instance: `pool = await asyncpg.create_pool(dsn="postgresql://..."); checklist = WearableActivationChecklist(redis, pg_pool=pool)`.

- **Issue:** WAC-006 E2E test events not appearing in DB
  - **Solution:** The consumer pipeline (P14-006) may have a processing delay. The code includes a 2-second sleep after POST. Increase to 5 seconds if needed: `await asyncio.sleep(5)`. Also verify the consumer is running: `systemctl status guinevere-health`.

- **Issue:** WAC-007 shows no data for some hypertables
  - **Solution:** Some metrics (stress, body_battery) are not in the REQUIRED_HYPERTABLES list — they are supplementary. WAC-007 only checks heart_rate, sleep_sessions, spo2, and hrv. Daily tables (daily_activity, daily_summary) are excluded since they may not have data within 24h.

- **Issue:** `redis.asyncio` import fails
  - **Solution:** Requires `redis>=5.0` with async support. Install: `pip install "redis[hiredis]>=5.0"`. Verify: `python -c "import redis.asyncio; print(redis.asyncio.__name__)"`.

## Notes

- **Safety-critical:** No health data collection may begin until `all_gates_passed()` returns True. This is enforced by the consent gate in P14-007, which checks WAC state before allowing `surveillance.wearable.health.explicit` events through.
- Gate state persistence uses Redis DB2 (same DB as P7 surveillance buffer and P14-019 cooldowns). The key schema `p14:activation:` is separate from `p14:alert:cooldown:` — no collision.
- WAC-001 through WAC-006 are designed to pass immediately after their respective P14 steps are complete. WAC-007 requires 24 hours of actual data collection — this is intentionally the final gate.
- Manual confirmation is not programmable — it requires Faiz to invoke `confirm_gate()` explicitly. This ensures human-in-the-loop verification for safety-critical infrastructure.
- The `reset_all()` method exists for testing and re-verification. It clears all gate state without modifying infrastructure. Use with caution in production.
- Post-launch enhancement: add a Discord command `/wac-status` that calls `get_report()` and presents the checklist as a rich embed with ✅/❌ indicators for each gate.
- Post-launch enhancement: add a systemd `ExecStartPre` hook in `guinevere-health.service` that blocks service start unless all gates pass.
