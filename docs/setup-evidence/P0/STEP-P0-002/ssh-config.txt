## Local SSH config ACL after repair

Command:
```powershell

```

Output:

Note: Windows OpenSSH rejected the config while an inherited stale unknown SID had write/read permissions. The ACL was tightened to the owner, SYSTEM, and Administrators so OpenSSH would parse the alias.
