## Design Notes

- `jail.local` was intentionally not created because this VPS already had fail2ban and Aizanta-specific jail configuration.
- The implementation uses a late-loading `jail.d/*.local` drop-in so rollback is one file removal plus service restart.
- `ignoreip` explicitly includes localhost, VPS Tailscale IP `100.94.104.22`, and operator Windows Tailscale IP `100.112.201.124`.
- The broad Tailscale CGNAT range was not whitelisted; only known operator/VPS IPs were whitelisted.
