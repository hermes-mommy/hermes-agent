```

    time TIMESTAMPTZ NOT NULL,
    sensor_id INTEGER,
    value DOUBLE PRECISION
);

-------------------

    (NOW() - INTERVAL '1 hour', 1, 24.1);

guinevere=# SELECT count(*) FROM test_hypertable;

-------

guinevere=# DROP TABLE test_hypertable;
```
