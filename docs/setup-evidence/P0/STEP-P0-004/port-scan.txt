

This is expected because `Test-NetConnection -Port` checks TCP, while Tailscale direct connections use UDP 41641. UFW evidence for UDP 41641 is captured in `ufw-status.txt`.

## Interpretation

- SSH port 22 is reachable as required.
- Guinevere PostgreSQL target port 5433 is not reachable from the workstation.
- Guinevere Redis target port 6380 is not reachable from the workstation.
- Tailscale UDP 41641 is allowed in UFW, but this fallback probe cannot validate UDP reachability.
