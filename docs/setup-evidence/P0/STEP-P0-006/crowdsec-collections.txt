## Acquisition Notes

CrowdSec unattended setup generated SSH acquisition from host auth logs:

```yaml
# /etc/crowdsec/acquis.d/setup.sshd.yaml
filenames:
  - /var/log/auth.log
  - /var/log/secure
labels:
  type: syslog
source: file
```

The nginx collection is installed as content-ready, but no fake host nginx acquisition was created because `/var/log/nginx` does not exist on the host. Aizanta nginx runs in Docker; this step did not touch Aizanta Docker, nginx, or log configuration.
