## Cosine Distance Test

```sql
-- Create test table
CREATE TABLE IF NOT EXISTS p0_015_test (id serial PRIMARY KEY, embedding vector(3));

-- Insert test embeddings
INSERT INTO p0_015_test (embedding) VALUES ('[1,2,3]'), ('[4,5,6]');

-- Cosine distance: identical vector = 0, different vector > 0
SELECT id, embedding, embedding <=> '[1,2,3]'::vector AS cosine_distance
FROM p0_015_test ORDER BY cosine_distance;

 id | embedding | cosine_distance 
----+-----------+-----------------
  1 | [1,2,3]  |                0
  2 | [4,5,6]  | 5.196152422706632
(2 rows)

-- Cleanup
DROP TABLE p0_015_test;
```

**Result: PASS**
- Identical vector `[1,2,3] <=> [1,2,3]` = 0 (correct)
- Different vector `[4,5,6] <=> [1,2,3]` = 5.196 (expected cosine distance ≠ 0)
- `<=>` operator functional
- Table cleanup successful
