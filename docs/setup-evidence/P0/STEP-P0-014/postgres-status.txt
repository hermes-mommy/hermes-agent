## Connectivity

```
$ psql -h 127.0.0.1 -p 5433 -U guinevere -d guinevere -c "SELECT version(), current_database(), current_user, inet_server_addr();"

current_database: guinevere
current_user: guinevere

$ pg_isready -h 127.0.0.1 -p 5433 -U guinevere -d guinevere
```
