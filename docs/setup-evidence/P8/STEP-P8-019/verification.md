# P8-019 Verification — Monthly Cost Report

## What Was Done

Implemented the automated monthly cost report service (P8-019) that generates
and posts a FinOps report to the #cost-tracker Discord channel on the 1st of
each month via a Discord webhook.

## Files Changed

| File | Action | Description |
|------|--------|-------------|
| `src/core/services/monthly_report.py` | Created | Full monthly report service (536 lines) |
| `src/core/main.py` | Modified | Registered APScheduler in lifespan with start/shutdown |

## Implementation Details

### Architecture

- **APScheduler** with `AsyncIOScheduler` and `CronTrigger` (daily at 01:00 UTC / 08:00 WIB)
- Job checks `today.day == 1` before generating report
- Posts via Discord webhook URL from `DISCORD_COST_TRACKER_WEBHOOK` env var
- Graceful degradation: missing webhook or post failure logs warning, retries next cycle

### Report Contents

- **Title**: "Monthly Cost Report — {Month YYYY}"
- **Total spend**: From `cost:monthly:{YYYY-MM}` + `cost:current_month` fallback
- **vs previous month**: Compares with `cost:monthly:{prev-YYYY-MM}`
- **Per-model table**: Top models from `cost:by_model:*` keys, formatted as code block
- **Per-tool table**: Aggregated from `tool:cost:*:*` keys, formatted as code block
- **7-day trend**: Visual bar chart of last 7 days from `cost:daily:*` keys
- **Budget status**: Cap, remaining, percentage used
- **Footer**: "Generated by Guinevere FinOps"
- **Embed color**: `0x6B21A8` (purple / PRIMARY)

### Data Types (Frozen)

- `ModelCostEntry`: model name + cost
- `ToolCostEntry`: tool name + cost
- `MonthlyReportData`: complete report payload with all fields

### Scheduler Protocol

- `SchedulerProtocol`: defines `start()` and `shutdown(wait)` interface
- `register_monthly_report_scheduler()` returns `SchedulerProtocol`
- Lifespan stores scheduler in `app.state.report_scheduler`
- Graceful shutdown: `report_scheduler.shutdown(wait=False)` before other cleanup

### Webhook Integration

- Uses `httpx.AsyncClient` for async HTTP POST
- JSON payload: `{"content": formatted_markdown_string}`
- 30-second timeout
- Error logging with structlog

## Boundary Compliance

- No persona drift: professional FinOps tone for reports
- No consent violation: webhook-based posting (no surveillance data)
- No secret exposure: webhook URL from env var, never logged
- No surveillance data in report: cost data only
- Graceful degradation: never crashes the main app on failure

## Caveats

- Model/tool breakdowns use running Redis totals (`cost:by_model:*`, `tool:cost:*`) which
  are not month-scoped. For precise historical month breakdowns, a future enhancement
  could add month-scoped aggregation keys.
- APScheduler and httpx must be available at runtime (both are in pyproject.toml).
