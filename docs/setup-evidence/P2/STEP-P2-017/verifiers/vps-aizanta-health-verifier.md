```bash
# Verify Aizanta core is running

```

### 2. Critical Port Availability

| Port | Service | Required |
|------|---------|----------|
| **5433** | PostgreSQL 16 | ✅ Must be listening |
| **5434** | PgBouncer | ✅ Must be listening |
| **6380** | Redis 7 | ✅ Must be listening |
| **20128** | 9Router (Node.js) | ✅ Must be listening |

```bash
# Quick port check
ss -tlnp | grep -E '5433|5434|6380|20128'
```

### 3. System Resource Health

```bash
# CPU usage — should be <50% idle drain
top -bn1 | grep "Cpu(s)"

# RAM usage — should be <50% of 16GB
free -h
```

### 4. Secrets Readiness

```bash
# SOPS age key must exist for decryption
ls -la /home/guinevere/.config/sops/age/keys.txt

# Test decrypt
sops decrypt /home/guinevere/secrets/discord-secrets.yaml --output /dev/null
```

### 5. Existing Guinevere Services

```bash
# Verify no service conflicts
systemctl list-units --type=service | grep guinevere

# Core service must be running
systemctl status guinevere-core
```

### 6. Network Isolation

```bash
# Confirm Docker network separation
docker network ls | grep guinevere-net
docker network inspect guinevere-net
```

### 7. Complete Verification Command

