### Step P12-013: Memory Store Integration

**Goal:** Store email episodes in Guinevere memory with proper classification, importance scoring, rule-based tags, and summary-only body storage — with full body encrypted in a separate PostgreSQL table using pgsodium.
**Dependencies:** P12-011 (Content Sanitizer), P12-012 (Secret Scanner — redacted content safe for storage).
**ADR References:** ADR-004 (Memory Schema — 47 tables across 12 schemas), ADR-006 (Data Classification — 5-tier system).
**Estimated Time:** 5 hours

#### Context

Guinevere's memory system — 47 tables across 12 schemas — stores episodes, conversations, entities, and relationships. The `store_episode()` function is the primary write interface. Email episodes must integrate seamlessly while respecting data classification.

Faiz decided:
- **Default classification: Confidential** for all email data
- **Auto-escalate to Restricted** for FINANCIAL, BILLING_INVOICE, CLIENT_WORK categories
- **Summary-only in memory**: LLM-generated 2-3 sentence summary in episodes table
- **Full body encrypted**: separate `email_archive` table with pgsodium TCE
- **Tags rule-based** for speed: `["email", f"sender:{domain}", f"category:{cat}", f"thread:{thread_id}"]`
- **Importance score** from ImportanceScorer (P12-010)

**Classification Tiers:**

| Tier | Level | Email Application |
|---|---|---|
| Public | 1 | Never for email |
| Internal | 2 | Never for email |
| Confidential | 3 | Default for all email |
| Restricted | 4 | FINANCIAL, BILLING_INVOICE, CLIENT_WORK |
| Critical | 5 | Security incidents only |

**Recall Integration:** Email episodes searchable via hybrid retrieval (vector similarity + full-text search + recency weighting, RRF k=60).

**Encrypted Full Body Storage:** Separate `email_archive` table with pgsodium Transparent Column Encryption (TCE) — per-row key IDs, AEAD authenticated encryption, auto-generated decrypted views.

```python
# File: src/gmail/memory/email_memory_store.py
import hashlib, logging
from dataclasses import dataclass
from datetime import datetime, timezone
from typing import Any, Optional

logger = logging.getLogger("gmail.memory")

RESTRICTED_CATEGORIES = {"FINANCIAL", "BILLING_INVOICE", "CLIENT_WORK"}
CLASSIFICATION_MAP = {
    "CLIENT_WORK": "Restricted", "FINANCIAL": "Restricted", "BILLING_INVOICE": "Restricted",
    "IMPORTANT": "Confidential", "NEWSLETTER": "Confidential", "PROMOTION": "Confidential",
    "TRANSACTIONAL": "Confidential", "SPAM_PHISHING": "Confidential",
}

@dataclass
class EmailEpisode:
    content: str  # 2-3 sentence summary
    source: str = "gmail"
    classification: str = "Confidential"
    importance: float = 0.0
    title: str = ""
    episode_type: str = "email"
    tags: list[str] | None = None
    metadata: dict[str, Any] | None = None
    content_hash: str = ""

class EmailMemoryStore:
    """Store email episodes in Guinevere memory with classification escalation,
    rule-based tags, summary-only body, and encrypted full body archive."""

    def __init__(self, db_pool, episode_store_fn, embedding_service=None,
                 summarizer=None, redis_client=None):
        self.db = db_pool
        self.store_episode = episode_store_fn
        self.summarizer = summarizer
        self.redis = redis_client

    async def store_email(self, redacted_content, sender, subject, thread_id,
                          message_id, category, importance_score, labels,
                          cc=None, delivery_status="delivered", raw_html=None,
                          received_at=None) -> Optional[str]:
        """Store email as episode + encrypted archive. Returns episode ID."""
        content_hash = hashlib.sha256(f"{message_id}:{subject}".encode()).hexdigest()
        if await self._is_duplicate(content_hash, message_id):
            logger.info(f"Duplicate skipped: {message_id}"); return None

        summary = await self._generate_summary(redacted_content, subject, sender)
        classification = CLASSIFICATION_MAP.get(category, "Confidential")
        sender_domain = sender.split("@")[1].lower() if "@" in sender else "unknown"
        tags = self._generate_tags(sender_domain, category, thread_id, labels)
        metadata = {
            "from": sender, "thread_id": thread_id, "subject": subject,
            "labels": labels, "cc": cc or [], "delivery_status": delivery_status,
            "category": category, "message_id": message_id,
        }
        episode = EmailEpisode(content=summary, classification=classification,
            importance=importance_score, title=subject, tags=tags,
            metadata=metadata, content_hash=content_hash)
        episode_id = await self._store_episode(episode)
        if raw_html:
            await self._store_encrypted_archive(
                message_id, hashlib.sha256(sender.encode()).hexdigest()[:16],
                subject, raw_html, received_at or datetime.now(timezone.utc),
                {"thread_id": thread_id, "labels": labels})
        await self._cache_for_dedup(content_hash, message_id)
        logger.info(f"Stored: id={episode_id}, class={classification}, imp={importance_score}")
        return episode_id

    async def _generate_summary(self, content, subject, sender):
        if self.summarizer:
            try:
                return (await self.summarizer.generate(
                    f"Summarize in 2-3 sentences. Sender: {sender}. Subject: {subject}.\n{content[:3000]}",
                    max_tokens=150)).strip()
            except Exception as e: logger.error(f"LLM summary failed: {e}")
        sentences = content.replace("\n", " ").split(". ")
        return ". ".join(sentences[:2]) + "." if sentences else content[:200]

    def _generate_tags(self, domain, category, thread_id, labels):
        tags = ["email", f"sender:{domain}", f"category:{category.lower()}"]
        if thread_id: tags.append(f"thread:{thread_id}")
        for l in labels:
            if l in {"Important", "Starred", "SENT"}: tags.append(f"label:{l.lower()}")
        return tags

    async def _store_episode(self, episode):
        try:
            result = await self.store_episode(
                content=episode.content, source=episode.source,
                classification=episode.classification, importance=episode.importance,
                title=episode.title, episode_type=episode.episode_type,
                tags=episode.tags, metadata=episode.metadata)
            return result.get("id") if isinstance(result, dict) else str(result)
        except Exception as e: logger.error(f"Episode store failed: {e}"); return None

    async def _store_encrypted_archive(self, msg_id, sender_hash, subject, body, received_at, meta):
        async with self.db.acquire() as conn:
            await conn.execute("""
                INSERT INTO private.email_archive
                    (gmail_message_id, sender_hash, received_at, subject_encrypted, body_encrypted, metadata)
                VALUES ($1,$2,$3,$4,$5,$6)
                ON CONFLICT (gmail_message_id) DO UPDATE SET body_encrypted = EXCLUDED.body_encrypted
            """, msg_id, sender_hash, received_at, subject, body, meta)

    async def _is_duplicate(self, content_hash, message_id):
        if self.redis and await self.redis.exists(f"gmail:dedup:{message_id}"): return True
        try:
            async with self.db.acquire() as conn:
                return (await conn.fetchrow(
                    "SELECT 1 FROM private.email_archive WHERE gmail_message_id=$1", message_id)) is not None
        except: return False

    async def _cache_for_dedup(self, content_hash, message_id):
        if self.redis: await self.redis.setex(f"gmail:dedup:{message_id}", 7*24*3600, content_hash)
```

```sql
-- File: migrations/p12/email_archive.sql
CREATE EXTENSION IF NOT EXISTS pgsodium;
CREATE SCHEMA IF NOT EXISTS private;
CREATE TABLE IF NOT EXISTS private.email_archive (
    id bigserial PRIMARY KEY,
    gmail_message_id text NOT NULL UNIQUE,
    sender_hash text NOT NULL,
    received_at timestamptz NOT NULL DEFAULT now(),
    subject_encrypted text,
    body_encrypted text,
    key_id uuid REFERENCES pgsodium.key(id) DEFAULT (pgsodium.create_key()).id,
    nonce bytea DEFAULT pgsodium.crypto_aead_det_noncegen(),
    metadata jsonb DEFAULT '{}'::jsonb,
    created_at timestamptz NOT NULL DEFAULT now()
);
SECURITY LABEL FOR pgsodium ON COLUMN private.email_archive.subject_encrypted
    IS 'ENCRYPT WITH KEY COLUMN key_id NONCE nonce ASSOCIATED (id, gmail_message_id)';
SECURITY LABEL FOR pgsodium ON COLUMN private.email_archive.body_encrypted
    IS 'ENCRYPT WITH KEY COLUMN key_id NONCE nonce ASSOCIATED (id, gmail_message_id)';
CREATE INDEX idx_email_archive_msg ON private.email_archive (gmail_message_id);
CREATE INDEX idx_email_archive_recv ON private.email_archive (received_at);
ALTER TABLE private.email_archive ENABLE ROW LEVEL SECURITY;
CREATE POLICY guinevere_email ON private.email_archive FOR ALL TO guinevere_service_role USING (true);
-- Retention: DELETE WHERE received_at < now() - interval '7 days' (daily cron)
```

#### Troubleshooting

- **pgsodium not available**: Install from PGXN (PostgreSQL 14+, libsodium). Fallback: Python `cryptography.fernet` app-level encryption.
- **store_episode() signature mismatch**: Check actual API. Adapt parameter names. Document mapping in evidence.
- **LLM summarization slow (>2s)**: Use DeepSeek V4 Flash. Skip LLM for importance < 3, use first-2-sentences fallback.
- **Too many email episodes in retrieval**: Add filter `episode_type = 'email'`. Adjust RRF k if emails drown other types.
- **Redis dedup evicts early**: Use dedicated DB6 with `maxmemory-policy noeviction`. DB-level dedup as authoritative source.
- **Archive table grows fast**: Run retention cleanup every 6 hours via pg_cron instead of daily.

#### Notes

- **Summary vs Full Body Split**: Episodes store summaries (searchable, useful without decryption). Full bodies encrypted in archive (defense-in-depth).
- **pgsodium vs App Encryption**: pgsodium preferred (root key never leaves PostgreSQL server). App-level encryption has larger attack surface.
- **Data Classification**: All email minimum Confidential per SurveillanceDataPolicy. Classification field enforces recall access control.
- **Tag Performance**: Rule-based <1ms vs 500-2000ms LLM tags. For 100-300 emails/day, saves 50-600s cumulative latency.
- **Cross-Reference P12-010**: Importance scores from ImportanceScorer. Default 5.0 if not operational.
- **Cross-Reference P12-014**: Financial metadata appended to episode metadata after FinancialEmailExtractor runs.
