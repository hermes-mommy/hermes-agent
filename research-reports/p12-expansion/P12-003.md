**Estimated Time:** 2 hours

#### Context

Resend is a transactional email API separate from Gmail API. It serves three purposes in Guinevere: (1) invoice sending linked to P9 Financial Tracking (structured invoice data → formatted email to clients), (2) project notifications (deployment alerts, task completion summaries), and (3) fallback when Gmail API is experiencing outages or quota exhaustion. The `RESEND_API_KEY` already exists in the deployment configuration from prior setup — this step wraps it in a proper client with templates, rate limiting, and monitoring.

Resend is chosen over alternatives (SendGrid, Mailgun, SES) because: (a) it has a modern Python SDK with type hints, (b) free tier is generous for single-user (100 emails/day), (c) API is simple (single POST endpoint), (d) supports HTML emails with attachments, and (e) already provisioned (`RESEND_API_KEY` exists).

The `ResendClient` wrapper provides: template rendering (Jinja2 for HTML emails), rate limiting (token bucket to stay within Resend API limits), structured error handling with Discord alerts, and Prometheus metrics for observability. This is a simpler module than the Gmail API client (P12-004) — Resend is send-only, no inbox reading.

After this step, Guinevere can: (1) send HTML emails via Resend API, (2) render invoice/notification templates, (3) respect rate limits automatically, (4) alert Faiz on Discord if sending fails, and (5) export metrics to Prometheus.

# src/gmail/resend_client.py

"""
ResendClient: Transactional email wrapper for Resend API.
Features: template rendering, rate limiting, error handling, Prometheus metrics.
"""
import time
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any

import jinja2
import resend
import structlog
from prometheus_client import Counter, Histogram

logger = structlog.get_logger(__name__)

# Prometheus metrics
resend_emails_sent = Counter("resend_emails_sent_total", "Total emails sent via Resend", ["template"])
resend_emails_failed = Counter("resend_emails_failed_total", "Total failed Resend sends", ["error_type"])
resend_send_latency = Histogram("resend_send_latency_seconds", "Resend API call latency")

@dataclass
class RateLimiter:
    """Token bucket rate limiter for Resend API (100 emails/day free tier)."""
    max_tokens: float = 100.0
    refill_rate: float = 100.0 / 86400.0  # tokens per second (100/day)
    tokens: float = field(default_factory=lambda: 100.0)
    last_refill: float = field(default_factory=time.time)

    def acquire(self) -> bool:
        """Try to acquire a token. Returns False if rate limited."""
        now = time.time()
        elapsed = now - self.last_refill
        self.tokens = min(self.max_tokens, self.tokens + elapsed * self.refill_rate)
        self.last_refill = now

        if self.tokens >= 1.0:
            self.tokens -= 1.0
            return True
        return False


class ResendClient:
    """Transactional email client with template rendering and rate limiting."""

    def __init__(
        self,
        api_key: str | None = None,
        template_dir: str = "src/gmail/templates",
        default_from: str = "Guinevere <onboarding@resend.dev>",
    ):
        self.template_dir = Path(template_dir)
        self.default_from = default_from
        self.rate_limiter = RateLimiter()

        # Initialize Resend SDK
        if api_key:
            resend.api_key = api_key
        logger.info("resend.client_initialized", template_dir=str(self.template_dir))

        # Jinja2 template environment
        self._jinja_env = jinja2.Environment(
            loader=jinja2.FileSystemLoader(str(self.template_dir)),
            autoescape=jinja2.select_autoescape(["html"]),
        )

    def send_email(
        self,
        to: str | list[str],
        subject: str,
        html: str | None = None,
        template: str | None = None,
        template_context: dict[str, Any] | None = None,
        attachments: list[dict] | None = None,
    ) -> dict[str, str]:
        """
        Send an email via Resend API.

        Args:
            to: Recipient email(s)
            subject: Email subject line
            html: Raw HTML content (mutually exclusive with template)
            template: Template filename to render (mutually exclusive with html)
            template_context: Variables for template rendering
            attachments: List of attachment dicts [{filename, content (base64), content_type}]

        Returns:
            Resend API response dict with 'id' key

        Raises:
            RateLimitError: If daily rate limit exceeded
            TemplateError: If template not found or rendering fails
            resend.exceptions.ResendError: If API call fails
        """
        # Rate limit check
        if not self.rate_limiter.acquire():
            resend_emails_failed.labels(error_type="rate_limited").inc()
            logger.error("resend.rate_limited", to=to, subject=subject)
            raise RateLimitError("Resend daily rate limit exceeded (100 emails/day)")

        # Resolve HTML content
        if template and not html:
            html = self._render_template(template, template_context or {})
        elif not html:
            raise ValueError("Either 'html' or 'template' must be provided")

        # Build request
        to_list = [to] if isinstance(to, str) else to
        params: dict[str, Any] = {
            "from": self.default_from,
            "to": to_list,
            "subject": subject,
            "html": html,
        }

        if attachments:
            params["attachments"] = attachments

        # Send with metrics
        with resend_send_latency.time():
            try:
                response = resend.Emails.send(params)
                template_name = template or "raw_html"
                resend_emails_sent.labels(template=template_name).inc()
                logger.info(
                    "resend.email_sent",
                    to=to_list,
                    subject=subject,
                    template=template_name,
                    message_id=response.get("id"),
                )
                return response
            except Exception as e:
                resend_emails_failed.labels(error_type=type(e).__name__).inc()
                logger.error("resend.send_failed", to=to_list, subject=subject, error=str(e))
                raise

    def _render_template(self, template_name: str, context: dict[str, Any]) -> str:
        """Render a Jinja2 HTML template with given context."""
        tmpl = self._jinja_env.get_template(template_name)
        return tmpl.render(**context)

    def send_test_email(self, to: str) -> dict[str, str]:
        """Send a test email to verify Resend connectivity."""
        return self.send_email(
            to=to,
            subject="🔧 Guinevere Resend Test",
            html="<h1>Test Successful</h1><p>Resend API is working correctly.</p>",
        )


class RateLimitError(Exception):
    """Raised when Resend daily rate limit is exceeded."""
    pass

#### Troubleshooting

- **Issue:** `resend.Emails.send()` returns 401 Unauthorized
  - **Solution:** API key is invalid or revoked. Generate a new key at resend.com/api-keys, SOPS-encrypt, and redeploy. Verify key format: should start with `re_`.
- **Issue:** `resend.Emails.send()` returns 403 "domain not verified"
  - **Solution:** The `from` address domain must be verified in Resend dashboard. For testing, use `onboarding@resend.dev` (works without verification). For production, verify the custom domain at resend.com/domains.
- **Issue:** `Jinja2 TemplateNotFound` error
  - **Solution:** Verify template files exist in `src/gmail/templates/`. Check file permissions. Ensure `template_dir` path in `ResendClient.__init__` is correct relative to the working directory.
- **Issue:** Rate limiter blocks all sends immediately
  - **Solution:** The `RateLimiter` initializes with 100 tokens (full capacity). If it blocks immediately, check that `last_refill` timestamp is being set correctly. Reset by creating a new `RateLimiter()` instance.
- **Issue:** `pip install resend` fails with version conflict
  - **Solution:** Resend SDK requires `httpx>=0.27.0`. If there's a conflict with another dependency, run `uv lock --upgrade-package resend` to resolve. Check `uv pip tree | grep resend` for the conflict path.

#### Notes

- **Resend vs Gmail API:** These are completely separate systems. Resend is for **sending** transactional emails (outbound only). Gmail API is for **reading** inbox and managing drafts (inbound + draft). They do not share credentials, tokens, or API keys.
- **Free Tier Limits:** Resend free tier: 100 emails/day, 3,000 emails/month. For single-user use with invoices and notifications, this is more than sufficient. If volume grows, the paid plan starts at $20/month for 50,000 emails.
- **Sender Address:** Testing uses `onboarding@resend.dev` which Resend provides for unverified accounts. For production, verify a custom domain and use `guinevere@[domain].com` as the sender. This requires DNS TXT record configuration.
- **Template System:** Jinja2 templates are stored in `src/gmail/templates/` alongside the code. They are NOT user-editable (no CMS). New templates require code changes and deployment.
- **Cross-Reference P9:** The invoice template (`invoice.html`) is designed to integrate with P9 Financial Tracking. When P9 generates invoice data, it passes structured fields (invoice_number, line_items, total_amount) to `ResendClient.send_email(template="invoice.html", template_context={...})`.
- **Cross-Reference P12-004:** When Gmail API is experiencing outages (403 quota exceeded, 500 internal errors), the draft reply pipeline can fall back to Resend for sending. The `ResendClient` provides the send capability while `GmailClient` (P12-004) handles inbox reading and draft management.
- **Attachments:** Resend supports attachments up to 25MB per email. Attachments are base64-encoded and included in the API request body. For invoice PDFs, convert to base64 before passing to `send_email()`.
