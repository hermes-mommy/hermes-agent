**Type:** Application

**Acceptance Criteria:** AC-EMAIL-001 (Gmail connected, OAuth valid), AC-EMAIL-002 (Emails classified within 5s — latency foundation).
**Estimated Time:** 3 hours

#### Context

The Gmail API (`google-api-python-client`) provides REST endpoints for reading emails, managing labels, creating drafts, and setting up push notifications. The raw API client is verbose and error-prone — every call requires credential management, pagination handling, quota awareness, and specific error handling for 401 (token expired), 403 (quota exceeded), and 404 (historyId expired). The `GmailClient` wrapper abstracts all of this into clean Python methods that downstream steps consume.

Gmail API quota: 6,000 units/min/user. Operation costs: `messages.list` = 5 units, `messages.get` = 5, `history.list` = 2, `drafts.create/send` = 25, `users.watch` = 100. The wrapper tracks cumulative usage and exposes it as a Prometheus gauge, warning at 80% and raising `QuotaExceededError` at 95%.

The wrapper is synchronous by default (matching `googleapiclient`'s design) but provides an `AsyncGmailClient` thin wrapper using `asyncio.to_thread()` for non-blocking integration with Guinevere's async-first architecture.

# src/gmail/gmail_client.py

"""GmailClient: Wrapper around Google Gmail API with quota tracking,
error handling, and credential management via TokenManager."""
import base64, time
from dataclasses import dataclass
from typing import Any, Generator

import structlog
from googleapiclient.discovery import Resource, build
from googleapiclient.errors import HttpError
from prometheus_client import Counter, Gauge, Histogram
from src.gmail.token_manager import TokenManager

logger = structlog.get_logger(__name__)

# Prometheus metrics
gmail_api_calls = Counter("gmail_api_calls_total", "API calls by method/status", ["method","status"])
gmail_api_quota = Gauge("gmail_api_quota_usage", "Current quota usage (units/min, max 6000)")
gmail_api_latency = Histogram("gmail_api_latency_seconds", "API latency by method", ["method"])
gmail_api_errors = Counter("gmail_api_errors_total", "Errors by HTTP status", ["error_type"])

# Quota costs per operation (~Google docs)
QUOTA: dict[str, int] = {
    "messages.list": 5, "messages.get": 5, "messages.modify": 10,
    "history.list": 2, "labels.list": 1, "threads.get": 10,
    "drafts.create": 25, "drafts.send": 25, "drafts.update": 25,
    "users.getProfile": 1, "users.watch": 100, "users.stop": 50,
}
QUOTA_LIMIT = 6000; WARN_AT = 0.80; CRITICAL_AT = 0.95

# Typed exceptions
class GmailClientError(Exception): pass
class QuotaExceededError(GmailClientError): pass
class TokenExpiredError(GmailClientError): pass
class HistoryExpiredError(GmailClientError): pass

@dataclass
class GmailMessage:
    """Parsed Gmail message with extracted fields."""
    id: str; thread_id: str; subject: str; from_addr: str
    to_addrs: list[str]; cc_addrs: list[str]; date: str
    snippet: str; labels: list[str]; body_plain: str | None
    body_html: str | None; has_attachments: bool; raw_payload: dict[str, Any]

class GmailClient:
    """Synchronous Gmail API wrapper. Methods: list_messages, get_message,
    list_history, list_labels, get_thread, create_draft, send_draft,
    watch, stop_watch, get_profile. All with quota tracking + error handling."""

    def __init__(self, token_manager: TokenManager):
        self.tm = token_manager
        self._svc: Resource | None = None
        self._quota_used = 0; self._quota_window = time.time()

    @property
    def service(self) -> Resource:
        if self._svc is None:
            self._svc = build("gmail","v1",credentials=self.tm.get_credentials(),cache_discovery=False)
        assert self._svc is not None, "Service build failed"
        return self._svc

    def _track(self, method: str):
        cost = QUOTA.get(method, 5)
        if time.time() - self._quota_window >= 60: self._quota_used = 0; self._quota_window = time.time()
        self._quota_used += cost; gmail_api_quota.set(self._quota_used)
        ratio = self._quota_used / QUOTA_LIMIT
        if ratio >= CRITICAL_AT: raise QuotaExceededError(f"{self._quota_used}/{QUOTA_LIMIT}")
        if ratio >= WARN_AT: logger.warning("gmail.quota", used=self._quota_used)

    def _exec(self, method: str, request) -> Any:
        self._track(method)
        with gmail_api_latency.labels(method=method).time():
            try:
                r = request.execute(); gmail_api_calls.labels(method=method,status="success").inc()
                return r
            except HttpError as e:
                gmail_api_calls.labels(method=method,status="error").inc()
                gmail_api_errors.labels(error_type=str(e.status_code)).inc()
                if e.status_code == 401: raise TokenExpiredError(f"401 on {method}")
                if e.status_code == 403: raise QuotaExceededError(f"403 on {method}")
                if e.status_code == 404 and "history" in method: raise HistoryExpiredError(f"historyId expired: {method}")
                raise GmailClientError(f"HTTP {e.status_code} on {method}: {e}")

    # --- Message Operations ---
    def list_messages(self, query="", label_ids=None, max_results=100, page_token=None) -> dict:
        params = {"userId":"me","maxResults":min(max_results,500)}
        if query: params["q"] = query
        if label_ids: params["labelIds"] = label_ids
        if page_token: params["pageToken"] = page_token
        return self._exec("messages.list", self.service.users().messages().list(**params))

    def get_message(self, message_id: str, format="full") -> GmailMessage:
        raw = self._exec("messages.get", self.service.users().messages().get(userId="me",id=message_id,format=format))
        return self._parse(raw)

    def _parse(self, raw: dict) -> GmailMessage:
        headers = {h["name"].lower(): h["value"] for h in raw.get("payload",{}).get("headers",[])}
        plain, html = self._body(raw.get("payload",{}))
        return GmailMessage(id=raw["id"], thread_id=raw["threadId"],
            subject=headers.get("subject","(no subject)"), from_addr=headers.get("from",""),
            to_addrs=[a.strip() for a in headers.get("to","").split(",") if a.strip()],
            cc_addrs=[a.strip() for a in headers.get("cc","").split(",") if a.strip()],
            date=headers.get("date",""), snippet=raw.get("snippet",""), labels=raw.get("labelIds",[]),
            body_plain=plain, body_html=html, has_attachments=self._att(raw.get("payload",{})),
            raw_payload=raw)

    def _body(self, payload: dict) -> tuple[str|None, str|None]:
        plain, html = None, None
        if "parts" in payload:
            for p in payload["parts"]:
                if "parts" in p: sp, sh = self._body(p); plain=plain or sp; html=html or sh
                elif p.get("mimeType")=="text/plain": plain = base64.b64decode(p["body"]["data"]).decode() if p.get("body",{}).get("data") else None
                elif p.get("mimeType")=="text/html": html = base64.b64decode(p["body"]["data"]).decode() if p.get("body",{}).get("data") else None
        elif payload.get("body",{}).get("data"):
            d = base64.b64decode(payload["body"]["data"]).decode()
            if payload.get("mimeType")=="text/plain": plain = d
            else: html = d
        return plain, html

    def _att(self, payload: dict) -> bool:
        if payload.get("filename"): return True
        return any(self._att(p) for p in payload.get("parts",[]))

    # --- History Operations ---
    def list_history(self, start_history_id: str, label_id=None, history_types=None, max_results=500) -> dict:
        """List changes since start_history_id. IMPORTANT: use OLD historyId (counter-intuitive but correct)."""
        params = {"userId":"me","startHistoryId":start_history_id,"maxResults":max_results}
        if label_id: params["labelId"] = label_id
        if history_types: params["historyTypes"] = history_types
        return self._exec("history.list", self.service.users().history().list(**params))

    # --- Label Operations ---
    def list_labels(self) -> list[dict]:
        return self._exec("labels.list", self.service.users().labels().list(userId="me")).get("labels",[])

    # --- Thread Operations ---
    def get_thread(self, thread_id: str, format="full") -> dict:
        return self._exec("threads.get", self.service.users().threads().get(userId="me",id=thread_id,format=format))

    # --- Draft Operations ---
    def create_draft(self, to: str, subject: str, body_html: str, thread_id=None) -> dict:
        from email.mime.text import MIMEText
        msg = MIMEText(body_html,"html"); msg["to"]=to; msg["subject"]=subject
        body = {"message":{"raw": base64.urlsafe_b64encode(msg.as_bytes()).decode()}}
        if thread_id: body["message"]["threadId"] = thread_id
        return self._exec("drafts.create", self.service.users().drafts().create(userId="me",body=body))

    def send_draft(self, draft_id: str) -> dict:
        return self._exec("drafts.send", self.service.users().drafts().send(userId="me",body={"id":draft_id}))

    # --- Watch Operations ---
    def watch(self, topic_name: str, label_ids=None) -> dict:
        """Set up Pub/Sub push notifications. Returns {historyId, expiration}.
        Must renew every 7 days (watch expiry)."""
        body = {"topicName":topic_name,"labelFilterAction":"include"}
        if label_ids: body["labelIds"] = label_ids
        return self._exec("users.watch", self.service.users().watch(userId="me",body=body))

    def stop_watch(self) -> None:
        self._exec("users.stop", self.service.users().stop(userId="me"))

    # --- Profile ---
    def get_profile(self) -> dict:
        return self._exec("users.getProfile", self.service.users().getProfile(userId="me"))

    # --- Pagination Helper ---
    def list_all_messages(self, query="", label_ids=None, max_total=1000) -> Generator[GmailMessage, None, None]:
        """Generator that paginates through all matching messages."""
        page_token = None; fetched = 0
        while fetched < max_total:
            r = self.list_messages(query=query,label_ids=label_ids,
                                   max_results=min(500,max_total-fetched),page_token=page_token)
            for stub in r.get("messages",[]):
                yield self.get_message(stub["id"]); fetched += 1
                if fetched >= max_total: break
            page_token = r.get("nextPageToken")
            if not page_token: break

# src/gmail/async_client.py
"""AsyncGmailClient: Non-blocking wrapper using asyncio.to_thread()."""
import asyncio
from typing import Any
from src.gmail.gmail_client import GmailClient, GmailMessage
from src.gmail.token_manager import TokenManager

class AsyncGmailClient:
    def __init__(self, tm: TokenManager): self._c = GmailClient(tm)

    async def list_messages(self, **kw) -> dict: return await asyncio.to_thread(self._c.list_messages, **kw)
    async def get_message(self, mid: str) -> GmailMessage: return await asyncio.to_thread(self._c.get_message, mid)
    async def list_history(self, shid: str, **kw) -> dict: return await asyncio.to_thread(self._c.list_history, shid, **kw)
    async def list_labels(self) -> list[dict]: return await asyncio.to_thread(self._c.list_labels)
    async def get_thread(self, tid: str) -> dict: return await asyncio.to_thread(self._c.get_thread, tid)
    async def create_draft(self, to, subject, html, tid=None) -> dict: return await asyncio.to_thread(self._c.create_draft, to, subject, html, tid)
    async def send_draft(self, did: str) -> dict: return await asyncio.to_thread(self._c.send_draft, did)
    async def watch(self, topic: str, **kw) -> dict: return await asyncio.to_thread(self._c.watch, topic, **kw)
    async def stop_watch(self) -> None: return await asyncio.to_thread(self._c.stop_watch)
    async def get_profile(self) -> dict: return await asyncio.to_thread(self._c.get_profile)

#### Troubleshooting

- **Issue:** `build("gmail","v1")` raises `UnknownApiError` — Gmail API not enabled
  - **Solution:** `gcloud services enable gmail.googleapis.com --project=guinevere-gmail-prod`
- **Issue:** `HttpError 403: "Daily Limit Exceeded"` — billing likely not linked
  - **Solution:** `gcloud billing projects describe guinevere-gmail-prod`. If billing disabled, link billing account. Free tier covers 1B calls/day.
- **Issue:** `HttpError 403: "Insufficient Permission"` on writes — scopes wrong
  - **Solution:** Ensure token includes `gmail.modify`. Re-run `!email-reauth` with correct scopes.
- **Issue:** `HttpError 404` on `history.list` even with recent historyId
  - **Solution:** historyId expires after ~7 days. Perform full sync (list messages) to get new historyId. P12-005 handles this automatically.
- **Issue:** `asyncio.to_thread()` hangs under load
  - **Solution:** Default thread pool size is 5. Single-user email volume won't saturate this. If needed: `asyncio.get_event_loop().set_default_executor()`.

#### Notes

- **Quota Guard:** The `_track()` method raises `QuotaExceededError` at 95% usage to prevent actual 403 responses from Google. This gives the caller time to back off.
- **`cache_discovery=False`:** Set because discovery document caching causes issues in long-running services. Acceptable since service rebuilds occur only on token refresh or startup.
- **`assert self._svc is not None` on `service` property:** `_svc` is `None | Resource` and property guarantees non-None after `_build_service()`. Assert narrows type for mypy without suppression.
- **Cross-Reference P12-005:** Sync engine uses `list_history()` with counter-intuitive `startHistoryId=OLD_ID`. `HistoryExpiredError` triggers full sync fallback.
- **Cross-Reference P12-008:** Draft pipeline uses `create_draft()` → Faiz approves in Discord → `send_draft()`.
- **Thread Safety:** `GmailClient` is NOT thread-safe. Each thread needs its own instance. `AsyncGmailClient` delegates to thread pool safely — `httplib2` handles connection-level threading.
