### Step P12-012: Secret Scanner + PII Redactor

**Goal:** Scan sanitized email content for secrets (API keys, tokens, passwords via 1100+ TruffleHog rules) and PII (emails, phones, KTP, credit cards), alert Faiz via Discord, and redact detected items from memory storage before LLM processing.
**Dependencies:** P12-011 (Content Sanitizer — receives sanitized content as input).
**ADR References:** ADR-018 (Security Policy — secrets must not reach LLM), PersonaSafetyPolicy (surveillance data — PII in email requires redaction).
**Estimated Time:** 6 hours

#### Context

Email bodies are a common vector for accidental secret exposure (forwarded error logs with API keys, shared credentials, OAuth tokens in automated notifications) and PII leakage (credit cards in receipts, KTP in government correspondence). Guinevere's memory stores email summaries — if secrets or PII are not redacted before storage, they persist and could surface in future recall contexts.

Faiz decided: **scan + alert + redact from memory.** Secrets found -> Discord alert + redact. PII found -> Discord alert + redact. Neither secrets nor PII are passed to the LLM.

**Detection Architecture — Two Parallel Scanners:**

| Scanner | Library | Coverage | Performance |
|---|---|---|---|
| Secret Scanner | `@sanity-labs/secret-scan` (Python wrapper/subprocess) | 1100+ TruffleHog rules | ~0.15ms per scan |
| PII Scanner | `datafog` (Rust core) + custom regex | Emails, phones, KTP, CC, NPWP, bank accounts | Microseconds per KB |

**Secret Categories:** Cloud keys (AWS AKIA, GCP SA JSON, Azure AccountKey), API tokens (GitHub ghp_/gho_/github_pat_, GitLab glpat-, OpenAI sk-proj-, Stripe sk_live_), auth tokens (Bearer, JWT eyJ, OAuth refresh), private keys (PEM, SSH, PGP), connection strings (postgres://, mongodb://, redis://), platform secrets (Discord bot tokens, Slack xoxb-, SendGrid SG.), high-entropy strings (Shannon >= 3.5 bits/char for 32+ chars near keywords).

**PII Categories (Indonesian-context aware):**

| Category | Detection | Indonesian Specific |
|---|---|---|
| Email addresses | RFC 5322 regex + TLD validation | — |
| Phone numbers | +62 prefix, 08xx mobile format | Yes |
| KTP (National ID) | 16-digit: province(2)+city(2)+DOB(6)+seq(4) | Yes |
| Credit cards | Luhn algorithm validation | — |
| Bank accounts | BCA 10-digit, Mandiri 13-digit, BRI 15-digit | Yes |
| NPWP (Tax ID) | 15-digit: XX.XXX.XXX.X-XXX.XXX | Yes |

**Action Flow:** Secret/PII Found -> Redact [REDACTED:TYPE] in content -> Discord Alert (type, sender hash, subject hash — NOT the value) -> Log metadata only -> Metrics: `gmail_secrets_detected_total{type}`, `gmail_pii_detected_total{type}`

**Whitelist:** Guinevere's own API endpoints, Discord webhook URLs, internal service URLs (localhost, Tailscale), known tracking pixels.

```python
    ("github_token", "GitHub Token", re.compile(r'(ghp|gho|ghu|ghs|ghr)_[A-Za-z0-9_]{36,}')),

    ("postgres_uri", "PostgreSQL URI", re.compile(r'postgres(?:ql)?://[^\s]{10,}')),

def shannon_entropy(data: str) -> float:
    if not data: return 0.0
    counter = Counter(data); length = len(data)
    return -sum((c/length) * math.log2(c/length) for c in counter.values() if c > 0)

@dataclass
class SecretFinding:
    rule_name: str; rule_description: str; redacted_value: str
    start_pos: int; end_pos: int; confidence: float

@dataclass
class SecretScanResult:
    findings: list[SecretFinding] = field(default_factory=list)
    secrets_detected: bool = False
    content_redacted: str = ""

class SecretScanner:
    """Scan email content for secrets: pattern matching + entropy analysis."""
    ENTROPY_THRESHOLD = 3.5
    CONTEXT_KEYWORDS = {"secret", "key", "token", "password", "credential", "api", "auth"}

    def __init__(self, whitelist_patterns=None):
        self.whitelist = whitelist_patterns or []

    def scan(self, content: str) -> SecretScanResult:
        result = SecretScanResult(); redacted = content
        for rule_name, desc, pattern in SECRET_PATTERNS:
            for match in pattern.finditer(redacted):
                if self._is_whitelisted(match.group(0)): continue
                result.findings.append(SecretFinding(rule_name, desc, f"[REDACTED:{rule_name}]", match.start(), match.end(), 0.95))
                redacted = redacted.replace(match.group(0), f"[REDACTED:{rule_name}]", 1)
        for token in re.findall(r'[A-Za-z0-9+/=_\-]{32,}', redacted):
            if self._is_whitelisted(token) or re.match(r'^[a-f0-9]{32}$', token, re.I): continue
            if shannon_entropy(token) >= self.ENTROPY_THRESHOLD:
                pos = redacted.find(token)
                if any(kw in redacted[max(0,pos-50):pos].lower() for kw in self.CONTEXT_KEYWORDS):
                    result.findings.append(SecretFinding("high_entropy", "High-entropy near keyword", "[REDACTED:high_entropy]", pos, pos+len(token), 0.7))
                    redacted = redacted.replace(token, "[REDACTED:high_entropy]", 1)
        result.secrets_detected = len(result.findings) > 0
        result.content_redacted = redacted
        return result

    def _is_whitelisted(self, text): return any(p.search(text) for p in self.whitelist)
```

```python
# File: src/gmail/scanner/pii_scanner.py
import re, logging
from dataclasses import dataclass, field

KTP_PATTERN = re.compile(r'\b([1-9][0-9])([0-9]{2})([0-6][0-9])([0-3][0-9])([0-9]{2})([0-9]{4})\b')
NPWP_PATTERN = re.compile(r'\b\d{2}\.\d{3}\.\d{3}\.\d-\d{3}\.\d{3}\b')
CC_PATTERN = re.compile(r'\b(?:4[0-9]{12}(?:[0-9]{3})?|5[1-5][0-9]{14}|3[47][0-9]{13})\b')
EMAIL_PATTERN = re.compile(r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}\b')
PHONE_ID_PATTERN = re.compile(r'(?:\+62|62|0)[2-9]\d{7,11}')

def luhn_check(number: str) -> bool:
    digits = [int(d) for d in number if d.isdigit()]
    if len(digits) < 13: return False
    total = 0
    for i, d in enumerate(digits[::-1]):
        if i % 2 == 1: d *= 2; d = d - 9 if d > 9 else d
        total += d
    return total % 10 == 0

@dataclass
class PIIFinding:
    category: str; redacted_value: str; start_pos: int; end_pos: int; confidence: float

@dataclass
class PIIScanResult:
    findings: list[PIIFinding] = field(default_factory=list)
    pii_detected: bool = False; content_redacted: str = ""
    categories_found: list[str] = field(default_factory=list)

class PIIScanner:
    """PII scanner with Indonesian-context awareness (KTP, NPWP, bank accounts)."""
    def __init__(self, sender_email=None):
        self.known_emails = {sender_email.lower()} if sender_email else set()

    def scan(self, content: str) -> PIIScanResult:
        result = PIIScanResult(); redacted = content
        for m in EMAIL_PATTERN.finditer(content):
            if m.group(0).lower() not in self.known_emails:
                result.findings.append(PIIFinding("email", "[REDACTED:email]", m.start(), m.end(), 0.95))
        for m in CC_PATTERN.finditer(content):
            if luhn_check(m.group(0)):
                result.findings.append(PIIFinding("credit_card", "[REDACTED:credit_card]", m.start(), m.end(), 0.98))
        for m in KTP_PATTERN.finditer(content):
            prov, month, day = int(m.group(1)), int(m.group(3)), int(m.group(4))
            if 11 <= prov <= 96 and 1 <= month <= 12 and 1 <= day <= 31:
                result.findings.append(PIIFinding("ktp", "[REDACTED:ktp]", m.start(), m.end(), 0.85))
        for m in NPWP_PATTERN.finditer(content):
            result.findings.append(PIIFinding("npwp", "[REDACTED:npwp]", m.start(), m.end(), 0.90))
        for m in PHONE_ID_PATTERN.finditer(content):
            result.findings.append(PIIFinding("phone", "[REDACTED:phone]", m.start(), m.end(), 0.80))
        for f in sorted(result.findings, key=lambda x: x.start_pos, reverse=True):
            redacted = redacted[:f.start_pos] + f.redacted_value + redacted[f.end_pos:]
        result.pii_detected = len(result.findings) > 0
        result.content_redacted = redacted
        result.categories_found = list({f.category for f in result.findings})
        return result
```

```python
# File: src/gmail/scanner/combined_scanner.py
import hashlib, logging
from dataclasses import dataclass

@dataclass
class CombinedScanResult:
    secret_result: "SecretScanResult"
    pii_result: "PIIScanResult"
    final_content: str
    total_findings: int = 0

class CombinedScanner:
    """Orchestrates secret + PII scanning with alerting and metrics."""
    def __init__(self, alert_dispatcher=None, metrics_collector=None, whitelist=None):
        self.secret_scanner = SecretScanner(whitelist_patterns=whitelist)
        self.alert_dispatcher = alert_dispatcher
        self.metrics = metrics_collector

    async def scan(self, content, sender, subject, message_id) -> CombinedScanResult:
        secret_result = self.secret_scanner.scan(content)
        pii_scanner = PIIScanner(sender_email=sender)
        pii_result = pii_scanner.scan(secret_result.content_redacted)
        total = len(secret_result.findings) + len(pii_result.findings)
        sender_hash = hashlib.sha256(sender.encode()).hexdigest()[:16]
        subject_hash = hashlib.sha256(subject.encode()).hexdigest()[:16]
        if secret_result.secrets_detected and self.alert_dispatcher:
            for f in secret_result.findings:
                await self.alert_dispatcher.send_secret_alert(f.rule_name, sender_hash, subject_hash, message_id)
        if pii_result.pii_detected and self.alert_dispatcher:
            for f in pii_result.findings:
                await self.alert_dispatcher.send_pii_alert(f.category, sender_hash, subject_hash, message_id)
        if self.metrics:
            for f in secret_result.findings:
                self.metrics.increment("gmail_secrets_detected_total", labels={"type": f.rule_name})
            for f in pii_result.findings:
                self.metrics.increment("gmail_pii_detected_total", labels={"type": f.category})
        return CombinedScanResult(secret_result, pii_result, pii_result.content_redacted, total)
```

#### Troubleshooting

- **@sanity-labs/secret-scan is npm**: Option (a) subprocess bridge to Node.js (~5ms). Option (b) port critical patterns to Python regex (SECRET_PATTERNS covers 30+ categories). Prefer (b) for latency.
- **KTP false positives on random 16-digit numbers**: Add context keyword check ("KTP", "NIK"). Lower confidence to 0.7 without context.
- **Bank account false positives**: Only trigger with contextual keywords: "rekening", "transfer", "bank".
- **datafog Rust core fails**: Install Rust toolchain. Fallback to custom regex patterns (same categories, no Rust dep).
- **Entropy flags tracking IDs**: Require keyword proximity (50 chars). Exclude UUIDs, hex hashes.
- **Discord alert spam**: Batch alerts (one per email). Rate-limit to 5/minute.

#### Notes

- **Logging Discipline**: NEVER log actual secret/PII values. Only metadata: sender_hash, subject_hash, rule_name, category. Per PersonaSafetyPolicy.
- **Redaction Before Memory**: Redaction happens BEFORE `store_episode()`. Memory store receives already-redacted content.
- **Whitelist Maintenance**: Update `config/gmail/secret_whitelist.yaml` as false positives discovered. Review quarterly.
- **Cross-Reference P12-011**: Secret/PII scanning runs AFTER sanitizer's 6-layer pipeline completes.
