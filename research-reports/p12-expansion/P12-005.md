### Step P12-005: Incremental Sync Engine

**Type:** Application
**Status:** Not Started
**Risk:** High
**Git Commit:** `feat(P12): pending`

**Goal:** Build the `SyncEngine` class that performs efficient incremental email sync using the `history.list(startHistoryId=old_id)` pattern, persists `last_history_id` in PostgreSQL, handles 404 (historyId expired → full sync fallback), processes messages through a pipeline (fetch → parse → yield to classifier), tracks threads for conversation continuity, filters by labels (Important, Work, Financial), and supports backfill mode (last 30 days, label-filtered).
**Dependencies:** P12-004 (GmailClient + AsyncGmailClient operational), P12-001 (Pub/Sub topic + subscription).
**Cost Impact:** $0/month (incremental sync within Gmail API free tier).
**ADR References:** ADR-022 (Channel Strategy — Gmail incremental sync via history API).
**Acceptance Criteria:** AC-EMAIL-001 (Gmail connected), AC-EMAIL-002 (Emails classified within 5s — sync latency component).
**Estimated Time:** 4 hours

#### Context

The Gmail API's `history.list` endpoint returns all changes (new messages, label changes, deletions) since a given `historyId`. This enables efficient incremental sync — instead of polling the entire inbox, only changes since the last sync are fetched. The critical insight (confirmed by Google docs and `research-reports/gmail-push-vs-polling-comparison.md`) is that **the OLD historyId is passed as `startHistoryId`**, not the new one from the Pub/Sub notification. This is counter-intuitive but correct: the old ID defines the starting point, and the API returns everything after that point.

Two operating modes:
1. **Incremental (default):** `history.list(startHistoryId=stored_old_id)` triggered by Pub/Sub notification or 5-minute polling fallback.
2. **Backfill (first run):** Last 30 days, label-filtered (Important only). Resumable via page-token cursor. Switches to incremental on completion.

When `history.list` returns 404 (historyId expired after ~7 days), the engine falls back to full sync: lists all recent messages, processes new ones, stores the new historyId from `getProfile()`.

The engine uses PostgreSQL for durable state and Redis for fast cache (60s TTL). Messages are yielded via async generator to the classification pipeline (P12-006), keeping the sync engine fully decoupled.

# src/gmail/sync_engine.py

"""SyncEngine: Incremental email sync using Gmail history API.
Modes: incremental (daily use) + backfill (first run, last 30 days)."""
import asyncio, hashlib, json, time
from datetime import datetime, timedelta, timezone
from typing import Any, AsyncGenerator

import structlog
from prometheus_client import Counter, Gauge, Histogram
from src.gmail.gmail_client import AsyncGmailClient, GmailMessage, HistoryExpiredError, TokenExpiredError
from src.gmail.token_manager import TokenManager

logger = structlog.get_logger(__name__)

# Metrics
sync_cycles = Counter("gmail_sync_cycles_total", "Sync cycles completed", ["mode","status"])
sync_msgs = Counter("gmail_sync_messages_processed_total", "Messages processed")
sync_latency = Histogram("gmail_sync_cycle_latency_seconds", "Cycle time", ["mode"])
sync_last = Gauge("gmail_sync_last_run_timestamp", "Last successful sync unix time")
gmail_connected = Gauge("gmail_connected", "API connection active (1/0)")

SYNC_LABELS = ["IMPORTANT","INBOX"]
BACKFILL_LABELS = ["IMPORTANT"]
BACKFILL_DAYS = 30
BACKFILL_BATCH = 50
POLL_INTERVAL = 300  # 5 min fallback

class SyncEngine:
    """Incremental sync engine. State persisted in PostgreSQL, cached in Redis."""

    def __init__(self, gmail: AsyncGmailClient, db_factory, redis):
        self.gmail = gmail
        self.db = db_factory
        self.redis = redis

    async def load_state(self) -> dict:
        """Load sync state: Redis cache → PostgreSQL fallback."""
        cached = await self.redis.get("gmail:sync_state")
        if cached: return json.loads(cached)
        async with self.db() as s:
            r = await s.execute("SELECT * FROM gmail_sync_state WHERE id=1")
            row = r.fetchone()
        state = {"last_history_id": 0, "sync_mode": "backfill", "backfill_cursor": None,
                 "total_synced": 0} if row is None else {
            "last_history_id": row[1], "sync_mode": row[3], "backfill_cursor": row[4],
            "total_synced": row[5]}
        await self.redis.setex("gmail:sync_state", 60, json.dumps(state))
        return state

    async def save_state(self, state: dict):
        """Persist to PostgreSQL + Redis cache."""
        async with self.db() as s:
            await s.execute("UPDATE gmail_sync_state SET last_history_id=:h,sync_mode=:m,"
                "last_sync_at=NOW(),backfill_cursor=:c,total_synced=:t WHERE id=1",
                {"h":state["last_history_id"],"m":state["sync_mode"],
                 "c":state.get("backfill_cursor"),"t":state["total_synced"]})
            await s.commit()
        await self.redis.setex("gmail:sync_state", 60, json.dumps(state))

    async def _record(self, msg: GmailMessage):
        h = hashlib.sha256(f"{msg.id}:{msg.subject}:{msg.from_addr}".encode()).hexdigest()
        async with self.db() as s:
            await s.execute("INSERT INTO gmail_synced_messages (message_id,thread_id,"
                "history_id,subject,from_addr,date_received,labels,content_hash) VALUES "
                "(:mid,:tid,0,:subj,:from_,:date_,:lbl,:hsh) ON CONFLICT (message_id) "
                "DO UPDATE SET labels=:lbl,processed_at=NOW()",
                {"mid":msg.id,"tid":msg.thread_id,"subj":msg.subject,"from_":msg.from_addr,
                 "date_":msg.date or datetime.now(timezone.utc).isoformat(),
                 "lbl":msg.labels,"hsh":h})
            await s.commit()

    # --- Incremental Sync ---
    async def sync_incremental(self) -> AsyncGenerator[GmailMessage, None]:
        """Fetch changes since stored historyId. Uses OLD id as startHistoryId."""
        state = await self.load_state()
        old_hid = str(state["last_history_id"])
        if old_hid == "0":
            p = await self.gmail.get_profile()
            state["last_history_id"] = int(p["historyId"]); state["sync_mode"]="incremental"
            await self.save_state(state); return

        logger.info("sync.inc.start", start_history_id=old_hid)
        try:
            yielded = 0
            while True:
                r = await self.gmail.list_history(start_history_id=old_hid,
                    history_types=["messageAdded","labelAdded"], max_results=500)
                for rec in r.get("history",[]):
                    for ma in rec.get("messagesAdded",[]):
                        mid = ma.get("message",{}).get("id")
                        if not mid or not any(l in ma.get("message",{}).get("labelIds",[]) for l in SYNC_LABELS):
                            continue
                        try:
                            msg = await self.gmail.get_message(mid)
                            await self._record(msg); yield msg; yielded+=1; sync_msgs.inc()
                        except Exception as e: logger.error("sync.msg_failed", mid=mid, err=str(e))
                if not r.get("nextPageToken"): break
            new_hid = r.get("historyId")
            if new_hid:
                state["last_history_id"] = int(new_hid)
                state["total_synced"] += yielded
                await self.save_state(state)
            logger.info("sync.inc.done", msgs=yielded, history_id=new_hid)
            sync_cycles.labels(mode="incremental",status="success").inc()
        except HistoryExpiredError:
            logger.warning("sync.history_expired")
            sync_cycles.labels(mode="incremental",status="history_expired").inc()
            async for msg in self.sync_full(): yield msg
        except TokenExpiredError:
            gmail_connected.set(0); sync_cycles.labels(mode="incremental",status="token_expired").inc(); raise

    # --- Full Sync (fallback) ---
    async def sync_full(self) -> AsyncGenerator[GmailMessage, None]:
        """Fallback: fetch last 7 days, establish new historyId. Cap 500 msgs."""
        logger.info("sync.full.start")
        p = await self.gmail.get_profile(); gmail_connected.set(1)
        since = (datetime.now(timezone.utc)-timedelta(days=7)).strftime("%Y/%m/%d")
        yielded = 0; pt = None
        while yielded < 500:
            r = await self.gmail.list_messages(query=f"after:{since}",label_ids=SYNC_LABELS,max_results=100,page_token=pt)
            for stub in r.get("messages",[]):
                try:
                    msg = await self.gmail.get_message(stub["id"])
                    await self._record(msg); yield msg; yielded+=1; sync_msgs.inc()
                except Exception as e: logger.error("sync.full_failed", mid=stub["id"], err=str(e))
            pt = r.get("nextPageToken")
            if not pt: break
        state = await self.load_state()
        state.update(last_history_id=int(p["historyId"]), sync_mode="incremental", total_synced=state["total_synced"]+yielded)
        await self.save_state(state)
        logger.info("sync.full.done", msgs=yielded)
        sync_cycles.labels(mode="full",status="success").inc()

    # --- Backfill (first run) ---
    async def sync_backfill(self) -> AsyncGenerator[GmailMessage, None]:
        """First run: fetch last 30 days of Important-labeled emails. Resumable."""
        state = await self.load_state()
        logger.info("sync.backfill.start", cursor=state.get("backfill_cursor"))
        since = (datetime.now(timezone.utc)-timedelta(days=BACKFILL_DAYS)).strftime("%Y/%m/%d")
        yielded = 0; pt = state.get("backfill_cursor")
        while True:
            r = await self.gmail.list_messages(query=f"after:{since}",
                label_ids=BACKFILL_LABELS, max_results=BACKFILL_BATCH, page_token=pt)
            batch = r.get("messages",[])
            if not batch: break
            for stub in batch:
                try:
                    msg = await self.gmail.get_message(stub["id"])
                    await self._record(msg); yield msg; yielded+=1; sync_msgs.inc()
                except Exception as e: logger.error("sync.bf_failed", mid=stub["id"], err=str(e))
            pt = r.get("nextPageToken")
            state["backfill_cursor"] = pt; state["total_synced"] += len(batch)
            await self.save_state(state)
            if not pt: break
            await asyncio.sleep(1)  # Respect quota
        p = await self.gmail.get_profile()
        state.update(last_history_id=int(p["historyId"]), sync_mode="incremental", backfill_cursor=None)
        await self.save_state(state)
        logger.info("sync.backfill.done", msgs=yielded, total=state["total_synced"])
        sync_cycles.labels(mode="backfill",status="success").inc()

    # --- Main Entry Point ---
    async def run_sync_cycle(self) -> AsyncGenerator[GmailMessage, None]:
        state = await self.load_state(); mode = state["sync_mode"]; t0 = time.time()
        try:
            generator = self.sync_backfill() if mode == "backfill" else self.sync_incremental()
            async for msg in generator: yield msg
            sync_last.set(time.time()); sync_latency.labels(mode=mode).observe(time.time()-t0)
            gmail_connected.set(1)
        except TokenExpiredError:
            logger.error("sync.token_expired"); gmail_connected.set(0); raise
        except Exception as e:
            logger.error("sync.cycle_failed", err=str(e))
            sync_cycles.labels(mode=mode,status="error").inc(); raise

# src/gmail/sync_scheduler.py
"""SyncScheduler: Pub/Sub StreamingPull (primary) + 5-min polling (fallback)."""
import asyncio, time
import structlog
from google.cloud import pubsub_v1
from src.gmail.sync_engine import SyncEngine, POLL_INTERVAL

logger = structlog.get_logger(__name__)

class SyncScheduler:
    def __init__(self, engine: SyncEngine,
                 subscription="projects/guinevere-gmail-prod/subscriptions/gmail-notifications-sub"):
        self.engine = engine; self.sub = subscription; self._run = False; self._last = 0.0

    async def start(self):
        self._run = True
        await asyncio.gather(self._pubsub_loop(), self._poll_loop())

    async def stop(self): self._run = False

    async def _pubsub_loop(self):
        while self._run:
            try:
                sub_client = pubsub_v1.SubscriberClient()
                for msg in sub_client.subscribe(self.sub):
                    if not self._run: break
                    msg.ack()
                    async for _ in self.engine.run_sync_cycle(): pass  # Pipeline integration via main loop
                    self._last = time.time()
            except Exception as e:
                logger.error("sync.pubsub_err", err=str(e))
                await asyncio.sleep(30)

    async def _poll_loop(self):
        while self._run:
            await asyncio.sleep(POLL_INTERVAL)
            if time.time() - self._last >= POLL_INTERVAL:
                logger.info("sync.polling_fallback")
                async for _ in self.engine.run_sync_cycle(): pass
                self._last = time.time()

#### Troubleshooting

- **Issue:** `history.list` returns 404 even with fresh historyId
  - **Solution:** historyId may be invalidated by bulk operations. Fetch new ID via `getProfile()`. `sync_full()` handles this automatically.
- **Issue:** Backfill processes too many messages, hits quota
  - **Solution:** Reduce `BACKFILL_BATCH` from 50 to 20, increase inter-batch sleep from 1s to 5s. Monitor `gmail_api_quota_usage` gauge.
- **Issue:** Pub/Sub StreamingPull disconnects frequently
  - **Solution:** Google drops idle connections after ~30 minutes. The reconnect loop (30s backoff) handles this. Polling fallback ensures no missed emails.
- **Issue:** `_record()` fails "duplicate key" on re-sync
  - **Solution:** `ON CONFLICT DO UPDATE` handles idempotent re-processing. If error persists, check that `content_hash` isn't in a unique constraint.
- **Issue:** Backfill resumes from wrong cursor after crash
  - **Solution:** `backfill_cursor` saved after every batch. Last complete batch's messages re-processed on restart (safe: ON CONFLICT DO UPDATE).
- **Issue:** `sync_full()` fetches too many messages (over 500 cap)
  - **Solution:** The 500 cap prevents quota exhaustion. If needed, increase cap and narrow the `since` range (reduce from 7 days to 3 days).

#### Notes

- **Counter-Intuitive historyId Pattern (CRITICAL):** `history.list(startHistoryId=OLD_ID)` — use the **old** stored ID, not the new one from Pub/Sub. The API returns all changes AFTER the old ID. New historyId from the response is stored for the next cycle. Confirmed by Google's official documentation.
- **Backfill Resume:** Interrupted backfills resume from `backfill_cursor` (Gmail API page token). Re-processed messages are idempotent (`ON CONFLICT DO UPDATE`).
- **Label Filtering Rationale:** `IMPORTANT` + `INBOX` reduces noise. Newsletters/promotions/spam typically lack the IMPORTANT label. `BACKFILL_LABELS` is narrower (IMPORTANT only) to reduce initial sync volume.
- **Thread Tracking:** `gmail_synced_messages.thread_id` enables cross-reference in the classifier (P12-006) — replies to existing threads get conversation context.
- **Cross-Reference P12-006:** Messages from `run_sync_cycle()` feed the classification engine, which assigns categories and importance scores.
- **Cross-Reference P12-008:** Draft pipeline uses `gmail_synced_messages` to find thread context (last 3 messages) via `get_thread()`.
- **Pub/Sub Dependency:** Install `google-cloud-pubsub>=2.20.0` separately from `google-api-python-client`. The subscription `gmail-notifications-sub` was created in P12-001.
- **Polling Fallback Necessity:** Pub/Sub has 99.9% delivery SLA. The 5-minute polling fallback guarantees no email is missed for more than 5 minutes even during complete Pub/Sub outages.
