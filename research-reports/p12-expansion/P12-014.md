### Step P12-014: Financial Email -> P9 Bridge

**Goal:** Extract structured financial data (amounts, categories, transaction dates, bank/fintech identity) from classified financial emails and store as metadata in the conversations record for P9's financial service to consume later.
**Dependencies:** P12-009 (Classification Engine — identifies FINANCIAL and BILLING_INVOICE emails).
**ADR References:** ADR-023 (Financial Tracking — P9 integration), ADR-009 (Cost Management — structured metadata).
**Estimated Time:** 6 hours

#### Context

P9 already has `financial.transactions` TimescaleDB hypertable but zero CRUD code. P12 writes structured financial metadata from emails; P9 reads later when its service is implemented. This is a **bridge pattern**.

Faiz decided: **store as structured metadata in memory, P9 reads later.** P12 does NOT insert into P9's table directly.

**Indonesian Financial Context:**
- Currency: `Rp 1.500.000,00` (dots = thousands, comma = decimal — opposite of US)
- Words: "juta" (million), "ribu" (thousand), "miliar" (billion)
- Banks: BCA, Mandiri, BRI, BNI, Jenius, BSI
- Fintech: GoPay, OVO, DANA, ShopeePay, LinkAja
- Utilities: PLN, PDAM, BPJS
- E-commerce: Tokopedia, Shopee, Bukalapak, Lazada

**Amount Extraction Patterns:**
- Standard IDR: `Rp 1.500.000,00` -> 1500000.00
- Compact: `Rp1.500.000` -> 1500000.00
- Words: `1,5 juta` -> 1500000.00, `500 ribu` -> 500000.00
- USD: `$150.00` or `USD 150` -> 150.00 (currency=USD)

# File: src/gmail/financial/financial_email_extractor.py
import re, logging
from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional

logger = logging.getLogger("gmail.financial")

# Indonesian amount patterns
IDR_STANDARD = re.compile(r'Rp\s?(\d{1,3}(?:\.\d{3})+)(?:,(\d{2}))?', re.I)
IDR_WORDS = re.compile(r'(\d+(?:[.,]\d+)?)\s*(juta|ribu|miliar|triliun)', re.I)
USD_PATTERN = re.compile(r'(?:USD|\$)\s?(\d{1,3}(?:,\d{3})*(?:\.\d{2})?)', re.I)

WORD_MULTIPLIERS = {"ribu": 1_000, "juta": 1_000_000, "miliar": 1_000_000_000, "triliun": 1_000_000_000_000}

INSTITUTION_MAP: dict[str, tuple[str, str]] = {
    "bca.co.id": ("BCA", "bank"), "klikbca.com": ("BCA", "bank"),
    "bankmandiri.co.id": ("Mandiri", "bank"), "bri.co.id": ("BRI", "bank"),
    "bni.co.id": ("BNI", "bank"), "jenius.co.id": ("Jenius", "digital_bank"),
    "bsi.co.id": ("BSI", "islamic_bank"),
    "gojek.com": ("GoPay", "fintech"), "gopay.co.id": ("GoPay", "fintech"),
    "ovo.id": ("OVO", "fintech"), "dana.id": ("DANA", "fintech"),
    "shopeepay.co.id": ("ShopeePay", "fintech"),
    "tokopedia.com": ("Tokopedia", "ecommerce"), "shopee.co.id": ("Shopee", "ecommerce"),
    "bukalapak.com": ("Bukalapak", "ecommerce"),
    "pln.co.id": ("PLN", "utility"), "bpjs-kesehatan.go.id": ("BPJS", "utility"),
    "telkomsel.com": ("Telkomsel", "telecom"),
}

DEBIT_KEYWORDS = ["debit", "pengeluaran", "pembayaran", "transfer keluar", "payment", "purchase", "pembelian", "tagihan", "billing"]
CREDIT_KEYWORDS = ["kredit", "pemasukan", "penerimaan", "transfer masuk", "credit", "deposit", "refund", "cashback", "gaji", "salary"]

def parse_indonesian_amount(match_str: str) -> Optional[float]:
    cleaned = re.sub(r'^[Rr][Pp]\s?', '', match_str.strip())
    if ',' in cleaned:
        parts = cleaned.rsplit(',', 1)
        integer_part = parts[0].replace('.', '')
        decimal_part = parts[1]
    else:
        integer_part = cleaned.replace('.', '')
        decimal_part = '00'
    try: return float(f"{integer_part}.{decimal_part}")
    except ValueError: return None

@dataclass
class FinancialTransaction:
    amount: float; currency: str = "IDR"; direction: str = "unknown"
    category: str = "unknown"; institution: str = "unknown"
    institution_type: str = "unknown"; description: str = ""
    transaction_date: Optional[str] = None; confidence: float = 0.0

@dataclass
class FinancialExtractionResult:
    is_financial: bool = False
    transactions: list[FinancialTransaction] = field(default_factory=list)
    source_email: dict = field(default_factory=dict)
    extraction_confidence: float = 0.0

class FinancialEmailExtractor:
    """Extract financial data from emails for P9 bridge.
    P12 writes structured metadata; P9 reads later."""

    def __init__(self, llm_classifier=None):
        self.llm_classifier = llm_classifier

    async def extract(self, content, sender, subject, email_date, message_id, category) -> FinancialExtractionResult:
        result = FinancialExtractionResult()
        if category not in ("FINANCIAL", "BILLING_INVOICE"): return result
        result.is_financial = True
        result.source_email = {"message_id": message_id, "sender": sender, "received_at": email_date.isoformat()}

        institution, inst_type = self._identify_institution(sender)
        amounts = self._extract_amounts(content)
        direction = self._detect_direction(content)
        tx_date = self._extract_transaction_date(content, email_date)
        description = self._generate_description(subject, content)
        tx_category = await self._classify_transaction(content, institution, inst_type)

        for amt in amounts:
            conf = 0.5
            if amt["amount"] > 0: conf += 0.2
            if institution != "unknown": conf += 0.15
            if direction != "unknown": conf += 0.15
            result.transactions.append(FinancialTransaction(
                amount=amt["amount"], currency=amt["currency"], direction=direction,
                category=tx_category, institution=institution, institution_type=inst_type,
                description=description, transaction_date=tx_date, confidence=min(conf, 1.0),
            ))
        if result.transactions:
            result.extraction_confidence = sum(t.confidence for t in result.transactions) / len(result.transactions)
        return result

    def _identify_institution(self, sender):
        try: domain = sender.split("@")[1].lower()
        except (IndexError, AttributeError): return ("unknown", "unknown")
        if domain in INSTITUTION_MAP: return INSTITUTION_MAP[domain]
        for known, info in INSTITUTION_MAP.items():
            if domain.endswith(f".{known}"): return info
        return ("unknown", "unknown")

    def _extract_amounts(self, content):
        amounts = []
        for m in IDR_STANDARD.finditer(content):
            if amt := parse_indonesian_amount(m.group(0)):
                if amt > 0: amounts.append({"amount": amt, "currency": "IDR"})
        for m in IDR_WORDS.finditer(content):
            try:
                num = float(m.group(1).replace(',', '.'))
                amt = num * WORD_MULTIPLIERS.get(m.group(2).lower(), 1)
                if amt > 0: amounts.append({"amount": amt, "currency": "IDR"})
            except ValueError: pass
        for m in USD_PATTERN.finditer(content):
            try:
                amt = float(m.group(1).replace(",", ""))
                if amt > 0: amounts.append({"amount": amt, "currency": "USD"})
            except ValueError: pass
        # Deduplicate by amount
        seen = set(); unique = []
        for a in amounts:
            if (k := (a["amount"], a["currency"])) not in seen: seen.add(k); unique.append(a)
        return unique

    def _detect_direction(self, content):
        lower = content.lower()
        d = sum(1 for kw in DEBIT_KEYWORDS if kw in lower)
        c = sum(1 for kw in CREDIT_KEYWORDS if kw in lower)
        return "debit" if d > c else ("credit" if c > d else "unknown")

    def _extract_transaction_date(self, content, email_date):
        patterns = [
            re.compile(r'(\d{1,2}[/-]\d{1,2}[/-]\d{2,4})'),
            re.compile(r'(?:tanggal|date|tgl)\s*[:.]?\s*(\d{1,2}[/-]\d{1,2}[/-]\d{2,4})', re.I),
        ]
        for p in patterns:
            if m := p.search(content):
                try:
                    from dateutil import parser as dp
                    return dp.parse(m.group(1), dayfirst=True).strftime("%Y-%m-%d")
                except (ValueError, ImportError): pass
        return email_date.strftime("%Y-%m-%d")

    def _generate_description(self, subject, content):
        first = content.replace("\n", " ").split(". ")[0][:150]
        return f"{subject}: {first}" if first else subject

    async def _classify_transaction(self, content, institution, inst_type):
        lower = content.lower()
        rules = [("transfer", ["transfer", "kirim", "send"]), ("payment", ["pembayaran", "payment", "bayar"]),
                 ("purchase", ["pembelian", "purchase", "order"]), ("income", ["gaji", "salary", "income"]),
                 ("refund", ["refund", "cashback"]), ("billing", ["tagihan", "billing", "invoice"]),
                 ("topup", ["top up", "topup", "isi ulang"])]
        for cat, keywords in rules:
            if any(kw in lower for kw in keywords): return cat
        if inst_type == "telecom": return "telecom_payment"
        if inst_type == "utility": return "utility_payment"
        if self.llm_classifier:
            try: return (await self.llm_classifier.classify(
                f"Classify transaction: {content[:500]}")).strip().lower()
            except Exception: pass
        return "other"

    def to_metadata(self, result) -> dict:
        if not result.is_financial: return {}
        return {
            "is_financial": True,
            "transactions": [{"amount": t.amount, "currency": t.currency, "direction": t.direction,
                              "category": t.category, "institution": t.institution,
                              "institution_type": t.institution_type, "description": t.description,
                              "transaction_date": t.transaction_date, "confidence": t.confidence}
                             for t in result.transactions],
            "source_email": result.source_email,
            "extraction_confidence": result.extraction_confidence,
        }

#### Troubleshooting

- **Non-standard formats (US-style separators from international senders)**: Use sender domain as locale hint — .co.id/.id domains use Indonesian format, international domains use US format.
- **Multiple amounts (balance + transaction amount)**: Prioritize amounts near transaction keywords. If ambiguous, take largest and flag for manual review. Store all amounts in metadata.
- **Unknown institution for new fintech domains**: Maintain `INSTITUTION_MAP` as config file (`config/gmail/institution_map.yaml`). Log unrecognized domains for periodic review.
- **Wrong transaction date**: Look for dates near transaction keywords. If multiple dates found, prefer closest to keywords.
- **LLM classification expensive**: Keyword rules cover ~85% of transactions. Only invoke LLM when keywords inconclusive. Cache results in Redis (30-day TTL).
- **P9 schema mismatch**: Expected — P12 writes metadata to conversations record, not P9's table. P9's future implementation maps from conversations metadata.

#### Notes

- **Bridge Pattern**: P12 writes, P9 reads. This step does NOT create/modify/query P9's `financial.transactions` table. Metadata stored in conversations `metadata_` JSONB field. P9 queries `metadata_->>'is_financial' = 'true'`.
- **Indonesian Decimal Convention**: Critical — dots for thousands, comma for decimal (opposite of US). `Rp 1.500.000,50` = 1,500,000.50 US. Parsing error = 100x amount misrepresentation.
- **Redis DB5**: P9 already uses DB5 for financial caching. P12 extractor uses same DB for institution map cache and classification cache.
- **Cross-Reference P12-009**: Classification engine determines which emails trigger financial extraction.
- **Cross-Reference P12-013**: Financial metadata appended to episode metadata via EmailMemoryStore.
- **Future Enhancement**: Bidirectional sync — P12 writes -> P9 reads/creates transactions -> P9 writes back `p9_synced: true` to conversations metadata.
- **Currency Conversion**: P12 extracts in original currency (IDR/USD). Conversion is P9's responsibility.
