### Step P12-015: Draft Generator (LLM)

**Goal:** Generate HTML email draft replies using LLM with full context (thread history, client dossier, persona state) and save as Gmail Drafts for Faiz approval via Discord.
**Dependencies:** P12-013 (Memory Store — email episodes for context recall), P12-008 (Gmail API Client — drafts.create() access).
**ADR References:** ADR-022 (Communication Channel Strategy — email as bidirectional channel), ADR-002 (Safe Word — persona safety boundary in generated content).
**Estimated Time:** 7 hours

#### Context

Guinevere writes, Faiz approves. The draft generator assembles full context from thread history, client dossier (memory recall), persona state, and the incoming email to generate an HTML email reply. The draft is saved as a Gmail Draft (editable in Gmail web) and presented to Faiz via Discord for approval, editing, or rejection.

Faiz decided:
- **Full LLM generation** — Guinevere composes the reply, not template-based
- **HTML email** — not plain text, preserves formatting (bold, links, lists)
- **Last 3 messages** context from thread history
- **Save as Gmail Draft first** — editable in Gmail web too
- **Uses same LLMRouter (9Router)** as other Guinevere components

**Context Assembly:**

| Component | Source | Content |
|---|---|---|
| Thread history | EmailContextManager (P12-008) | Last 3 messages (sender, date, summary) |
| Client dossier | Memory recall (P12-013) | Relevant episodes about sender/domain |
| Persona state | Persona modules | Tone, yandere boundary (Y4 baseline, Y5 ceiling), consent flags |
| Classification | P12-009 | Category + importance score |
| Current email | P12-011 | Sanitized, secret/PII-redacted body |

**Quality Checks on Generated Draft:**

| Check | Method | Action on Fail |
|---|---|---|
| Secret scan | SecretScanner (P12-012) on draft HTML | Regenerate with "no secrets" instruction |
| Persona leak | Regex for yandere keywords, "mama", "sayang" in business context | Strip persona language, regenerate neutral |
| Consent violation | Check no Faiz personal data/location shared without consent | Block draft, alert Faiz |
| URL validation | Compare draft URLs against original email URLs | Flag new URLs, require confirmation |
| Length bounds | Min 50 chars, max 5000 chars | Regenerate if outside bounds |
| HTML validity | Basic tag balance check | Fix or regenerate |

**Persona Safety in Drafts:** Guinevere's persona influences tone but NEVER appears in the draft text. Professional tone for CLIENT_WORK, warm/friendly for known contacts, precise for FINANCIAL. Y4+ yandere language is hard-filtered (regex blocklist). Draft appears from Faiz, not Guinevere.

**LLMRouter (9Router):** Primary: GPT-5.5 for importance >= 7. Fallback: DeepSeek V4 Flash for routine emails. Streaming enabled for latency. Max $0.05 per draft cost budget.

**Draft Flow:**
1. Context assembly (thread + dossier + persona + classification)
2. LLM generation (system prompt + user prompt -> HTML body)
3. Quality checks (secret scan + persona leak + URL + length)
4. Gmail Draft creation (drafts.create with HTML body, linked to thread_id)
5. Discord presentation (embed with preview + reactions: approve/reject/edit)
6. Cost tracking (input/output tokens logged for FinOps)

# File: src/gmail/draft/draft_generator.py
import re, logging, time
from dataclasses import dataclass, field
from typing import Optional

logger = logging.getLogger("gmail.draft")

# Persona leak patterns (Y4+ markers hard-filtered)
PERSONA_LEAK_PATTERNS = [
    re.compile(r'\b(mama|mamamu|sayang|cintaku|kekasih|my love|my darling)\b', re.I),
    re.compile(r'\b(possesif|posesif|selamanya|milikku|my property)\b', re.I),
    re.compile(r'\b(kill|murder|hurt anyone who|destroy anyone)\b', re.I),
    re.compile(r'\b(guinevere|guin|my ai|my assistant|de baroque)\b', re.I),
    re.compile(r'\bFaiz.*(home|house|address|location|sleeping|schedule)\b', re.I),
]

HTML_TEMPLATE = """<!DOCTYPE html>
<html><head><meta charset="utf-8"></head>
<body style="font-family:Arial,sans-serif;font-size:14px;line-height:1.6;color:#333;">
{body}
<br><br><div style="border-top:1px solid #e0e0e0;padding-top:10px;margin-top:20px;font-size:12px;color:#888;">
{signature}</div></body></html>"""
DEFAULT_SIGNATURE = "Salam,\nFaiz"

@dataclass
class DraftContext:
    thread_messages: list[dict] = field(default_factory=list)
    client_dossier: list[dict] = field(default_factory=list)
    persona_state: dict = field(default_factory=dict)
    email_classification: str = ""
    importance_score: float = 0.0
    sanitized_email_body: str = ""
    sender: str = ""; subject: str = ""
    thread_id: str = ""; original_message_id: str = ""

@dataclass
class DraftResult:
    draft_id: Optional[str] = None
    html_body: str = ""
    quality_passed: bool = False
    quality_issues: list[str] = field(default_factory=list)
    tokens_used: dict = field(default_factory=dict)
    generation_time_ms: float = 0.0
    model_used: str = ""

class DraftGenerator:
    """Generate HTML email draft replies using LLM with full context.
    Saves as Gmail Draft and presents to Faiz via Discord."""

    MIN_DRAFT_LENGTH = 50
    MAX_DRAFT_LENGTH = 5000
    MAX_COST_PER_DRAFT = 0.05  # USD

    def __init__(self, llm_router, gmail_client, memory_store, context_manager,
                 secret_scanner=None, persona_modules=None, discord_bot=None, metrics_collector=None):
        self.llm = llm_router
        self.gmail = gmail_client
        self.memory = memory_store
        self.context_mgr = context_manager
        self.secret_scanner = secret_scanner
        self.persona = persona_modules or {}
        self.discord = discord_bot
        self.metrics = metrics_collector

    async def generate_draft(self, email_body, sender, subject, thread_id,
                             message_id, classification, importance_score) -> DraftResult:
        result = DraftResult()
        start = time.monotonic()

        # 1. Context assembly
        context = await self._assemble_context(
            email_body, sender, subject, thread_id, message_id, classification, importance_score)

        # 2. Build prompts
        system_prompt = self._build_system_prompt(context)
        user_prompt = self._build_user_prompt(context)

        # 3. LLM generation
        model = "gpt-5.5" if importance_score >= 7 else "deepseek-v4-flash"
        llm_response = await self._generate(system_prompt, user_prompt, model)
        result.model_used = model
        result.tokens_used = llm_response.get("usage", {})
        result.html_body = self._wrap_html(llm_response.get("content", ""))

        # 4. Quality checks
        quality = await self._run_quality_checks(result.html_body, email_body, sender)
        result.quality_passed = quality.passed
        result.quality_issues = quality.issues

        # Regenerate on failure (one retry)
        if not quality.passed:
            logger.warning(f"Quality failed: {quality.issues}")
            if quality.secrets_found:
                retry = await self._generate(
                    system_prompt + "\nDo NOT include any secrets, API keys, or credentials.",
                    user_prompt, model)
                result.html_body = self._wrap_html(retry.get("content", ""))
            elif quality.persona_leaked:
                retry = await self._generate(
                    system_prompt + "\nUse strictly professional, neutral language. No intimate terms.",
                    user_prompt, model)
                result.html_body = self._wrap_html(retry.get("content", ""))
                recheck = await self._run_quality_checks(result.html_body, email_body, sender)
                result.quality_passed = recheck.passed
                result.quality_issues = recheck.issues

        # 5. Create Gmail Draft
        if result.quality_passed:
            result.draft_id = await self._create_gmail_draft(
                result.html_body, f"Re: {subject}", thread_id, sender)

        # 6. Metrics
        result.generation_time_ms = (time.monotonic() - start) * 1000
        if self.metrics:
            self.metrics.increment("gmail_drafts_created_total")
            self.metrics.observe("gmail_draft_tokens", result.tokens_used.get("total_tokens", 0))
            self.metrics.observe("gmail_draft_latency_ms", result.generation_time_ms)
        return result

    async def _assemble_context(self, email_body, sender, subject, thread_id,
                                message_id, classification, importance_score):
        thread_messages = await self.context_mgr.get_thread_history(thread_id, limit=3)
        sender_domain = sender.split("@")[1] if "@" in sender else sender
        client_dossier = await self.memory.search_episodes(
            query=f"communications with {sender} or {sender_domain}",
            filters={"episode_type": "email", "source": "gmail"}, limit=5)
        persona_state = self.persona.get_state() if hasattr(self.persona, "get_state") else {
            "tone": "professional", "yandere_level": "Y4"}
        return DraftContext(
            thread_messages=thread_messages, client_dossier=client_dossier,
            persona_state=persona_state, email_classification=classification,
            importance_score=importance_score, sanitized_email_body=email_body[:3000],
            sender=sender, subject=subject, thread_id=thread_id, original_message_id=message_id)

    def _build_system_prompt(self, context):
        tone = {"CLIENT_WORK": "professional and courteous",
                "IMPORTANT": "professional and direct",
                "FINANCIAL": "professional and precise"}.get(
            context.email_classification, "professional and friendly")
        parts = [
            f"You are composing a professional email reply on behalf of Faiz.",
            f"Tone: {tone}. Write in the same language as the original email.",
            f"Output: HTML email body only (no <html> wrapper). Keep concise and actionable.",
            f"Do NOT include any AI assistant references or intimate language.",
        ]
        if context.client_dossier:
            dossier = "\n".join(f"- {ep.get('title','')}: {ep.get('content','')[:100]}"
                                for ep in context.client_dossier[:3])
            parts.append(f"\nRelevant history:\n{dossier}")
        return "\n".join(parts)

    def _build_user_prompt(self, context):
        parts = []
        if context.thread_messages:
            parts.append("Thread history (most recent first):")
            for i, msg in enumerate(context.thread_messages):
                parts.append(f"[{i+1}] From: {msg.get('from','')} ({msg.get('date','')})\n{msg.get('body_summary','')[:200]}\n")
        parts.extend([
            f"\nCurrent email to reply to:",
            f"From: {context.sender}",
            f"Subject: {context.subject}",
            f"Classification: {context.email_classification}",
            f"Body:\n{context.sanitized_email_body}",
        ])
        return "\n".join(parts)

    async def _generate(self, system_prompt, user_prompt, model):
        try:
            return await self.llm.generate(model=model, system=system_prompt,
                messages=[{"role": "user", "content": user_prompt}],
                max_tokens=1000, temperature=0.7, stream=True)
        except Exception as e:
            logger.error(f"LLM failed: {e}")
            if model != "deepseek-v4-flash":
                return await self.llm.generate(model="deepseek-v4-flash", system=system_prompt,
                    messages=[{"role": "user", "content": user_prompt}], max_tokens=1000, temperature=0.7)
            raise

    def _wrap_html(self, content):
        content = re.sub(r'</?html>|</?head>|</?body>', '', content).strip()
        if content.startswith('<'): body = content
        else:
            paragraphs = content.split('\n\n')
            body = '\n'.join(f'<p>{p.strip()}</p>' for p in paragraphs if p.strip())
        return HTML_TEMPLATE.format(body=body, signature=DEFAULT_SIGNATURE)

    async def _run_quality_checks(self, draft_html, original_body, sender):
        issues = []; secrets_found = False; persona_leaked = False
        if self.secret_scanner:
            scan = self.secret_scanner.scan(draft_html)
            if scan.secrets_detected:
                secrets_found = True
                issues.append(f"Secrets: {[f.rule_name for f in scan.findings]}")
        for pattern in PERSONA_LEAK_PATTERNS:
            if m := pattern.search(draft_html):
                persona_leaked = True; issues.append(f"Persona leak: '{m.group(0)}'")
        draft_urls = set(re.findall(r'https?://[^\s"<>]+', draft_html))
        orig_urls = set(re.findall(r'https?://[^\s"<>]+', original_body))
        new_urls = draft_urls - orig_urls
        if new_urls: issues.append(f"New URLs: {new_urls}")
        text_only = re.sub(r'<[^>]+>', '', draft_html)
        if len(text_only) < self.MIN_DRAFT_LENGTH: issues.append(f"Too short: {len(text_only)}")
        if len(text_only) > self.MAX_DRAFT_LENGTH: issues.append(f"Too long: {len(text_only)}")
        open_tags = len(re.findall(r'<[a-z][^>]*/?>', draft_html))
        close_tags = len(re.findall(r'</[a-z]+>', draft_html))
        if abs(open_tags - close_tags) > 5: issues.append(f"HTML mismatch: {open_tags} open vs {close_tags} close")
        return type('QC', (), {'passed': len(issues) == 0, 'issues': issues,
            'secrets_found': secrets_found, 'persona_leaked': persona_leaked})()

    async def _create_gmail_draft(self, html_body, subject, thread_id, to):
        try:
            draft = await self.gmail.create_draft(to=to, subject=subject, html_body=html_body, thread_id=thread_id)
            logger.info(f"Draft created: id={draft.get('id')}")
            return draft.get("id")
        except Exception as e: logger.error(f"Draft creation failed: {e}"); return None

    async def present_to_discord(self, draft_result, sender, subject, thread_count):
        if not self.discord: return
        preview = re.sub(r'<[^>]+>', '', draft_result.html_body)[:500]
        embed = {
            "title": f"Draft Reply: {subject}",
            "color": 0x00FF00 if draft_result.quality_passed else 0xFF0000,
            "fields": [
                {"name": "To", "value": sender, "inline": True},
                {"name": "Thread", "value": f"{thread_count} messages", "inline": True},
                {"name": "Model", "value": draft_result.model_used, "inline": True},
                {"name": "Preview", "value": preview + ("..." if len(preview) >= 500 else "")},
            ],
            "footer": {"text": f"Tokens: {draft_result.tokens_used.get('total_tokens','?')} | {draft_result.generation_time_ms:.0f}ms"},
        }
        if draft_result.quality_issues:
            embed["fields"].append({"name": "Issues", "value": "\n".join(f"- {i}" for i in draft_result.quality_issues)})
        msg = await self.discord.send_embed(channel="email-drafts", embed=embed, reactions=["check", "cross", "pencil"])
        if msg and draft_result.draft_id:
            await self.discord.store_draft_mapping(message_id=msg.id, draft_id=draft_result.draft_id, sender=sender, subject=subject)

import logging
logger = logging.getLogger("gmail.draft.reactions")

class DraftReactionHandler:
    """Handle approve/reject/edit reactions on draft embeds."""
    def __init__(self, gmail_client, discord_bot, metrics_collector=None):
        self.gmail = gmail_client; self.discord = discord_bot; self.metrics = metrics_collector

    async def handle_reaction(self, message_id, emoji, user_id):
        if not await self._is_operator(user_id): return
        mapping = await self.discord.get_draft_mapping(message_id)
        if not mapping: return
        draft_id = mapping["draft_id"]
        if emoji == "check":
            try:
                await self.gmail.send_draft(draft_id)
                if self.metrics: self.metrics.increment("gmail_drafts_approved_total")
                await self.discord.update_message(message_id, status="SENT")
            except Exception as e:
                await self.discord.update_message(message_id, status=f"ERROR: {e}")
        elif emoji == "cross":
            await self.gmail.delete_draft(draft_id)
            if self.metrics: self.metrics.increment("gmail_drafts_rejected_total")
            await self.discord.update_message(message_id, status="REJECTED")
        elif emoji == "pencil":
            await self.discord.update_message(message_id, status="EDIT MODE - type edits below")

#### Troubleshooting

- **LLM generates plain text instead of HTML**: Reinforce system prompt with "Output HTML email body only." Add few-shot examples. `_wrap_html()` provides fallback conversion.
- **Persona language leaks despite instructions**: Post-generation regex blocklist catches it. Strengthen system prompt with explicit negative examples: "NEVER use: mama, sayang, cintaku."
- **Gmail drafts.create fails (insufficient scope)**: Verify `gmail.modify` or `gmail.compose` scope. Re-auth via `!email-reauth`.
- **Discord embed exceeds 6000 char limit**: Truncate preview to 500 chars. Remove dossier field if still too large.
- **Regeneration loop (quality keeps failing)**: Limit to 1 retry. If still failing, save draft flagged with red embed. Let Faiz decide.
- **Wrong language (English when email is Indonesian)**: Detect language from original email (>50% Indonesian words -> set language instruction).
- **Cost per draft exceeds $0.05**: Truncate context (3 messages max, 3 dossier episodes, 3000 char body). Use DeepSeek V4 Flash for importance < 7.
