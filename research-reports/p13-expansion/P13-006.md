### Step P13-006: Sidecar Parser

**Type:** Expansion
**Status:** Not Started
**Risk:** Medium
**Git Commit:** `feat(P13): pending`

**Goal:** Implement the P13 X Auto Poster sidecar parser that reads `.meta.json` files beside queued images, validates scheduling and metadata fields, applies English defaults, and merges sidecar values with Gemini-generated content using the hybrid strategy.
**Dependencies:** P13-005 Queue Polling Loop, S3 prefix `guinevere-assets/x-poster/`, existing LLMRouter through 9Router, Gemini Flash default model with Gemini Pro fallback.
**Cost Impact:** Minimal LLM cost only when sidecar does not fully bypass generation; parser itself adds no infrastructure.
**ADR References:** ADR-015 (Secrets Management via SOPS+age), PersonaSafetyPolicy for safe public-facing text, P13 requirements section 2.3 and 4.2.
**Acceptance Criteria:** AC-POSTING-006 (Caption Pipeline), AC-POSTING-001 (Queue Flow), AC-POSTING-004 (Error Recovery).
**Estimated Time:** 15-30 minutes.

#### Context

Every queued image can have a sidecar metadata file with the same basename and `.meta.json` extension. For example, `guinevere-assets/x-poster/pending/2026-06-04_080000_abcd.jpg` may have `guinevere-assets/x-poster/pending/2026-06-04_080000_abcd.meta.json`. The parser must read the sidecar when present, validate fields, and produce a normalized metadata object for downstream queue, rate-limit, caption, and posting stages.

Required sidecar fields are:

- `caption`: string or null.
- `custom_alt`: string or null.
- `schedule`: `immediate` or ISO 8601 datetime.
- `tone`: `professional`, `casual`, or `auto`.
- `language`: `id`, `en`, or `auto`, with English default.
- `tags`: array of hashtag strings.
- `skip_llm`: boolean.

The generation strategy is hybrid. Sidecar fields override LLM outputs where explicitly provided. If `skip_llm=true`, use the `caption` field as-is and do not request Gemini caption generation. If LLM generation is needed, use Gemini Flash by default and Gemini Pro as fallback. The parser must reject malformed JSON, missing required fields, invalid schedule values, invalid field types, and unsafe empty pass-through captions when `skip_llm=true`.

#### Troubleshooting

- **Issue:** `datetime.fromisoformat` rejects a schedule with `Z` suffix.
  - **Solution:** Normalize trailing `Z` to `+00:00` before parsing, or document accepted ISO 8601 offset format explicitly.
- **Issue:** `skip_llm=true` with null caption.
  - **Solution:** Reject the sidecar with reason `missing_caption_for_skip_llm` and move the item to the appropriate failure path.
- **Issue:** Sidecar missing from S3.
  - **Solution:** Use default metadata: `caption=null`, `custom_alt=null`, `schedule=immediate`, `tone=auto`, `language=en`, `tags=[]`, `skip_llm=false` only if the product decision allows missing sidecars.
- **Issue:** Tags contain raw words without `#`.
  - **Solution:** Normalize in one place before posting; preserve evidence of normalization in parser tests.
- **Issue:** LLM output conflicts with sidecar caption.
  - **Solution:** Sidecar explicit fields win; LLM fills only missing generated fields.

#### Notes

- This step does not perform actual X posting. It prepares validated metadata for later caption, rate-limit, and compose steps.
- The default language is English unless the sidecar explicitly requests Indonesian or auto-detection resolves otherwise.
- Public caption content should remain consent-safe and must not leak private operator data.
- Use post-launch wording for deferred enhancements only.
- Keep model policy explicit: Gemini Flash default, Gemini Pro fallback.
