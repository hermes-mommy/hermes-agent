**Type:** Application
**Status:** Not Started

**Goal:** Implement tone and language control for the P13 caption pipeline so sidecar metadata can force professional or casual output, or request automatic image-aware classification before caption generation.
**Dependencies:** P13-006 Sidecar Parser, P13-011 Caption Generator, P13-012 Content Moderation, existing LLMRouter through 9Router.

**Estimated Time:** 2 hours

#### Context

P13 sidecar metadata supports `tone` values of `professional`, `casual`, or `auto`, and `language` values of `id`, `en`, or `auto`. The tone controller sits between sidecar parsing and caption generation. It must preserve explicit operator choices and only call the LLM classifier when a field is set to `auto` or missing in a way that requires inference.

The controller output is a structured object consumed by the caption generator:

```json
{
  "detected_tone": "professional | casual",
  "detected_language": "id | en",
  "tone_prompt_adjustment": "string"
}
```

Gemini Flash is the default model for image-aware classification. Gemini Pro is used only as fallback when Flash fails. If both models fail, use safe deterministic defaults: professional tone and English language, and record the fallback reason in telemetry without blocking the post.

#### Troubleshooting

- **Issue:** The LLM returns unsupported tone text.
  - **Solution:** Parse through a strict schema and normalize only accepted values. Invalid output falls back to professional.
- **Issue:** Language auto-detection produces values other than `id` or `en`.
  - **Solution:** Reject schema output and retry with Gemini Pro. If still invalid, default to English.
- **Issue:** Prompt adjustment makes captions exceed 280 characters.
  - **Solution:** The adjustment is instruction text only, not caption text. Enforce character limit after generation.
- **Issue:** Image classification is unavailable because the image is missing.
  - **Solution:** Return deterministic defaults and let corrupt-file handling decide whether the post can continue.

#### Notes

- Tone is not moderation. P13-012 still owns unsafe content blocking.
- The tone controller should be pure and testable where possible: inputs are sidecar metadata plus image context; output is a structured prompt control object.
- Professional tone should be polished, concise, and restrained.
- Casual tone should be warm, conversational, and still safe for public X posting.
- Indonesian language output must use natural Indonesian, not machine-translated fragments.
- English remains the default language when no sidecar value is provided.
- Do not expose raw sidecar metadata beyond what is needed for classification.
- This step is required before P13-014 through P13-016 can post final caption text confidently.
