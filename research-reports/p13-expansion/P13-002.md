### Step P13-002: Windows Watchdog Script

**Type:** Infrastructure
**Status:** Not Started
**Risk:** Medium
**Git Commit:** `feat(P13): pending`

**Goal:** Build a Windows Python watchdog uploader that monitors a configurable source folder, detects new JPG/PNG/WEBP files through `watchdog.events.FileCreatedEvent`, uploads each image to S3 `guinevere-assets/x-poster/pending/`, and uploads a matching `.meta.json` sidecar with English defaults.
**Dependencies:** P13-001 S3 Queue Setup complete; dedicated IAM credentials stored securely; Python available on Faiz's Windows machine; `watchdog` and `boto3` installable in a virtual environment.
**Cost Impact:** $0/month beyond S3 requests and object storage from P13-001.
**ADR References:** ADR-015 (Secrets Management via SOPS+age), P13 requirements §2.1 and §2.3.
**Acceptance Criteria:** AC-POSTING-001 (Queue Flow), AC-POSTING-006 (Caption Pipeline input contract), AC-POSTING-012 (P13 GATE).
**Estimated Time:** 15-30 min
**Phase:** P13
**Integration:** Windows upload bridge for X Auto Poster; later Discord controls must use `/x-` prefix.
**Default Language:** English
**LLM Defaults:** Sidecar supports LLM generation later with Gemini Flash primary and Gemini Pro fallback.

#### Context

The P13 queue starts on Faiz's Windows machine. The operator drops an image into a configured local folder, and the watchdog uploads it to S3 without manual VPS interaction. This makes the X Auto Poster feel like a simple desktop drop-folder while preserving a server-side queue, rate limiter, and posting engine.

This step creates the uploader script and sidecar behavior only. It does not post to X, generate captions, or run Discord commands. The sidecar should be useful enough for later steps: a null caption means the caption pipeline can generate text, null custom alt means accessibility alt text can be generated, and default `language` is English unless configured otherwise.

The upload naming contract is `YYYY-MM-DD_HHmmss_uuid.ext` for the image and the same basename plus `.meta.json` for the sidecar. Supported formats are JPG, JPEG, PNG, and WEBP. Unsupported files should be ignored with a clear log entry.

```python
# 5. Script skeleton: tools/p13/windows_watchdog.py
from __future__ import annotations

import json
import mimetypes
import os
import time
import uuid
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path

import boto3
from watchdog.events import FileCreatedEvent, FileSystemEventHandler
from watchdog.observers import Observer

SUPPORTED_SUFFIXES = {".jpg", ".jpeg", ".png", ".webp"}


@dataclass(frozen=True)
class WatchdogConfig:
    source_dir: Path
    bucket: str
    prefix: str


def load_config() -> WatchdogConfig:
    source = os.environ["P13_X_POSTER_SOURCE"]
    bucket = os.environ["P13_X_POSTER_BUCKET"]
    prefix = os.environ.get("P13_X_POSTER_PREFIX", "guinevere-assets/x-poster/pending")
    return WatchdogConfig(source_dir=Path(source), bucket=bucket, prefix=prefix.strip("/"))


def build_object_name(path: Path) -> str:
    timestamp = datetime.now().strftime("%Y-%m-%d_%H%M%S")
    extension = ".jpg" if path.suffix.lower() == ".jpeg" else path.suffix.lower()
    return f"{timestamp}_{uuid.uuid4().hex}{extension}"


def build_sidecar(original_path: Path, object_key: str) -> dict[str, object]:
    return {
        "caption": None,
        "custom_alt": None,
        "schedule": "immediate",
        "tone": "auto",
        "language": "en",
        "tags": [],
        "skip_llm": False,
        "source_filename": original_path.name,
        "s3_key": object_key,
        "created_by": "windows_watchdog",
        "created_at": datetime.now().astimezone().isoformat(),
    }


def wait_until_stable(path: Path, timeout_seconds: int = 30) -> None:
    deadline = time.monotonic() + timeout_seconds
    last_size = -1
    while time.monotonic() < deadline:
        current_size = path.stat().st_size
        if current_size > 0 and current_size == last_size:
            return
        last_size = current_size
        time.sleep(1)
    raise RuntimeError(f"File did not become stable before timeout: {path}")


class XPosterUploadHandler(FileSystemEventHandler):
    def __init__(self, config: WatchdogConfig) -> None:
        self.config = config
        self.s3 = boto3.client("s3")

    def on_created(self, event: FileCreatedEvent) -> None:
        if event.is_directory:
            return
        path = Path(event.src_path)
        if path.suffix.lower() not in SUPPORTED_SUFFIXES:
            print(f"Ignoring unsupported file: {path}")
            return
        wait_until_stable(path)
        object_name = build_object_name(path)
        image_key = f"{self.config.prefix}/{object_name}"
        meta_key = f"{image_key}.meta.json"
        content_type = mimetypes.guess_type(path.name)[0] or "application/octet-stream"
        self.s3.upload_file(str(path), self.config.bucket, image_key, ExtraArgs={"ServerSideEncryption": "AES256", "ContentType": content_type})
        sidecar = build_sidecar(path, image_key)
        self.s3.put_object(Bucket=self.config.bucket, Key=meta_key, Body=json.dumps(sidecar, indent=2).encode("utf-8"), ContentType="application/json", ServerSideEncryption="AES256")
        print(f"Uploaded {path.name} to s3://{self.config.bucket}/{image_key}")


def main() -> None:
    config = load_config()
    config.source_dir.mkdir(parents=True, exist_ok=True)
    observer = Observer()
    observer.schedule(XPosterUploadHandler(config), str(config.source_dir), recursive=False)
    observer.start()
    print(f"Watching {config.source_dir} for JPG/PNG/WEBP files")
    try:
        while True:
            time.sleep(5)
    finally:
        observer.stop()
        observer.join()


if __name__ == "__main__":
    main()
```

#### Troubleshooting

- **Issue:** Watchdog does not detect copied files.
  - **Solution:** Confirm the configured source folder matches the folder receiving files and that `recursive=False` is expected.
- **Issue:** Upload occurs before file copy finishes.
  - **Solution:** Increase `wait_until_stable()` timeout or add a second stable-size confirmation cycle.
- **Issue:** `NoCredentialsError` from boto3.
  - **Solution:** Confirm dedicated credentials are loaded from the approved SOPS/env workflow or Windows credential profile.
- **Issue:** `.jpeg` files upload with unexpected extension.
  - **Solution:** The skeleton normalizes `.jpeg` to `.jpg`; document this so downstream MIME handling expects JPG.
- **Issue:** Sidecar language is not English.
  - **Solution:** Check environment overrides or edited sidecar templates; default must remain `en`.

#### Notes

- Use Windows watchdog library events, specifically `FileCreatedEvent`, rather than polling the folder manually.
- Keep the uploader narrow: it uploads images and metadata only. Caption generation remains server-side with Gemini Flash default and Gemini Pro fallback.
- Do not add deprecated browser libraries or JavaScript-based upload tools; Python `watchdog` plus `boto3` is the required path.
- Later command surfaces must use `/x-` names such as `/x-status`, `/x-list`, and `/x-dryrun`.
- Use `post-launch` for enhancements such as startup backfill, tray UI, or Windows service installation.
