## Goal

Extend POST `/surveillance/events` to accept `event_type: "health"` payloads, route them through the P7 pipeline (HMAC → consent gate → classification → TimescaleDB `health.*` hypertables), and perform idempotent upserts keyed on `(time, device_id, metric)`.

---

## Context

The P7 `/surveillance/events` endpoint currently accepts standard surveillance event types (`app_usage`, `location`, `clipboard`, etc.) and routes them through a single pipeline: HMAC auth → Redis buffer → consumer → `surveillance.events` hypertable. Health data requires a *parallel* ingestion path within the same pipeline: health events bypass the generic consumer and are written directly to dedicated `health.*` hypertables (`heart_rate`, `sleep_sessions`, `sleep_stages`, `daily_activity`, `spo2`, `hrv`, `daily_summary`).

This step adds a health ingestion route that:
1. Shares the same HMAC auth dependency (`verify_hmac` from `src/surveillance/auth.py`)
2. Checks the consent gate for `surveillance.wearable.health.explicit` (added in P14-007; referenced here as a dependency)
3. Classifies health data as CRITICAL with `medium_operational` retention (already defined in `src/surveillance/classification.py` at line 139–145)
4. Routes to the correct `health.*` hypertable based on metric type
5. Performs idempotent upserts to prevent duplicate data from re-syncs

Health data carries **365-day retention** (overriding the 90-day `medium_operational` default) because clinical baselines require full-year trend analysis. This is implemented via a `RETENTION_HEALTH_DAYS` constant in `src/surveillance/retention.py`.

from enum import StrEnum

class HealthMetricType(StrEnum):
    """Discriminator for health metric payload routing."""
    HEART_RATE = "heart_rate"
    SLEEP_SESSION = "sleep_session"
    SLEEP_STAGE = "sleep_stage"
    DAILY_ACTIVITY = "daily_activity"
    SPO2 = "spo2"
    HRV = "hrv"
    STRESS = "stress"
    BODY_BATTERY = "body_battery"


class HealthMetricPayload(BaseModel):
    """Validated payload shape for health event ingestion."""
    model_config = ConfigDict(extra="forbid", strict=True)

    metric: HealthMetricType
    occurred_at: datetime
    value: float | None = None
    unit: str | None = None
    session_id: int | None = None  # For sleep stage events
    stage: str | None = None       # For sleep stage events
    duration_s: int | None = None  # For sleep stage events
    steps: int | None = None
    active_min: int | None = None
    calories: int | None = None
    distance_m: float | None = None
    efficiency_pct: float | None = None
    start_time: datetime | None = None
    end_time: datetime | None = None
    total_s: int | None = None
    awake_s: int | None = None
    deep_s: int | None = None
    rem_s: int | None = None
    light_s: int | None = None

    @field_validator("occurred_at", mode="before")
    @classmethod
    def _parse_occurred_at(cls, v: Any) -> datetime:
        if isinstance(v, str):
            dt = datetime.fromisoformat(v)
            if dt.tzinfo is None:
                raise ValueError("occurred_at must be timezone-aware")
            return dt
        return v

**4. Create `src/surveillance/ingestion/health_writer.py`**

This module contains the async writer that routes health payloads to the correct `health.*` hypertable with idempotent upserts:

```python
"""Async writer for health metric ingestion into health.* hypertables.

P14-006: Routes validated HealthMetricPayload objects to the correct
health.* hypertable using idempotent UPSERT (ON CONFLICT DO NOTHING or
ON CONFLICT DO UPDATE) keyed on (time, device_id, metric).
"""

from __future__ import annotations

import uuid
from datetime import datetime, timezone
from typing import Any, Protocol

import structlog

from src.surveillance.models import HealthMetricPayload, HealthMetricType

logger = structlog.get_logger()

_DEVICE_NAMESPACE: uuid.UUID = uuid.NAMESPACE_DNS

# ---------------------------------------------------------------------------
# Upsert SQL templates per metric type
# ---------------------------------------------------------------------------

_METRIC_UPSERTS: dict[HealthMetricType, str] = {
    HealthMetricType.HEART_RATE: """
        INSERT INTO health.heart_rate (time, device_id, bpm, source, owner_id)
        VALUES (:time, :device_id, :bpm, :source, :owner_id)
        ON CONFLICT (time, device_id, owner_id) DO NOTHING
    """,
    HealthMetricType.SPO2: """
        INSERT INTO health.spo2 (time, device_id, spo2_pct, owner_id)
        VALUES (:time, :device_id, :spo2_pct, :owner_id)
        ON CONFLICT DO NOTHING
    """,
    HealthMetricType.HRV: """
        INSERT INTO health.hrv (time, device_id, rmssd_ms, owner_id)
        VALUES (:time, :device_id, :rmssd_ms, :owner_id)
        ON CONFLICT DO NOTHING
    """,
    HealthMetricType.DAILY_ACTIVITY: """
        INSERT INTO health.daily_activity (date, steps, active_min, calories, distance_m, device_id, owner_id)
        VALUES (:date, :steps, :active_min, :calories, :distance_m, :device_id, :owner_id)
        ON CONFLICT DO NOTHING
    """,
    HealthMetricType.SLEEP_SESSION: """
        INSERT INTO health.sleep_sessions (device_id, start_time, end_time, total_s, awake_s, deep_s, rem_s, light_s, efficiency_pct, owner_id)
        VALUES (:device_id, :start_time, :end_time, :total_s, :awake_s, :deep_s, :rem_s, :light_s, :efficiency_pct, :owner_id)
        ON CONFLICT DO NOTHING
        RETURNING id
    """,
    HealthMetricType.SLEEP_STAGE: """
        INSERT INTO health.sleep_stages (time, session_id, stage, duration_s, device_id, owner_id)
        VALUES (:time, :session_id, :stage, :duration_s, :device_id, :owner_id)
        ON CONFLICT DO NOTHING
    """,
    HealthMetricType.STRESS: """
        INSERT INTO health.stress (time, device_id, stress_score, owner_id)
        VALUES (:time, :device_id, :stress_score, :owner_id)
        ON CONFLICT DO NOTHING
    """,
    HealthMetricType.BODY_BATTERY: """
        INSERT INTO health.body_battery (time, device_id, energy_score, owner_id)
        VALUES (:time, :device_id, :energy_score, :owner_id)
        ON CONFLICT DO NOTHING
    """,
}


class _HealthDBSession(Protocol):
    """Minimal protocol for an async DB session."""

    async def execute(self, statement: Any, params: dict[str, Any] | None = None) -> Any: ...
    async def commit(self) -> None: ...
    async def rollback(self) -> None: ...
    async def close(self) -> None: ...


class HealthIngestionWriter:
    """Routes health metric payloads to the correct health.* hypertable.

    Each write is an idempotent upsert keyed on (time, device_id, metric
    or owner_id) to prevent duplicates from re-synced data.
    """

    def __init__(
        self,
        session_factory: Callable[[], _HealthDBSession],
        default_owner_id: uuid.UUID = uuid.UUID("00000000-0000-0000-0000-000000000001"),
    ) -> None:
        self._session_factory = session_factory
        self._default_owner_id = default_owner_id

    async def write_metric(
        self,
        payload: HealthMetricPayload,
        device_id: str,
        source: str = "gadgetbridge",
    ) -> bool:
        """Route and write a single health metric to its hypertable.

        Args:
            payload: Validated health metric payload.
            device_id: String device identifier.
            source: Data source label ("gadgetbridge" or "mifitness").

        Returns:
            True if the row was inserted (not a duplicate).
        """
        device_uuid = str(uuid.uuid5(_DEVICE_NAMESPACE, device_id))
        upsert_sql = _METRIC_UPSERTS.get(payload.metric)

        if upsert_sql is None:
            logger.warning(
                "health_ingestion_unknown_metric",
                metric=payload.metric,
                device_id=device_id,
            )
            return False

        params = self._build_params(payload, device_uuid, source)
        session = self._session_factory()

        try:
            result = await session.execute(upsert_sql, params)
            await session.commit()
            rowcount = getattr(result, "rowcount", 0)
            inserted = rowcount > 0
            logger.debug(
                "health_metric_written",
                metric=payload.metric,
                device_id=device_id,
                inserted=inserted,
                source=source,
            )
            return inserted
        except Exception:
            await session.rollback()
            logger.exception(
                "health_metric_write_failed",
                metric=payload.metric,
                device_id=device_id,
                source=source,
            )
            return False
        finally:
            await session.close()

    def _build_params(
        self,
        payload: HealthMetricPayload,
        device_uuid: str,
        source: str,
    ) -> dict[str, Any]:
        """Build upsert parameters for a given metric type."""
        base: dict[str, Any] = {
            "device_id": device_uuid,
            "owner_id": str(self._default_owner_id),
        }

        match payload.metric:
            case HealthMetricType.HEART_RATE:
                return {**base, "time": payload.occurred_at, "bpm": int(payload.value or 0), "source": source}
            case HealthMetricType.SPO2:
                return {**base, "time": payload.occurred_at, "spo2_pct": payload.value or 0}
            case HealthMetricType.HRV:
                return {**base, "time": payload.occurred_at, "rmssd_ms": payload.value or 0}
            case HealthMetricType.DAILY_ACTIVITY:
                return {
                    **base,
                    "date": payload.occurred_at.date(),
                    "steps": payload.steps or 0,
                    "active_min": payload.active_min or 0,
                    "calories": payload.calories or 0,
                    "distance_m": payload.distance_m or 0,
                }
            case HealthMetricType.SLEEP_SESSION:
                return {
                    **base,
                    "start_time": payload.start_time or payload.occurred_at,
                    "end_time": payload.end_time or payload.occurred_at,
                    "total_s": payload.total_s,
                    "awake_s": payload.awake_s,
                    "deep_s": payload.deep_s,
                    "rem_s": payload.rem_s,
                    "light_s": payload.light_s,
                    "efficiency_pct": payload.efficiency_pct,
                }
            case HealthMetricType.SLEEP_STAGE:
                return {
                    **base,
                    "time": payload.occurred_at,
                    "session_id": payload.session_id,
                    "stage": payload.stage,
                    "duration_s": payload.duration_s,
                }
            case HealthMetricType.STRESS:
                return {**base, "time": payload.occurred_at, "stress_score": int(payload.value or 0)}
            case HealthMetricType.BODY_BATTERY:
                return {**base, "time": payload.occurred_at, "energy_score": int(payload.value or 0)}

        return base
```

**5. Extend `src/surveillance/router.py` with health-specific POST route**

Add a new endpoint `POST /surveillance/health` that shares the HMAC dependency but routes through the health ingestion path:

```python
# Add to src/surveillance/router.py after existing imports, before surveillance_router definition

from src.surveillance.ingestion.health_writer import HealthIngestionWriter
from src.surveillance.models import HealthMetricPayload

# Add inside the module (after _buffer definition:

@surveillance_router.post(
    "/health",
    response_model=SurveillanceEventResponse,
    status_code=202,
)
async def receive_health_event(
    payload: HealthMetricPayload,
    device_id: str = Header(..., alias="X-Device-ID"),
    auth: HMACVerification = Depends(verify_hmac),
    health_writer: HealthIngestionWriter = Depends(_get_health_writer),
) -> SurveillanceEventResponse:
    """Accept validated health metric data and write to health.* hypertables.

    Shares the same HMAC authentication as /surveillance/events. After
    authentication, the payload is routed directly to the health writer
    (bypassing the generic consumer buffer) for idempotent upsert into
    the appropriate health.* hypertable.

    Consent gate enforcement for ``surveillance.wearable.health.explicit``
    is handled by the health writer internally (fail-closed: undefined
    scope or denied consent → HTTP 403).
    """
    event_id = str(uuid4())

    logger.info(
        "health_event_received",
        metric=payload.metric,
        device_id=device_id,
        event_id=event_id,
        nonce_prefix=auth.nonce[:8] if auth.nonce else None,
    )

    # Consent gate: check surveillance.wearable.health.explicit scope
    try:
        consent_result = await check_consent("surveillance.wearable.health.explicit")
    except Exception:
        logger.exception("health_consent_check_failed", device_id=device_id)
        raise HTTPException(status_code=503, detail="Consent service unavailable — fail-closed")

    if not consent_result.allowed:
        logger.info(
            "health_consent_denied",
            device_id=device_id,
            reason=consent_result.reason,
        )
        raise HTTPException(status_code=403, detail=f"Health data consent required: {consent_result.reason}")

    # Route to health writer
    inserted = await health_writer.write_metric(
        payload=payload,
        device_id=device_id,
        source=payload.source if hasattr(payload, "source") else "gadgetbridge",
    )

    return SurveillanceEventResponse(
        status="accepted",
        event_id=event_id,
        received_at=datetime.now(tz=timezone.utc),
    )
```

def _get_health_writer() -> HealthIngestionWriter:
    global _health_writer
    if _health_writer is None:
        from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker, create_async_engine

        database_url = os.environ.get("DATABASE_URL", "")
        if not database_url:
            db_password = os.environ.get("GUINEVERE_DB_PASSWORD", "")
            database_url = f"postgresql+asyncpg://guinevere:{db_password}@localhost:5433/guinevere"

        engine = create_async_engine(database_url, echo=False, pool_pre_ping=True)
        session_factory = async_sessionmaker(engine, class_=AsyncSession, expire_on_commit=False)

        def _factory() -> Any:
            return session_factory()

        _health_writer = HealthIngestionWriter(session_factory=_factory)
    return _health_writer

## Notes

- Health events bypass the generic `SurveillanceEventRequest` model because the payload shape is metric-dependent. The `HealthMetricPayload` model provides strict validation per metric type.
- The consumer pipeline in `consumer.py` does **not** process health events — they are routed directly in `router.py` via the `/surveillance/health` endpoint. This avoids double-processing and keeps the generic consumer focused on non-health surveillance data.
- Idempotency is guaranteed by `ON CONFLICT DO NOTHING` on the unique constraint `(time, device_id, owner_id)` per hypertable. If duplicate detection needs to change, update the unique indexes in P14-003.
- Source tracking (`gadgetbridge` vs `mifitness`) is stored in the `source` column of `health.heart_rate` and `health.sync_log`. This enables P14-008 fallback gap analysis.
- The 365-day retention for health data is stored as a constant in `retention.py` but the actual TimescaleDB retention policy is configured in P14-003 (`add_retention_policy('health.heart_rate', INTERVAL '365 days')`).
- **WAC-001..007 checklist** (P14-020) must pass before health data collection begins in production. During development, consent scope can be manually set to ACTIVE for testing.
- Cross-reference: P14-005 (Gadgetbridge parser produces the JSON that this endpoint consumes), P14-007 (consent scope registration), P14-008 (Mi Fitness fallback shares the same ingestion path).
