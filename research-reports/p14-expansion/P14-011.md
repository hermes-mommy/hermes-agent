## Goal

Compute the Guinevere Health Index (GHI) — a composite 0-100 score from four weighted pillars (Sleep 40%, Cardio 20%, Activity 20%, Recovery 20%) — daily at 05:00 WIB, stored in `health.ghi_daily`, with 5-tier classification.

---

## Context

GHI is the single-number health summary that drives persona state transitions (P14-013), Discord health commands (P14-016, P14-018), and proactive alerts (P14-019). Each pillar is scored 0-100 based on metric quality vs personal 28-day baseline (P14-009) and clinical targets. Anomaly events from P14-010 apply score penalties.

**Binding Decisions from requirements (Round 3-4):**
- Weighting: Sleep 40% + Cardio 20% + Activity 20% + Recovery 20%
- Tiers: Excellent ≥85 | Good ≥70 | Fair ≥55 | Poor ≥40 | Critical <40
- Sleep pillar: Total duration (7-9h ideal), quality score (efficiency + stage distribution), consistency vs baseline
- Cardio pillar: Resting HR, HRV vs baseline, overnight HR range
- Activity pillar: Steps vs 8000 target, active minutes, calories vs baseline
- Recovery pillar: Stress level, body battery, SpO2 stability
- APScheduler cron: daily at 05:00 WIB (22:00 UTC previous day)
- Warmup: GHI defaults to `None` (not 0) until 28 days of data

"""Guinevere Health Index (GHI) composite score engine.

Computes daily GHI from 4 weighted pillars:
  - Sleep (40%): duration, quality, stage distribution, consistency
  - Cardio (20%): resting HR, HRV, overnight HR
  - Activity (20%): steps vs 8000 target, active minutes, calories
  - Recovery (20%): stress, body battery, SpO2 stability

5 tiers: Excellent ≥85 | Good ≥70 | Fair ≥55 | Poor ≥40 | Critical <40
"""

from __future__ import annotations

# Pillar weights (must sum to 1.0)

CARDIO_WEIGHT = 0.20
ACTIVITY_WEIGHT = 0.20
RECOVERY_WEIGHT = 0.20

# GHI tiers

TIER_GOOD = 70
TIER_FAIR = 55

# Below TIER_POOR → critical

# Clinical targets

def classify_ghi_tier(score: int) -> str:
    """Map GHI score to tier label.

    Raises:
        ValueError: If score is outside 0-100 range.
    """
    if score < 0 or score > 100:
        raise ValueError(f"GHI score must be 0-100, got {score}")
    if score >= TIER_EXCELLENT:
        return "excellent"
    if score >= TIER_GOOD:
        return "good"
    if score >= TIER_FAIR:
        return "fair"
    if score >= TIER_POOR:
        return "poor"
    return "critical"

def _clamp(value: float, min_val: float = 0.0, max_val: float = 100.0) -> float:
    """Clamp a value to [min_val, max_val]."""
    return max(min_val, min(value, max_val))


def score_sleep_pillar(
    duration_hours: float,
    efficiency_pct: float,
    deep_pct: float,
    rem_pct: float,
    consistency: float,  # 0-100: how consistent sleep timing is vs baseline
) -> PillarScore:
    """Score Sleep pillar (0-100).

    - Duration: 7-9 hours = 100 points; outside range scales down linearly.
      - <4h → 0 points; >12h → 0 points (oversleeping also penalized).
    - Efficiency: percentage of time asleep vs time in bed (≥90% = 100 points).
    - Deep sleep: ideal 20-25% of total sleep = 100 points.
    - REM sleep: ideal 20-25% of total sleep = 100 points.
    - Consistency: deviation from baseline sleep time (0 deviation = 100).

    Composite: (duration × 0.35) + (efficiency × 0.20) + (deep × 0.15) + (rem × 0.15) + (consistency × 0.15)
    """
    # Duration score: linear peak at 7-9h
    if duration_hours < 4.0:
        duration_score = 0.0
    elif duration_hours < 7.0:
        duration_score = ((duration_hours - 4.0) / 3.0) * 100.0
    elif duration_hours <= 9.0:
        duration_score = 100.0
    elif duration_hours <= 12.0:
        duration_score = 100.0 - ((duration_hours - 9.0) / 3.0) * 100.0
    else:
        duration_score = 0.0

    # Efficiency: ≥90% = 100, linear below
    efficiency_score = _clamp(efficiency_pct * (100.0 / 90.0))

    # Deep sleep: peak at 20-25%
    deep_score = _clamp(deep_pct * (100.0 / 22.5))

    # REM: peak at 20-25%
    rem_score = _clamp(rem_pct * (100.0 / 22.5))

    # Consistency: 100 - deviation_from_baseline (capped)
    consistency_score = _clamp(100.0 - abs(consistency - 50.0) * 2.0)

    score = int(round(
        duration_score * 0.35
        + efficiency_score * 0.20
        + deep_score * 0.15
        + rem_score * 0.15
        + consistency_score * 0.15
    ))

    return PillarScore(
        score=int(_clamp(score, 0.0, 100.0)),
        label="sleep",
        detail={
            "duration_hours": duration_hours,
            "efficiency_pct": efficiency_pct,
            "deep_pct": deep_pct,
            "rem_pct": rem_pct,
            "consistency": consistency,
        },
    )


def score_cardio_pillar(
    resting_hr: float,
    hrv_ms: float,
    overnight_hr_avg: float,
    baseline_resting_hr: float,
    baseline_hrv: float,
) -> PillarScore:
    """Score Cardio pillar (0-100).

    - Resting HR: 60-70 bpm ideal; >90 → 0; <50 → 90 (athletic, not penalized).
    - HRV: higher is better; compared to baseline (≥baseline = 100).
    - Overnight HR: should be 10-20% below daytime; large elevation = penalty.
    """
    # Resting HR score: 60-70 = 100, linear down to 90 = 0, below 60 = 90+
    if 60.0 <= resting_hr <= 70.0:
        hr_score = 100.0
    elif resting_hr < 60.0:
        hr_score = 90.0 + ((60.0 - resting_hr) / 10.0) * 10.0  # max 100
    elif resting_hr <= 90.0:
        hr_score = 100.0 - ((resting_hr - 70.0) / 20.0) * 100.0
    else:
        hr_score = 0.0

    # HRV score: vs baseline (≥100% of baseline = 100 points)
    if baseline_hrv <= 0 or hrv_ms <= 0:
        hrv_score = 50.0  # neutral if no baseline
    else:
        hrv_score = _clamp((hrv_ms / baseline_hrv) * 100.0)

    # Overnight HR: should be 10-20% below daytime resting
    expected_overnight = resting_hr * 0.85
    if overnight_hr_avg <= expected_overnight:
        overnight_score = 100.0
    elif overnight_hr_avg <= resting_hr:
        overnight_score = 100.0 - ((overnight_hr_avg - expected_overnight) / (resting_hr - expected_overnight)) * 50.0
    else:
        overnight_score = 50.0 - min(50.0, ((overnight_hr_avg - resting_hr) / resting_hr) * 100.0)

    score = int(round(hr_score * 0.40 + hrv_score * 0.35 + overnight_score * 0.25))
    return PillarScore(
        score=int(_clamp(score, 0.0, 100.0)),
        label="cardio",
        detail={
            "resting_hr": resting_hr,
            "hrv_ms": hrv_ms,
            "overnight_hr_avg": overnight_hr_avg,
            "baseline_resting_hr": baseline_resting_hr,
            "baseline_hrv": baseline_hrv,
        },
    )


def score_activity_pillar(
    steps: int,
    active_minutes: int,
    calories: float,
    baseline_steps: float,
    baseline_active_min: float,
) -> PillarScore:
    """Score Activity pillar (0-100).

    - Steps: ≥8000 = 100 points; linear below.
    - Active minutes: ≥30 = 100 points; linear below.
    - Calories: compared to baseline (≥baseline = 100).
    """
    steps_score = _clamp((steps / STEPS_DAILY_TARGET) * 100.0)
    active_score = _clamp((active_minutes / ACTIVE_MINUTES_TARGET) * 100.0)

    if baseline_steps <= 0:
        cal_score = 50.0
    else:
        cal_score = _clamp((calories / (baseline_steps * 0.04)) * 100.0)

    score = int(round(steps_score * 0.50 + active_score * 0.30 + cal_score * 0.20))
    return PillarScore(
        score=int(_clamp(score, 0.0, 100.0)),
        label="activity",
        detail={
            "steps": float(steps),
            "active_minutes": float(active_minutes),
            "calories": calories,
        },
    )


def score_recovery_pillar(
    stress_score: float,
    body_battery: float,
    spo2_avg: float,
    baseline_stress: float,
) -> PillarScore:
    """Score Recovery pillar (0-100).

    - Stress: lower is better; ≤baseline = 100 points.
    - Body battery: higher is better (0-100 scale, used directly).
    - SpO2: ≥95% = 100 points; <90% = 0 points; linear between.
    """
    # Stress: inverted score (lower = better)
    if baseline_stress <= 0:
        stress_norm = 50.0
    elif stress_score <= baseline_stress:
        stress_norm = 100.0
    else:
        stress_norm = _clamp(100.0 - ((stress_score - baseline_stress) / baseline_stress) * 100.0)

    # Body battery: raw 0-100 scale
    battery_score = _clamp(body_battery)

    # SpO2: ≥95 = 100, <90 = 0
    if spo2_avg >= SPO2_NORMAL_MIN:
        spo2_score = 100.0
    elif spo2_avg < 90.0:
        spo2_score = 0.0
    else:
        spo2_score = ((spo2_avg - 90.0) / 5.0) * 100.0

    score = int(round(stress_norm * 0.40 + battery_score * 0.35 + spo2_score * 0.25))
    return PillarScore(
        score=int(_clamp(score, 0.0, 100.0)),
        label="recovery",
        detail={
            "stress_score": stress_score,
            "body_battery": body_battery,
            "spo2_avg": spo2_avg,
        },
    )

async def compute_daily_ghi(
    session: GHISession,
    target_date: date,
    device_id: str,
) -> GHIResult:
    """Compute complete GHI for a single day.

    Args:
        session: Async DB session.
        target_date: Date to compute GHI for.
        device_id: Device UUID for metric queries.

    Returns:
        GHIResult with all pillar scores, composite GHI, and tier.

    Raises:
        ValueError: If insufficient data to compute any pillar.
    """
    # Fetch pillar data from TimescaleDB
    sleep_data = await _fetch_sleep_data(session, target_date, device_id)
    cardio_data = await _fetch_cardio_data(session, target_date, device_id)
    activity_data = await _fetch_activity_data(session, target_date, device_id)
    recovery_data = await _fetch_recovery_data(session, target_date, device_id)

    # Score each pillar
    sleep_pillar = score_sleep_pillar(
        duration_hours=sleep_data.get("duration_hours", 0.0),
        efficiency_pct=sleep_data.get("efficiency_pct", 0.0),
        deep_pct=sleep_data.get("deep_pct", 0.0),
        rem_pct=sleep_data.get("rem_pct", 0.0),
        consistency=sleep_data.get("consistency", 50.0),
    )

    cardio_pillar = score_cardio_pillar(
        resting_hr=cardio_data.get("resting_hr", 70.0),
        hrv_ms=cardio_data.get("hrv_ms", 30.0),
        overnight_hr_avg=cardio_data.get("overnight_hr_avg", 65.0),
        baseline_resting_hr=cardio_data.get("baseline_resting_hr", 70.0),
        baseline_hrv=cardio_data.get("baseline_hrv", 30.0),
    )

    activity_pillar = score_activity_pillar(
        steps=activity_data.get("steps", 0),
        active_minutes=activity_data.get("active_minutes", 0),
        calories=activity_data.get("calories", 0.0),
        baseline_steps=activity_data.get("baseline_steps", 8000.0),
        baseline_active_min=activity_data.get("baseline_active_min", 30.0),
    )

    recovery_pillar = score_recovery_pillar(
        stress_score=recovery_data.get("stress_score", 50.0),
        body_battery=recovery_data.get("body_battery", 50.0),
        spo2_avg=recovery_data.get("spo2_avg", 97.0),
        baseline_stress=recovery_data.get("baseline_stress", 50.0),
    )

    # Count anomaly events for penalty
    anomaly_count = await _count_anomalies(session, target_date, device_id)
    anomaly_penalty = anomaly_count * ANOMALY_PENALTY_PER_EVENT

    # Weighted composite
    raw_ghi = (
        sleep_pillar.score * SLEEP_WEIGHT
        + cardio_pillar.score * CARDIO_WEIGHT
        + activity_pillar.score * ACTIVITY_WEIGHT
        + recovery_pillar.score * RECOVERY_WEIGHT
    )
    ghi_score = int(round(max(0, raw_ghi - anomaly_penalty)))
    ghi_tier = classify_ghi_tier(ghi_score)

    result = GHIResult(
        date=target_date,
        ghi_score=ghi_score,
        ghi_tier=ghi_tier,
        sleep_score=sleep_pillar.score,
        cardio_score=cardio_pillar.score,
        activity_score=activity_pillar.score,
        recovery_score=recovery_pillar.score,
        anomaly_penalty=anomaly_penalty,
        pillars={"sleep": sleep_pillar, "cardio": cardio_pillar, "activity": activity_pillar, "recovery": recovery_pillar},
    )

    logger.info(
        "ghi_computed",
        date=str(target_date),
        ghi=ghi_score,
        tier=ghi_tier,
        pillars={
            "sleep": sleep_pillar.score,
            "cardio": cardio_pillar.score,
            "activity": activity_pillar.score,
            "recovery": recovery_pillar.score,
        },
        anomaly_penalty=anomaly_penalty,
    )
    return result


async def persist_ghi(
    session: GHISession,
    result: GHIResult,
    device_id: str,
) -> None:
    """Store GHI result in health.ghi_daily (upsert)."""
    stmt = """
        INSERT INTO health.ghi_daily
            (date, ghi_score, ghi_tier, sleep_score, cardio_score, activity_score,
             recovery_score, anomaly_penalty, device_id, computed_at)
        VALUES ($1, $2, $3, $4, $5, $6, $7, $8, $9, NOW())
        ON CONFLICT (date, device_id, owner_id)
        DO UPDATE SET
            ghi_score = EXCLUDED.ghi_score,
            ghi_tier = EXCLUDED.ghi_tier,
            sleep_score = EXCLUDED.sleep_score,
            cardio_score = EXCLUDED.cardio_score,
            activity_score = EXCLUDED.activity_score,
            recovery_score = EXCLUDED.recovery_score,
            anomaly_penalty = EXCLUDED.anomaly_penalty,
            computed_at = NOW()
    """
    await session.execute(stmt, (
        result.date,
        result.ghi_score,
        result.ghi_tier,
        result.sleep_score,
        result.cardio_score,
        result.activity_score,
        result.recovery_score,
        result.anomaly_penalty,
        device_id,
    ))


async def _count_anomalies(
    session: GHISession,
    target_date: date,
    device_id: str,
) -> int:
    """Count anomaly events for given date."""
    stmt = """
        SELECT COUNT(*) FROM health.anomaly_events
        WHERE device_id = $1
          AND time::date = $2
    """
    result = await session.execute(stmt, (device_id, target_date))
    row = result.fetchone()
    return row[0] if row else 0

async def _fetch_sleep_data(
    session: GHISession, target_date: date, device_id: str
) -> dict[str, float]:
    """Fetch sleep data for GHI sleep pillar from health.sleep_sessions."""
    stmt = """
        SELECT
            COALESCE(total_s / 3600.0, 0) as duration_hours,
            COALESCE(efficiency_pct, 0) as efficiency_pct,
            COALESCE(deep_s * 100.0 / NULLIF(total_s, 0), 0) as deep_pct,
            COALESCE(rem_s * 100.0 / NULLIF(total_s, 0), 0) as rem_pct,
            50.0 as consistency
        FROM health.sleep_sessions
        WHERE device_id = $1
          AND start_time::date = $2
        ORDER BY total_s DESC
        LIMIT 1
    """
    result = await session.execute(stmt, (device_id, target_date))
    row = result.fetchone()
    if row is None:
        return {"duration_hours": 0.0, "efficiency_pct": 0.0, "deep_pct": 0.0, "rem_pct": 0.0, "consistency": 50.0}
    return dict(zip(["duration_hours", "efficiency_pct", "deep_pct", "rem_pct", "consistency"], row))


async def _fetch_cardio_data(
    session: GHISession, target_date: date, device_id: str
) -> dict[str, float]:
    """Fetch cardio data from health.heart_rate and health.hrv."""
    hr_stmt = """
        SELECT MIN(bpm), MAX(bpm), AVG(bpm), PERCENTILE_CONT(0.1) WITHIN GROUP (ORDER BY bpm)
        FROM health.heart_rate
        WHERE device_id = $1 AND time::date = $2
    """
    hr_result = await session.execute(hr_stmt, (device_id, target_date))
    hr_row = hr_result.fetchone()

    hrv_stmt = """
        SELECT AVG(rmssd_ms) FROM health.hrv
        WHERE device_id = $1 AND time::date = $2
    """
    hrv_result = await session.execute(hrv_stmt, (device_id, target_date))
    hrv_row = hrv_result.fetchone()

    resting_hr = float(hr_row[3]) if hr_row and hr_row[3] else 70.0  # 10th percentile ≈ resting
    overnight_hr_avg = float(hr_row[2]) if hr_row and hr_row[2] else 65.0
    hrv_ms = float(hrv_row[0]) if hrv_row and hrv_row[0] else 30.0

    return {"resting_hr": resting_hr, "hrv_ms": hrv_ms, "overnight_hr_avg": overnight_hr_avg,
            "baseline_resting_hr": resting_hr, "baseline_hrv": hrv_ms}


async def _fetch_activity_data(
    session: GHISession, target_date: date, device_id: str
) -> dict[str, float]:
    """Fetch activity data from health.daily_activity."""
    stmt = """
        SELECT COALESCE(steps, 0), COALESCE(active_min, 0), COALESCE(calories, 0)
        FROM health.daily_activity
        WHERE device_id = $1 AND date = $2
    """
    result = await session.execute(stmt, (device_id, target_date))
    row = result.fetchone()
    if row is None:
        return {"steps": 0.0, "active_minutes": 0.0, "calories": 0.0, "baseline_steps": 8000.0, "baseline_active_min": 30.0}
    return {"steps": float(row[0]), "active_minutes": float(row[1]), "calories": float(row[2]),
            "baseline_steps": max(float(row[0]), 8000.0), "baseline_active_min": max(float(row[1]), 30.0)}


async def _fetch_recovery_data(
    session: GHISession, target_date: date, device_id: str
) -> dict[str, float]:
    """Fetch recovery data from health.stress, health.body_battery, and health.spo2."""
    stress_stmt = "SELECT AVG(score) FROM health.stress WHERE device_id = $1 AND time::date = $2"
    stress_result = await session.execute(stress_stmt, (device_id, target_date))
    stress_row = stress_result.fetchone()

    battery_stmt = "SELECT AVG(energy) FROM health.body_battery WHERE device_id = $1 AND time::date = $2"
    battery_result = await session.execute(battery_stmt, (device_id, target_date))
    battery_row = battery_result.fetchone()

    spo2_stmt = "SELECT AVG(spo2_pct) FROM health.spo2 WHERE device_id = $1 AND time::date = $2"
    spo2_result = await session.execute(spo2_stmt, (device_id, target_date))
    spo2_row = spo2_result.fetchone()

    return {
        "stress_score": float(stress_row[0]) if stress_row and stress_row[0] else 50.0,
        "body_battery": float(battery_row[0]) if battery_row and battery_row[0] else 50.0,
        "spo2_avg": float(spo2_row[0]) if spo2_row and spo2_row[0] else 97.0,
        "baseline_stress": 50.0,
    }

def register_ghi_job(scheduler, session_factory):
    """Register daily GHI computation job (05:00 WIB = 22:00 UTC)."""
    from apscheduler.triggers.cron import CronTrigger

## Troubleshooting

- **Issue:** GHI always returns 0 or very low scores
  - **Solution:** Check that all health tables have data for the target date. Run individual pillar scorer functions with sample data to identify which pillar is returning 0. Verify `ANOMALY_PENALTY_PER_EVENT = 2` — if anomalies are high, penalty may drag score down.

- **Issue:** `classify_ghi_tier()` raises `ValueError`
  - **Solution:** GHI score is outside 0-100 range. Check that pillar scores are clamped and anomaly penalty doesn't push score below 0 (`max(0, raw_ghi - penalty)` handles this). Verify score computations.

- **Issue:** Sleep pillar consistently low despite healthy data
  - **Solution:** Check `consistency` field — default is 50.0 if no baseline comparison available. During warmup, consistency defaults to neutral (50). Review the `_fetch_sleep_data` query to ensure all columns are populated.

- **Issue:** HRV baseline causing division by zero
  - **Solution:** `score_cardio_pillar` has a guard: if `baseline_hrv <= 0`, defaults to neutral (50). Ensure baseline data from P14-009 is populated for HRV. During warmup, this is expected.

- **Issue:** APScheduler job fires but no GHI stored
  - **Solution:** Check logs for `ghi_daily_computation_failed`. Verify device_id UUID is valid. Check that `_fetch_*` queries return non-empty results. Run `compute_daily_ghi()` manually for the current date to isolate the issue.

- **Issue:** Tiers don't match expectations
  - **Solution:** Tier thresholds are hardcoded constants: 85/70/55/40. These can be adjusted post-launch if clinical thresholds differ from initial values. Verify `classify_ghi_tier()` boundary logic — score=85 is "excellent", score=84 is "good".

## Notes

- **Warmup behavior:** During first 28 days, GHI pillars that depend on baselines will use neutral defaults (50). This produces GHI scores that trend toward neutral (50) until baselines stabilize. GHI is computed daily regardless — it just becomes more accurate over time.
- **Anomaly penalty:** Each anomaly event from P14-010 deducts 2 points from raw GHI. This ensures anomalies impact the composite score without dominating it. Critical anomalies (SpO2 < 94%) also contribute penalty but the special rule doesn't double-count.
- **Overnight vs daytime HR:** Overnight HR is approximated by averaging all HR readings for the date. Post-launch enhancement: add explicit overnight window filter (00:00-06:00) for more accurate cardio scoring.
- **Consistency metric:** Activity data consistency (sleep/wake time regularity) requires 7+ days of data for meaningful computation. During warmup, defaults to neutral (50). Full consistency scoring post-launch via P14-009 baseline extension.
- **GHI trend:** `health.ghi_daily` stores one row per day. 7-day/30-day trends are computed at query time (P14-016, P14-023). No separate trend table needed.
- **Timezone:** All computations use UTC internally. WIB offset (+7) applied at the APScheduler cron level (22:00 UTC = 05:00 WIB). Data queries use UTC date boundaries.
- **post-launch enhancements:** Weighted anomaly penalty by severity (moderate=1, high=3, critical=5), per-metric configurable targets, machine learning trend prediction for early warning.
