## Goal

Compare latest health metrics against 28-day personal baselines (computed in P14-009), flag deviations exceeding ±20% threshold, classify severity, and store structured anomaly events in `health.anomaly_events` hypertable.

---

## Context

P14-009 computes rolling 28-day baselines per metric (HR, SpO2, sleep, steps, stress, HRV, body battery). P14-010 consumes those baselines and compares each new ingestion batch against them. This is the first analysis layer that turns raw data into actionable health signals. Anomalies feed downstream into P14-011 (GHI score penalties) and P14-013 (persona state transitions). Critical anomalies also trigger proactive alerts (P14-019).

**Binding Decisions from requirements (Round 2-4):**
- Threshold: ±20% from personal 28-day baseline (clinical reference)
- Severity tiers: moderate (20-35%), high (35-50%), critical (>50%)
- Special rules: SpO2 < 94% always critical regardless of deviation; HR > baseline+20% sustained >30min = high
- Baseline reset: gap > 7 consecutive days resets baseline (handled by P14-009)
- Warmup period: 28 days before metrics are clinically valid (P14-009 handles this)
- APScheduler: run after each ingestion batch (hourly hook) + independent hourly check as safety net

```python
"""Anomaly detection engine for wearable health metrics.

Compares latest metrics against 28-day personal baselines (P14-009).
Flags deviations exceeding threshold with severity classification.

Severity tiers:
  - moderate: 20-35% deviation
  - high: 35-50% deviation
  - critical: >50% deviation OR special rules (SpO2 < 94%, sustained HR)

Special rules (always applied regardless of deviation pct):
  - SpO2 < 94% → critical severity
  - HR > baseline+20% sustained >30 minutes → high severity
"""

from __future__ import annotations

from dataclasses import dataclass
from datetime import datetime, timedelta, timezone
from typing import Protocol, runtime_checkable

import structlog

logger = structlog.get_logger(__name__)

# ---------------------------------------------------------------------------
# Configuration
# ---------------------------------------------------------------------------

DEVIATION_THRESHOLD = 20.0          # ±20% from baseline
MODERATE_THRESHOLD = 35.0           # upper bound for moderate
HIGH_THRESHOLD = 50.0               # upper bound for high (above = critical)
SPO2_CRITICAL_THRESHOLD = 94.0      # SpO2 below this always critical
HR_SUSTAINED_MINUTES = 30           # sustained HR elevation duration
WARMUP_DAYS = 28                    # baseline data required before anomalies valid

# ---------------------------------------------------------------------------
# Exceptions
# ---------------------------------------------------------------------------


class AnomalyDetectionError(Exception):
    """Base exception for anomaly detection errors."""


class BaselineNotReadyError(AnomalyDetectionError):
    """Baseline data insufficient — warmup period not met."""


# ---------------------------------------------------------------------------
# Types
# ---------------------------------------------------------------------------


@dataclass(frozen=True, slots=True)
class Baseline:
    """28-day baseline stats for a single metric."""
    metric: str
    mean: float
    median: float
    stddev: float
    p10: float
    p90: float
    sample_count: int
    computed_at: datetime


@dataclass(frozen=True, slots=True)
class AnomalyEvent:
    """A detected anomaly ready for storage."""
    time: datetime
    device_id: str
    metric: str
    value: float
    baseline_value: float
    deviation_pct: float
    severity: str  # 'moderate' | 'high' | 'critical'


# ---------------------------------------------------------------------------
# DB Session Protocol
# ---------------------------------------------------------------------------


class AnomalyUpsertSession(Protocol):
    """Protocol for async DB session that can INSERT anomaly rows."""

    async def execute(self, stmt: object, params: object | None = ...) -> object: ...


# ---------------------------------------------------------------------------
# Pure functions
# ---------------------------------------------------------------------------


def compute_deviation(value: float, baseline_mean: float) -> float:
    """Compute percentage deviation from baseline mean.

    Returns absolute percentage deviation. Positive = above baseline.

    Raises:
        ValueError: If baseline_mean is zero or negative.
    """
    if baseline_mean <= 0:
        raise ValueError(f"baseline_mean must be positive, got {baseline_mean}")
    return ((value - baseline_mean) / baseline_mean) * 100.0


def classify_severity(
    deviation_pct: float,
    metric: str,
    current_value: float,
    hr_sustained_count: int = 0,
) -> str:
    """Classify anomaly severity based on deviation and special rules.

    Args:
        deviation_pct: Absolute deviation from baseline (can be negative).
        metric: Metric name (e.g. 'spo2', 'heart_rate', 'sleep_duration').
        current_value: Current raw value for special-rule checks.
        hr_sustained_count: Number of consecutive elevated HR readings (5-min intervals).
            If >= 6 (30 min), sustained rule triggers.

    Returns:
        Severity string: 'moderate', 'high', or 'critical'.
    """
    abs_dev = abs(deviation_pct)

    # ---- Special rule: SpO2 always critical below threshold ----
    if metric == "spo2" and current_value < SPO2_CRITICAL_THRESHOLD:
        return "critical"

    # ---- Special rule: sustained HR elevation → high ----
    if metric == "heart_rate" and deviation_pct > 0 and hr_sustained_count >= 6:
        return "high"

    # ---- Standard deviation classification ----
    if abs_dev <= MODERATE_THRESHOLD:
        return "moderate"
    if abs_dev <= HIGH_THRESHOLD:
        return "high"
    return "critical"


def is_baseline_ready(baseline: Baseline | None) -> bool:
    """Check if baseline has sufficient data for valid anomaly detection."""
    if baseline is None:
        return False
    return baseline.sample_count >= WARMUP_DAYS


# ---------------------------------------------------------------------------
# Detection engine
# ---------------------------------------------------------------------------


async def detect_anomalies(
    session: AnomalyUpsertSession,
    metric: str,
    current_values: list[tuple[datetime, str, float]],
    baseline: Baseline | None,
) -> list[AnomalyEvent]:
    """Run anomaly detection for a batch of metric readings.

    Args:
        session: Async DB session for querying sustained HR state.
        metric: Metric name.
        current_values: List of (timestamp, device_id, value) tuples.
        baseline: 28-day baseline stats (or None if not ready).

    Returns:
        List of detected AnomalyEvent objects.

    Raises:
        BaselineNotReadyError: If baseline is None or insufficient samples.
    """
    if not is_baseline_ready(baseline):
        raise BaselineNotReadyError(
            f"Baseline for {metric} has insufficient samples "
            f"({baseline.sample_count if baseline else 0} < {WARMUP_DAYS})"
        )

    # baseline is guaranteed non-None after is_baseline_ready check
    assert baseline is not None

    events: list[AnomalyEvent] = []
    baseline_mean = baseline.mean

    for ts, device_id, value in current_values:
        try:
            deviation = compute_deviation(value, baseline_mean)
        except ValueError:
            logger.warning(
                "anomaly_deviation_skip",
                metric=metric,
                value=value,
                baseline_mean=baseline_mean,
                reason="baseline_mean <= 0",
            )
            continue

        if abs(deviation) < DEVIATION_THRESHOLD:
            continue  # within normal range

        # Compute sustained HR count (simplified — full implementation checks
        # recent readings in DB for timestamp continuity)
        hr_sustained = 0
        if metric == "heart_rate" and deviation > 0:
            hr_sustained = await _count_sustained_elevated(session, device_id, ts)

        severity = classify_severity(deviation, metric, value, hr_sustained)

        event = AnomalyEvent(
            time=ts,
            device_id=device_id,
            metric=metric,
            value=value,
            baseline_value=baseline_mean,
            deviation_pct=deviation,
            severity=severity,
        )
        events.append(event)

    logger.info(
        "anomaly_detection_complete",
        metric=metric,
        readings=len(current_values),
        anomalies=len(events),
    )
    return events


async def _count_sustained_elevated(
    session: AnomalyUpsertSession,
    device_id: str,
    reference_time: datetime,
    lookback_minutes: int = 30,
) -> int:
    """Count consecutive elevated HR readings within lookback window.

    Each reading is ~5 minutes apart; 6 readings = 30 minutes sustained.
    """
    window_start = reference_time - timedelta(minutes=lookback_minutes)
    # Query health.heart_rate for elevated readings in window
    # Returns count of consecutive readings where bpm > baseline
    # (Full implementation uses TimescaleDB time_bucket for efficiency)
    stmt = """
        SELECT COUNT(*) FROM health.heart_rate
        WHERE device_id = $1
          AND time >= $2
          AND time <= $3
    """
    result = await session.execute(stmt, (device_id, window_start, reference_time))
    row = result.fetchone()
    return row[0] if row else 0


async def persist_anomalies(
    session: AnomalyUpsertSession,
    events: list[AnomalyEvent],
) -> int:
    """Insert anomaly events into health.anomaly_events hypertable.

    Args:
        session: Async DB session.
        events: List of AnomalyEvent objects to persist.

    Returns:
        Number of rows inserted.
    """
    if not events:
        return 0

    stmt = """
        INSERT INTO health.anomaly_events (time, device_id, metric, value, baseline_value, deviation_pct, severity)
        VALUES ($1, $2, $3, $4, $5, $6, $7)
    """
    count = 0
    for event in events:
        await session.execute(stmt, (
            event.time,
            event.device_id,
            event.metric,
            event.value,
            event.baseline_value,
            event.deviation_pct,
            event.severity,
        ))
        count += 1

    logger.info("anomalies_persisted", count=count)
    return count


async def run_anomaly_check(
    session: AnomalyUpsertSession,
    metric: str,
) -> list[AnomalyEvent]:
    """Hourly scheduled anomaly check for a single metric.

    Called by APScheduler cron job. Fetches latest readings + baseline,
    runs detection, persists results.

    Returns:
        List of detected AnomalyEvent objects (also persisted to DB).
    """
    from src.surveillance.analysis.baseline import get_baseline  # P14-009

    baseline = await get_baseline(session, metric)
    if not is_baseline_ready(baseline):
        logger.debug("baseline_not_ready", metric=metric)
        return []

    # Fetch latest batch (since last check, ~1 hour window)
    readings = await _fetch_recent_readings(session, metric)
    events = await detect_anomalies(session, metric, readings, baseline)
    await persist_anomalies(session, events)
    return events


async def _fetch_recent_readings(
    session: AnomalyUpsertSession,
    metric: str,
    window_hours: int = 1,
) -> list[tuple[datetime, str, float]]:
    """Fetch recent metric readings from the appropriate health hypertable."""
    table_map = {
        "heart_rate": ("health.heart_rate", "bpm"),
        "spo2": ("health.spo2", "spo2_pct"),
        "hrv": ("health.hrv", "rmssd_ms"),
        "stress": ("health.stress", "score"),
        "body_battery": ("health.body_battery", "energy"),
    }
    if metric not in table_map:
        raise AnomalyDetectionError(f"Unknown metric for anomaly detection: {metric}")

    table, column = table_map[metric]
    since = datetime.now(timezone.utc) - timedelta(hours=window_hours)
    stmt = f"""
        SELECT time, device_id::text, {column} FROM {table}
        WHERE time >= $1
        ORDER BY time ASC
    """
    result = await session.execute(stmt, (since,))
    rows = result.fetchall()
    return [(row[0], row[1], float(row[2])) for row in rows]


# ---------------------------------------------------------------------------
# APScheduler job registration
# ---------------------------------------------------------------------------

ANOMALY_JOB_ID = "p14_anomaly_detection_hourly"

def register_anomaly_job(scheduler, session_factory):
    """Register hourly anomaly detection job with APScheduler.

    Args:
        scheduler: APScheduler instance.
        session_factory: Callable that returns an async DB session.
    """
    from apscheduler.triggers.interval import IntervalTrigger

    async def _job():
        async with session_factory() as session:
            metrics = ["heart_rate", "spo2", "hrv", "stress", "body_battery"]
            for metric in metrics:
                try:
                    await run_anomaly_check(session, metric)
                except BaselineNotReadyError:
                    logger.debug("anomaly_skip_baseline_not_ready", metric=metric)
                except Exception:
                    logger.exception("anomaly_check_failed", metric=metric)

    scheduler.add_job(
        _job,
        trigger=IntervalTrigger(hours=1),
        id=ANOMALY_JOB_ID,
        name="P14 Health Anomaly Detection",
        replace_existing=True,
    )
    logger.info("anomaly_job_registered", job_id=ANOMALY_JOB_ID)
```

## Troubleshooting

- **Issue:** `BaselineNotReadyError` on every run — baseline warmup not complete
  - **Solution:** Wait for 28 days of data (or use mock data generator P14-026). Verify `health.baseline` has sufficient samples with `SELECT metric, sample_count FROM health.baseline`.

- **Issue:** No anomalies detected despite known deviation
  - **Solution:** Check `DEVIATION_THRESHOLD` constant. Verify baseline values are non-zero and realistic. Run `compute_deviation()` manually with sample values.

- **Issue:** HR sustained detection not triggering
  - **Solution:** Check that `health.heart_rate` has readings at ~5-min intervals. The `_count_sustained_elevated` function counts readings in a 30-min window; verify the timestamp alignment.

- **Issue:** SpO2 special rule not applying
  - **Solution:** Verify `SPO2_CRITICAL_THRESHOLD = 94.0` and that `classify_severity()` is called with `metric="spo2"`. Check that current_value is the raw SpO2 percentage, not a deviation.

- **Issue:** APScheduler job not running
  - **Solution:** Verify `guinevere-health.service` is active (`systemctl status guinevere-health`). Check APScheduler logs for registration errors. Ensure `register_anomaly_job()` is called during service startup.

## Notes

- **Warmup period:** Anomaly detection produces no output during the first 28 days of data collection (until `health.baseline` has sufficient samples). This is by design — clinical baselines need statistical significance.
- **Baseline reset:** If P14-009 resets baseline (gap > 7 days), anomaly detection automatically pauses until the new baseline reaches 28 samples. No code changes needed.
- **Mock testing:** Use P14-026 mock data generator to test anomaly detection without waiting 28 days. Configure mock data with known deviations.
- **Performance:** `_fetch_recent_readings` queries 1-hour windows per metric. For high-resolution HR data (~5min intervals), this is ~12 rows per hour — negligible. Monitor query times via Prometheus (P14-022).
- **Downstream consumers:** Anomaly events are read by P14-011 (GHI score penalty), P14-013 (persona state machine), and P14-019 (proactive alerts). No direct Discord output from this module.
- **Metric scope:** Initial release covers `heart_rate`, `spo2`, `hrv`, `stress`, `body_battery`. Sleep and activity anomaly detection added post-launch via `sleep_duration` and `steps` metrics.
- **post-launch enhancements:** Multi-metric correlation (e.g., low SpO2 + high HR = escalate), ML-based anomaly detection as alternative to threshold-based, configurable thresholds per metric via `health.anomaly_config`.
