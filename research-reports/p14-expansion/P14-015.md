## Goal

Implement proactive health distress escalation: when critical health triggers fire, Guinevere sends structured alerts via Discord DM and `#system-health` channel with tiered severity — **NEVER** for behavioral correction, always care-only.

---

## Context

### Why This Exists

P14-010 (Anomaly Detection) flags health anomalies. P14-013 (Persona State Machine) translates them into persona states. But neither takes action — they are diagnostic only. P14-015 is the **action layer**: when Faiz's health metrics cross critical thresholds, Guinevere proactively reaches out.

### Trigger Table

| Trigger | Threshold | Severity | Action |
|---|---|---|---|
| SpO2 low | < 94% | **critical** | DM + `#system-health` + log + suggest medical |
| SpO2 emergency | < 90% | **emergency** | DM + `#system-health` + `#guinevere-health` + escalate to D3 |
| GHI critical | < 40 | **critical** | DM with care message + `#system-health` |
| HR elevated | > baseline +20% sustained >30min | **critical** | DM suggest rest + `#system-health` |
| Sleep deprivation | < 5h for 3 consecutive days | **critical** | DM with concern + `#system-health` |
| Watch battery | < 20% | **info** | `#guinevere-health` only |
| Device stale | No data > 2h | **warn** | `#guinevere-health` only |
| Night owl | Awake past 1 AM | **info** | Gentle DM suggestion (never command) |

### Escalation Levels

```
info     → Log only (structured log entry, no alert)
warn     → Discord #guinevere-health channel alert
critical → DM + #system-health channel + structured log
emergency → DM + #system-health + #guinevere-health + escalate to D3 + suggest medical
```

### Binding Decisions

1. **Cooldown: 30 minutes** between repeated alerts for the same trigger type (Redis-backed TTL).
2. **DM is always care-toned.** No accusation, no blame, no "you should have slept earlier." Format: "Mommy notice [observation]. [Gentle suggestion]."
3. **NEVER use health data for confrontation or behavioral correction.** Hardcoded: escalation messages are template-based with zero behavioral-judgment language.
4. **Emergency protocol (D3):** SpO2 < 90% or HR > 130 sustained triggers PersonaSafetyPolicy distress level D3.
5. **Night owl is suggestion, not command.** "Mommy notice it's late... maybe rest soon?" — NEVER "Go to bed."
6. **No pestering.** Max 3 critical alerts per 24 hours (any trigger type combined). After the 3rd, log-only escalation.

Monitors health anomaly events and persona state from P14-013 and triggers

crossed.

Rules (HARD):
  - NEVER use health data for confrontation, correction, or punishment.

def _route_trigger_to_level(trigger: TriggerType) -> EscalationLevel:
    """Map trigger type to escalation level."""
    routing: dict[TriggerType, EscalationLevel] = {
        TriggerType.SPO2_LOW: EscalationLevel.CRITICAL,
        TriggerType.SPO2_EMERGENCY: EscalationLevel.EMERGENCY,
        TriggerType.GHI_CRITICAL: EscalationLevel.CRITICAL,
        TriggerType.HR_ELEVATED: EscalationLevel.CRITICAL,
        TriggerType.SLEEP_DEPRIVATION: EscalationLevel.CRITICAL,
        TriggerType.WATCH_BATTERY: EscalationLevel.INFO,
        TriggerType.DEVICE_STALE: EscalationLevel.WARN,
        TriggerType.NIGHT_OWL: EscalationLevel.INFO,
    }
    return routing.get(trigger, EscalationLevel.INFO)


def _build_escalation_event(
    trigger: TriggerType,
    *,
    value: str = "N/A",
    baseline: str = "N/A",
    days: int = 0,
    hour: int = NIGHT_OWL_HOUR,
    threshold: str = "N/A",
) -> EscalationEvent:
    """Build a structured EscalationEvent from trigger + parameters.

    All messages use care-toned templates. ZERO behavioral judgment language.
    """
    level = _route_trigger_to_level(trigger)

    title_map: dict[EscalationLevel, str] = {
        EscalationLevel.INFO: "ℹ️ Health Notice",
        EscalationLevel.WARN: "⚠️ Health Warning",
        EscalationLevel.CRITICAL: "🔴 Health Alert",
        EscalationLevel.EMERGENCY: "🚨 EMERGENCY — Health Crisis",
    }

    # Build DM message from templates
    dm_message: str | None = None
    channel_message: str | None = None

    if trigger in _CRITICAL_TEMPLATES:
        template = _CRITICAL_TEMPLATES[trigger]
        dm_message = template.format(
            value=value, baseline=baseline, days=days, threshold=threshold
        )
        channel_message = (
            f"**{title_map[level]}** — {trigger.value}\n"
            f"{dm_message}\n\n"
            f"*Triggered: {datetime.now(WIB).strftime('%Y-%m-%d %H:%M WIB')}*"
        )
    elif trigger in _INFO_TEMPLATES:
        template = _INFO_TEMPLATES[trigger]
        channel_message = template.format(value=value, hour=hour)
        if trigger == TriggerType.NIGHT_OWL:
            dm_message = channel_message  # Gentle DM for night owl

    suggested_action: str | None = None
    escalate_to_d3 = False

    if trigger == TriggerType.SPO2_EMERGENCY:
        suggested_action = (
            "Check breathing. If short of breath/dizzy/chest pain → "
            "seek emergency medical attention immediately."
        )
        escalate_to_d3 = True
    elif trigger == TriggerType.SPO2_LOW:
        suggested_action = "Deep breathing. Monitor for 30 min. Seek medical advice if persists."
    elif trigger == TriggerType.HR_ELEVATED:
        suggested_action = "Rest for 15-30 min. Hydrate. Monitor HR trend."
    elif trigger == TriggerType.SLEEP_DEPRIVATION:
        suggested_action = "Prioritize early bedtime tonight. Avoid caffeine after 4 PM."
    elif trigger == TriggerType.GHI_CRITICAL:
        suggested_action = "Rest, hydrate, eat well. Check individual pillar scores for specifics."

    return EscalationEvent(
        trigger=trigger,
        level=level,
        title=title_map[level],
        description=f"Health distress trigger: {trigger.value}",
        dm_message=dm_message,
        channel_message=channel_message,
        suggested_action=suggested_action,
        escalate_to_d3=escalate_to_d3,
    )


# ---------------------------------------------------------------------------
# Cooldown & Rate Limiting (Redis-backed)
# ---------------------------------------------------------------------------


async def _check_cooldown(
    redis_client: object,
    trigger: TriggerType,
) -> bool:
    """Return True if cooldown is active for this trigger type.

    Uses Redis SET NX with TTL for atomic check-and-set.
    """
    key = f"{REDIS_COOLDOWN_PREFIX}{trigger.value}"
    try:
        # SET key "1" NX EX 1800 → returns True if key was set (cooldown not active)
        # Returns False if key already exists (cooldown active)
        was_set = await redis_client.set(
            key, "1", nx=True, ex=COOLDOWN_SECONDS
        )
        # If was_set is truthy, key was NOT present → cooldown NOT active → return False
        # If was_set is falsy, key WAS present → cooldown IS active → return True
        return not was_set
    except Exception:
        _logger.exception("redis_cooldown_check_failed", extra={"trigger": trigger.value})
        # Fail open on Redis failure: don't block alerts if Redis is down
        return False


async def _check_daily_limit(
    redis_client: object,
) -> bool:
    """Return True if daily critical alert limit has been reached."""
    try:
        count = await redis_client.incr(REDIS_DAILY_COUNTER)
        if count == 1:
            # First increment today — set TTL
            await redis_client.expire(REDIS_DAILY_COUNTER, REDIS_DAILY_COUNTER_TTL)
        return count > MAX_CRITICAL_PER_DAY
    except Exception:
        _logger.exception("redis_daily_counter_failed")
        # Fail open: allow alerts if Redis counter unavailable
        return False

# ---------------------------------------------------------------------------
# Main Escalation Dispatch
# ---------------------------------------------------------------------------


async def dispatch_escalation(
    event: EscalationEvent,
    *,
    redis_client: object | None = None,
) -> dict[str, bool]:
    """Dispatch an escalation event through all applicable channels.

    Channel dispatch per level:
      - info: log only (no Discord)
      - warn: #guinevere-health
      - critical: DM + #system-health + structured log
      - emergency: DM + #system-health + #guinevere-health + D3

    Rate limiting:
      - Cooldown: 30 min between same trigger type.
      - Daily cap: max 3 critical/emergency alerts per 24h.

    Args:
        event: The escalation event to dispatch.
        redis_client: Optional Redis client for cooldown/daily-limit.
                      If None, rate limiting is skipped (useful for testing).

    Returns:
        Dict of channel → success boolean for auditing.
    """
    results: dict[str, bool] = {}

    # ---- Rate Limiting ----------------------------------------------------
    if redis_client is not None:
        if await _check_cooldown(redis_client, event.trigger):
            _logger.info(
                "escalation_cooldown_active",
                extra={"trigger": event.trigger.value},
            )
            results["cooldown_blocked"] = True
            return results

        if event.level in (EscalationLevel.CRITICAL, EscalationLevel.EMERGENCY):
            if await _check_daily_limit(redis_client):
                _logger.warning(
                    "daily_critical_limit_reached",
                    extra={"trigger": event.trigger.value},
                )
                results["daily_limit_blocked"] = True
                # Log only — don't dispatch
                _log_escalation(event, dispatched=False, reason="daily_limit")
                return results

    # ---- Structured Log Entry ---------------------------------------------
    _log_escalation(event, dispatched=True)

    # ---- Dispatch per level -----------------------------------------------
    if event.level == EscalationLevel.INFO:
        # Log only — no Discord messages
        results["logged"] = True

    elif event.level == EscalationLevel.WARN:
        if event.channel_message:
            results["guinevere_health"] = await _post_to_channel(
                CHANNEL_GUINEVERE_HEALTH, event.channel_message
            )

    elif event.level == EscalationLevel.CRITICAL:
        if event.dm_message:
            results["dm"] = await _send_dm_to_faiz(event.dm_message)
        if event.channel_message:
            results["system_health"] = await _post_to_channel(
                CHANNEL_SYSTEM_HEALTH, event.channel_message
            )

    elif event.level == EscalationLevel.EMERGENCY:
        if event.dm_message:
            results["dm"] = await _send_dm_to_faiz(event.dm_message)
        if event.channel_message:
            results["system_health"] = await _post_to_channel(
                CHANNEL_SYSTEM_HEALTH, event.channel_message
            )
            results["guinevere_health"] = await _post_to_channel(
                CHANNEL_GUINEVERE_HEALTH, event.channel_message
            )
        if event.escalate_to_d3:
            await _escalate_to_d3(
                reason=f"{event.trigger.value}: {event.description}"
            )
            results["d3_escalation"] = True

    return results


def _log_escalation(
    event: EscalationEvent,
    *,
    dispatched: bool = True,
    reason: str | None = None,
) -> None:
    """Write structured escalation log entry."""
    _logger.info(
        "health_escalation",
        extra={
            "trigger": event.trigger.value,
            "level": event.level.value,
            "dispatched": dispatched,
            "block_reason": reason,
            "escalate_to_d3": event.escalate_to_d3,
            "timestamp_wib": event.timestamp.astimezone(WIB).isoformat(),
        },
    )

async def evaluate_spo2_trigger(
    spo2_value: float,
    redis_client: object | None = None,
) -> EscalationEvent | None:
    """Evaluate SpO2 reading for escalation triggers.

    Returns None if no threshold crossed.
    """
    if spo2_value <= SPO2_EMERGENCY_THRESHOLD:
        return _build_escalation_event(
            TriggerType.SPO2_EMERGENCY,
            value=f"{spo2_value:.1f}",
        )
    if spo2_value <= SPO2_WARN_THRESHOLD:
        return _build_escalation_event(
            TriggerType.SPO2_LOW,
            value=f"{spo2_value:.1f}",
        )
    return None


async def evaluate_ghi_trigger(
    ghi_score: int,
    redis_client: object | None = None,
) -> EscalationEvent | None:
    """Evaluate GHI score for critical tier escalation."""
    if ghi_score < GHI_CRITICAL_THRESHOLD:
        return _build_escalation_event(
            TriggerType.GHI_CRITICAL,
            value=str(ghi_score),
        )
    return None


async def evaluate_hr_trigger(
    current_bpm: int,
    baseline_bpm: int,
    elevated_duration_min: int,
    redis_client: object | None = None,
) -> EscalationEvent | None:
    """Evaluate heart rate for sustained elevation trigger.

    Only triggers if HR > baseline +20% AND sustained >30 minutes.
    """
    threshold = baseline_bpm * (1 + HR_ELEVATION_PCT / 100)
    if current_bpm > threshold and elevated_duration_min >= HR_ELEVATION_DURATION_MIN:
        return _build_escalation_event(
            TriggerType.HR_ELEVATED,
            value=str(current_bpm),
            baseline=str(baseline_bpm),
        )
    return None


async def evaluate_sleep_trigger(
    sleep_hours: float,
    consecutive_bad_nights: int,
    redis_client: object | None = None,
) -> EscalationEvent | None:
    """Evaluate sleep deprivation for escalation trigger.

    Triggers when sleep < 5h for 3+ consecutive days.
    """
    if (
        sleep_hours < SLEEP_DEPRIVATION_HOURS
        and consecutive_bad_nights >= SLEEP_DEPRIVATION_CONSECUTIVE_DAYS
    ):
        return _build_escalation_event(
            TriggerType.SLEEP_DEPRIVATION,
            value=f"{sleep_hours:.1f}",
            threshold=str(SLEEP_DEPRIVATION_HOURS),
            days=consecutive_bad_nights,
        )
    return None


async def evaluate_night_owl_trigger(
    current_hour_wib: int,
    redis_client: object | None = None,
) -> EscalationEvent | None:
    """Evaluate night owl behavior trigger.

    Triggers if Faiz is active past 1 AM WIB. NEVER commands — gentle suggestion only.
    """
    if current_hour_wib >= NIGHT_OWL_HOUR and current_hour_wib < 5:
        return _build_escalation_event(
            TriggerType.NIGHT_OWL,
            hour=current_hour_wib,
        )
    return None

## Notes

### Safety Boundaries (ABSOLUTE)

1. **All DM templates are care-toned.** Verified by dm-template-audit.md evidence — every template uses "Mommy notice" / "please" / gentle suggestion language. ZERO instances of "you should have," "why didn't you," or any behavioral judgment.
2. **Night owl is suggestion, not command.** Template says "Maybe rest soon? Just a gentle suggestion — no pressure." NEVER "Go to bed" or any commanding language.
3. **Health data NEVER for confrontation.** The escalation engine has no code path that mentions health metrics in a confrontational context. All messages follow the care-only template format.
4. **Emergency triggers → D3 + medical suggestion.** SpO2 < 90% and HR > 130 sustained escalate to PersonaSafetyPolicy D3 per ADR-001 emergency protocol.

### Cooldown Design

- Redis TTL-backed (30 min = 1800s). Atomic via `SET NX EX`.
- If Redis is unavailable, cooldown is skipped (fail-open: alerts still dispatch).
- Daily rate limit also Redis-backed with 24h TTL.
- Max 3 critical + emergency alerts per 24h combined. After limit, log-only.

### Cross-References

- **P14-010** (Anomaly Detection): Source of anomaly events that trigger escalations.
- **P14-013** (Persona State Machine): Persona state is read but NOT used to suppress alerts — even in `stressed` state, critical health alerts fire (safety > persona).
- **P2** (Discord): `send_dm_to_faiz()`, `get_channel_by_name()`, `#system-health` channel.
- **P14-019** (Proactive Health Alerts): The channel-based notification companion step — P14-015 handles the escalation logic; P14-019 handles the scheduled polling.

### Post-Launch Enhancements
