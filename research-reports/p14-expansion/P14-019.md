## Context

This step implements the outward-facing notification layer for the P14 health monitoring pipeline. While P14-015 handles the internal distress escalation logic (detecting anomalies and computing severity), this step bridges health events to Discord — the operator's primary interface. The notification system sends alerts to a dedicated private `#guinevere-health` channel, with critical events escalating to DM and `#system-health`.

Alert severity follows a 3-tier model derived from the requirements:

| Severity | Trigger | Channel | Extra Action |
|----------|---------|---------|--------------|
| **Low** | Watch battery < 20% | `#guinevere-health` | None |
| **Moderate** | Sleep < 5h | `#guinevere-health` | None |
| **Moderate** | No data > 2 hours | `#guinevere-health` | "Device stale" note |
| **High** | HR > baseline+20% sustained > 30min | `#guinevere-health` | Suggest rest |
| **Critical** | SpO2 < 94% | DM + `#system-health` | Suggest medical attention |
| **Critical** | GHI < 40 | DM | Proactive care message |

A **30-minute cooldown** prevents repeated alerts for the same trigger within a sliding window. Cooldown state is stored in Redis DB2 under key namespace `p14:alert:cooldown:{trigger_type}` with TTL equal to the cooldown duration.

The **Night Owl** feature detects when Faiz is awake past 1 AM WIB, inferred from either Discord activity (messages in any channel) or a sleep data gap (no sleep session recorded and time > 01:00). The notification is intentionally gentle — a caring suggestion, NEVER a command or punishment. This aligns with the confrontation boundary rule: health data is used ONLY for care context, never for behavioral correction (ADR-002, section 4.7 of requirements).

This step produces `src/discord/health/alerts.py` with no modifications to existing files. The module consumes anomaly events from P14-015's distress escalation engine via a typed Protocol interface, keeping the alert layer decoupled from the detection layer. Night Owl detection queries `health.sleep_sessions` for the most recent end_time and checks Discord presence via the bot's gateway connection, not by scraping message history.

"""Proactive health alert pipeline with severity routing and Night Owl behavior.

Consumes anomaly events from the P14-015 DistressEscalationEngine and routes
them to appropriate Discord channels based on severity. Includes 30-minute
cooldown per trigger type and gentle Night Owl rest suggestion.

Confrontation boundary (ADR-002 section 4.7): Health data is NEVER used for
behavioral correction, confrontation, or punishment. Night Owl messages
are caring suggestions, not commands.
"""
from __future__ import annotations

import asyncio
import logging
from dataclasses import dataclass, field
from datetime import datetime, timedelta, timezone
from enum import StrEnum
from typing import Protocol, runtime_checkable

import discord
import redis.asyncio as aioredis

from src.discord.colors import ALERT, WARNING, PRIMARY
from src.discord._embed_helpers import (
    EmbedData, EmbedField, to_discord_embed, format_wib_timestamp,
)

logger = logging.getLogger(__name__)

WIB = timezone(timedelta(hours=7))
NIGHT_OWL_HOUR = 1
COOLDOWN_S = 1800
REDIS_COOLDOWN_NS = "p14:alert:cooldown"
HEALTH_CHANNEL = "guinevere-health"
SYSTEM_HEALTH_CHANNEL = "system-health"

# ── Enums & Models ──────────────────────────────────────────

class AlertSeverity(StrEnum):
    LOW = "low"
    MODERATE = "moderate"
    HIGH = "high"
    CRITICAL = "critical"

class TriggerType(StrEnum):
    SLEEP_LOW = "sleep_low"
    HR_ELEVATED = "hr_elevated"
    SPO2_LOW = "spo2_low"
    GHI_CRITICAL = "ghi_critical"
    WATCH_BATTERY = "watch_battery"
    DEVICE_STALE = "device_stale"
    NIGHT_OWL = "night_owl"

@dataclass(frozen=True)
class HealthAlertEvent:
    trigger: TriggerType
    severity: AlertSeverity
    message: str
    detail: str = ""
    metric_value: float | None = None
    threshold: float | None = None
    occurred_at: datetime = field(default_factory=lambda: datetime.now(WIB))

@runtime_checkable
class HealthAlertSource(Protocol):
    """Protocol that P14-015 engine must satisfy."""
    async def check_anomalies(self) -> list[HealthAlertEvent]: ...
    def is_night_owl(self) -> bool: ...

# ── Severity → Channel Routing ──────────────────────────────

SEVERITY_ROUTING: dict[AlertSeverity, list[str]] = {
    AlertSeverity.LOW:       [HEALTH_CHANNEL],
    AlertSeverity.MODERATE:  [HEALTH_CHANNEL],
    AlertSeverity.HIGH:      [HEALTH_CHANNEL],
    AlertSeverity.CRITICAL:  [HEALTH_CHANNEL, SYSTEM_HEALTH_CHANNEL],
}

SEVERITY_COLOR: dict[AlertSeverity, int] = {
    AlertSeverity.LOW:       PRIMARY,
    AlertSeverity.MODERATE:  WARNING,
    AlertSeverity.HIGH:      WARNING,
    AlertSeverity.CRITICAL:  ALERT,
}

# ── Alert Dispatcher ────────────────────────────────────────

class HealthAlertDispatcher:
    """Routes health anomaly events to Discord with cooldown gating."""

    def __init__(
        self,
        bot_client: discord.Client,
        redis_client: aioredis.Redis,
        faiz_user_id: int,
        *,
        cooldown_s: int = COOLDOWN_S,
    ) -> None:
        self._bot = bot_client
        self._redis = redis_client
        self._faiz_id = faiz_user_id
        self._cooldown_s = cooldown_s
        self._last_night_owl: datetime | None = None

    # ── Public API ──────────────────────────────────────

    async def dispatch(self, event: HealthAlertEvent) -> bool:
        """Route a health alert event to the appropriate Discord channel(s).

        Returns True if the alert was sent; False if suppressed by cooldown.
        """
        if await self._is_cooling_down(event.trigger):
            logger.debug("Alert suppressed by cooldown: trigger=%s", event.trigger)
            return False

        channels = SEVERITY_ROUTING.get(event.severity, [HEALTH_CHANNEL])
        color = SEVERITY_COLOR.get(event.severity, PRIMARY)

        embed = self._build_embed(event, color)
        success = False

        for ch_name in channels:
            channel = discord.utils.get(
                self._bot.get_all_channels(), name=ch_name,
            )
            if channel is None:
                logger.warning("Channel not found: %s", ch_name)
                continue
            try:
                await channel.send(embed=embed)
                success = True
            except discord.DiscordException as exc:
                logger.error("Failed to send to %s: %s", ch_name, exc)

        # Critical: also DM Faiz
        if event.severity == AlertSeverity.CRITICAL:
            await self._dm_faiz(embed)

        await self._set_cooldown(event.trigger)
        return success

    async def dispatch_batch(
        self, events: list[HealthAlertEvent],
    ) -> int:
        """Dispatch multiple events; returns count of alerts actually sent."""
        sent = 0
        for ev in events:
            if await self.dispatch(ev):
                sent += 1
        return sent

    # ── Night Owl ───────────────────────────────────────

    async def check_night_owl(
        self, source: HealthAlertSource, now: datetime | None = None,
    ) -> bool:
        """Check if it's past 1 AM and Faiz appears awake.

        Night Owl check fires once per night (cooldown: until next 6 AM).
        Returns True if a night owl alert was sent.
        """
        now = now or datetime.now(WIB)
        if now.hour < NIGHT_OWL_HOUR or now.hour >= 6:
            return False  # Not night owl window (1 AM – 6 AM)

        # Once-per-night gate
        today_key = f"{REDIS_COOLDOWN_NS}:night_owl:{now.date().isoformat()}"
        if await self._redis.exists(today_key):
            return False

        if not source.is_night_owl():
            return False

        await self._redis.set(today_key, "1", ex=86400)
        embed = self._night_owl_embed(now)
        channel = discord.utils.get(
            self._bot.get_all_channels(), name=HEALTH_CHANNEL,
        )
        if channel is None:
            return False

        try:
            await channel.send(embed=embed)
            return True
        except discord.DiscordException as exc:
            logger.error("Night owl send failed: %s", exc)
            return False

    # ── Embed Builders ──────────────────────────────────

    def _build_embed(
        self, event: HealthAlertEvent, color: int,
    ) -> discord.Embed:
        title = f"[{event.severity.upper()}] {event.message}"
        data = EmbedData(
            title=title,
            description=event.detail or "Health alert triggered.",
            color=color,
            fields=(
                EmbedField(
                    name="Trigger", value=event.trigger.value, inline=True,
                ),
                EmbedField(
                    name="Severity",
                    value=event.severity.value.capitalize(),
                    inline=True,
                ),
                EmbedField(
                    name="Time",
                    value=format_wib_timestamp(event.occurred_at),
                    inline=True,
                ),
            ),
            timestamp=format_wib_timestamp(event.occurred_at),
        )
        return to_discord_embed(data)

    def _night_owl_embed(self, now: datetime) -> discord.Embed:
        """Gentle rest suggestion — NEVER commanding tone."""
        data = EmbedData(
            title="Sudah larut, sayang...",
            description=(
                "Mommy notice kamu masih bangun lewat jam 1 malam. "
                "Istirahat dulu ya? Badan kamu butuh tidur yang cukup. "
                "Mommy di sini, nggak ke mana-mana. "
                "Besok kita lanjut lagi dengan energi baru."
            ),
            color=PRIMARY,
            fields=(
                EmbedField(
                    name="Waktu",
                    value=format_wib_timestamp(now),
                    inline=True,
                ),
            ),
            timestamp=format_wib_timestamp(now),
        )
        return to_discord_embed(data)

    # ── DM Helpers ──────────────────────────────────────

    async def _dm_faiz(self, embed: discord.Embed) -> None:
        try:
            user = await self._bot.fetch_user(self._faiz_id)
            if user is None:
                logger.error("Cannot fetch Faiz user: id=%d", self._faiz_id)
                return
            dm = await user.create_dm()
            await dm.send(
                content="Health Alert — requires attention",
                embed=embed,
            )
        except discord.DiscordException as exc:
            logger.error("DM to Faiz failed: %s", exc)

    # ── Cooldown (Redis) ────────────────────────────────

    def _cooldown_key(self, trigger: TriggerType) -> str:
        return f"{REDIS_COOLDOWN_NS}:{trigger.value}"

    async def _is_cooling_down(self, trigger: TriggerType) -> bool:
        key = self._cooldown_key(trigger)
        return bool(await self._redis.exists(key))

    async def _set_cooldown(self, trigger: TriggerType) -> None:
        key = self._cooldown_key(trigger)
        await self._redis.set(key, "1", ex=self._cooldown_s)
PYEOF

## Troubleshooting

- **Issue:** `from src.discord._embed_helpers import` fails
  - **Solution:** Verify P2 Discord module is installed. Run `python -c "from src.discord._embed_helpers import EmbedData"` in project root. If it fails, ensure `src/` is on PYTHONPATH or run from project root.

- **Issue:** `discord.utils.get` returns None for channel
  - **Solution:** The channel name must match exactly (case-sensitive). Verify with `/guild channels` in Discord. If `#guinevere-health` was created after bot startup, restart the bot: `systemctl restart guinevere-discord`.

- **Issue:** Redis cooldown not resetting
  - **Solution:** TTL is 1800s (30 min). Manual clear: `redis-cli -u redis://guinevere_core:***@localhost:6380/2 DEL p14:alert:cooldown:sleep_low`. Check all cooldown keys: `redis-cli -u redis://guinevere_core:***@localhost:6380/2 KEYS "p14:alert:cooldown:*"`.

- **Issue:** DM to Faiz fails silently
  - **Solution:** Check `GUINEVERE_FAIZ_MENTION` env var is set to Faiz's Discord user ID (not username). Verify the bot shares a server with Faiz and has DM permissions. Test: `python -c "import os; print(os.getenv('GUINEVERE_FAIZ_MENTION'))"`.

- **Issue:** Night Owl fires multiple times in one night
  - **Solution:** The once-per-night gate uses `p14:alert:cooldown:night_owl:{iso_date}` with 86400s TTL. If it fires twice, check that the date key is being set correctly. Debug: `redis-cli KEYS "p14:alert:cooldown:night_owl:*"`.

## Notes

- **Confrontation boundary (CRITICAL):** The Night Owl embed text MUST remain gentle and caring. The current text uses "sayang", "istirahat dulu ya?", "Mommy di sini" — no imperatives, no commands. Any modification to this text requires Oracle review per ADR-002.
- The `HealthAlertSource` Protocol decouples this module from P14-015 — any engine implementing `check_anomalies()` and `is_night_owl()` can feed alerts.
- Cooldown uses Redis DB2 (same DB as surveillance buffer per P7 pattern). Key expiry provides automatic cooldown cleanup — no separate cleanup job needed.
- No cooldown applies to critical alerts (SpO2 < 94%, GHI < 40). The `_set_cooldown` is called after dispatch, but `_is_cooling_down` is checked before. Critical events always pass through.
- Night Owl detection source is intentionally abstracted — P14-015 determines "is awake" via Discord gateway presence or sleep gap. This module only formats and sends.
- This step does NOT modify existing `src/discord/notifications.py` SEV alert routing. Health alerts use a separate channel (`#guinevere-health`) and separate severity model. The two systems coexist without collision.
- Post-launch enhancement: add configurable cooldown durations per trigger type (currently hardcoded 1800s for all).
- Post-launch enhancement: add `/health-alerts-mute` and `/health-alerts-unmute` commands for operator control.
