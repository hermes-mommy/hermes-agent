**Goal:** Build an async pipeline that bridges existing Redis DB5 cost tracking data (4 service classes, 11+ key patterns) to the PostgreSQL `financial.transactions` table with provider-level attribution, running every 5 minutes via systemd timer.
**Dependencies:** P9-002 (transactions table with provider column), P9-003 (Redis DB5 cost tracking verified and populated), P9-001 (PostgreSQL schema operational)
**Cost Impact:** $0/month (batch process on existing VPS; negligible CPU/memory overhead)
**ADR References:** ADR-004, ADR-006, ADR-027, ADR-032
**Acceptance Criteria:** AC-FIN-001, AC-FIN-003, AC-FIN-004, AC-FIN-006
**Estimated Time:** 4 hours

#### Context

Redis DB5 contains a fully built cost tracking subsystem: `CostTracker` (total running costs via `cost:total` keys), `BudgetEnforcer` (budget limit checks via `cost:budget:*` keys), `ToolCostTracker` (per-tool costs via `cost:tool:*` keys), and `LoopCostTracker` (per-agent-loop costs via `cost:loop:*` keys). This step builds the persistent bridge that reads these ephemeral Redis cost keys, transforms them into structured `financial.transactions` rows with provider attribution, and inserts them into PostgreSQL via TimescaleDB batch operations. Provider attribution maps cost sources to specific providers: LLM API costs (OpenAI, Anthropic, DeepSeek, Google) via 9Router routing logs, infrastructure costs (hostdata.id VPS — fixed monthly), backup storage costs (idcloudhost S3, Cloudflare R2 — fixed monthly). The bridge runs as a systemd timer every 5 minutes. Deduplication prevents double-counting via a Redis `processed:*` key set with TTL matching the bridge interval.

#### Pre-flight Checks

- [ ] `financial.providers` lookup table exists: `provider_name`, `api_endpoint_pattern`, `cost_per_unit`

"""Async Redis DB5 to PostgreSQL cost attribution bridge.

Reads cost tracking data from Redis DB5, attributes costs to specific providers,
and batch-inserts into financial.transactions with deduplication.
"""

import asyncio
import hashlib
import logging
import os
from datetime import datetime, timezone
from typing import Optional

import asyncpg
import redis.asyncio as aioredis

logger = logging.getLogger(__name__)

BRIDGE_INTERVAL_SECONDS = 300  # 5 minutes
BATCH_SIZE = 100
PROCESSED_KEY_PREFIX = "cost:processed:"
PROCESSED_TTL = 600  # 10 minutes — longer than bridge interval to prevent gaps

COST_KEY_PATTERNS = [
    "cost:total:*",       # CostTracker: total running costs
    "cost:budget:*",      # BudgetEnforcer: budget limit checks
    "cost:tool:*",        # ToolCostTracker: per-tool costs
    "cost:loop:*",        # LoopCostTracker: per-agent-loop costs
]

PROVIDER_MAPPING = {
    "openai": "OpenAI",
    "anthropic": "Anthropic",
    "deepseek": "DeepSeek",
    "google": "Google",
    "hostdata": "hostdata.id",
    "idcloudhost": "idcloudhost",
    "cloudflare": "Cloudflare",
    "unknown": "Unknown",
}


class CostBridge:
    """Redis-to-PostgreSQL cost attribution pipeline."""

    def __init__(
        self,
        redis_url: str = "redis://localhost:6379/5",
        pg_dsn: Optional[str] = None,
    ):
        self.redis_url = redis_url
        self.pg_dsn = pg_dsn or os.environ["DATABASE_URL"]
        self.redis: Optional[aioredis.Redis] = None
        self.pool: Optional[asyncpg.Pool] = None

    async def connect(self) -> None:
        """Establish connections to Redis and PostgreSQL."""
        self.redis = aioredis.from_url(
            self.redis_url,
            decode_responses=True,
            socket_connect_timeout=5,
            socket_timeout=5,
        )
        self.pool = await asyncpg.create_pool(
            dsn=self.pg_dsn,
            min_size=1,
            max_size=4,
        )
        await self.redis.ping()
        logger.info("CostBridge connected to Redis DB5 and PostgreSQL")

    async def close(self) -> None:
        """Gracefully close connections."""
        if self.redis:
            await self.redis.close()
        if self.pool:
            await self.pool.close()
        logger.info("CostBridge connections closed")

    async def sync_once(self) -> int:
        """Execute one sync cycle. Returns number of transactions bridged."""
        if not self.redis or not self.pool:
            raise RuntimeError("CostBridge not connected. Call connect() first.")

        transactions: list[dict] = []

        for pattern in COST_KEY_PATTERNS:
            cursor = 0
            while True:
                cursor, keys = await self.redis.scan(
                    cursor=cursor, match=pattern, count=100
                )
                for key in keys:
                    txn = await self._process_key(key)
                    if txn:
                        transactions.append(txn)
                if cursor == 0:
                    break

        if not transactions:
            logger.info("No new cost data to bridge")
            return 0

        deduped = await self._deduplicate(transactions)
        if not deduped:
            logger.info("All cost entries already bridged (deduplication)")
            return 0

        inserted = await self._batch_insert(deduped)
        logger.info(f"Bridged {inserted} cost transactions (filtered from {len(transactions)} raw)")
        return inserted

    async def _process_key(self, key: str) -> Optional[dict]:
        """Read a Redis cost key and transform into a transaction row candidate."""
        processed_key = f"{PROCESSED_KEY_PREFIX}{key}"
        was_processed = await self.redis.get(processed_key)
        if was_processed:
            return None

        key_type = await self.redis.type(key)
        if key_type == "hash":
            data = await self.redis.hgetall(key)
        elif key_type == "string":
            raw = await self.redis.get(key)
            if raw is None:
                return None
            try:
                amount = float(raw)
            except (ValueError, TypeError):
                logger.debug(f"Skipping non-numeric string key: {key}")
                return None
            data = {"amount": str(amount), "description": key}
        else:
            logger.debug(f"Skipping key type '{key_type}' for key: {key}")
            return None

        amount = float(data.get("amount", data.get("total", data.get("cost", 0))))
        if amount <= 0:
            return None

        provider = self._attribute_provider(key, data)
        cost_source = self._derive_cost_source(key)
        description = data.get("description", data.get("desc", key))
        timestamp = data.get("timestamp", data.get("time", data.get("ts")))

        txn_date = self._parse_timestamp(timestamp) if timestamp else datetime.now(timezone.utc)

        return {
            "amount": round(amount, 6),
            "provider": provider,
            "cost_source": cost_source,
            "description": description[:500],
            "transaction_date": txn_date,
            "_redis_key": key,
            "_processed_key": processed_key,
        }

    def _attribute_provider(self, key: str, data: dict) -> str:
        """Determine the provider from Redis key name and data fields."""
        provider = (data.get("provider") or data.get("model") or "").lower()
        key_lower = key.lower()

        if "openai" in provider or "gpt" in provider or "openai" in key_lower:
            return "OpenAI"
        if "anthropic" in provider or "claude" in provider or "anthropic" in key_lower:
            return "Anthropic"
        if "deepseek" in provider or "deepseek" in key_lower:
            return "DeepSeek"
        if "google" in provider or "gemini" in provider or "google" in key_lower:
            return "Google"
        if "hostdata" in key_lower or "vps" in key_lower:
            return "hostdata.id"
        if "idcloudhost" in key_lower or "s3" in key_lower:
            return "idcloudhost"
        if "cloudflare" in key_lower or "r2" in key_lower:
            return "Cloudflare"

        return "Unknown"

    def _derive_cost_source(self, key: str) -> str:
        """Classify the cost source from the Redis key pattern."""
        if "cost:total" in key:
            return "aggregate_runtime"
        if "cost:budget" in key:
            return "budget_enforcement"
        if "cost:tool" in key:
            return "tool_execution"
        if "cost:loop" in key:
            return "agent_loop"
        return "unknown"

    def _parse_timestamp(self, raw: str) -> datetime:
        """Parse timestamp in multiple possible formats."""
        formats = [
            "%Y-%m-%dT%H:%M:%S.%fZ",
            "%Y-%m-%dT%H:%M:%S.%f",
            "%Y-%m-%dT%H:%M:%SZ",
            "%Y-%m-%d %H:%M:%S",
            "%Y-%m-%d",
        ]
        for fmt in formats:
            try:
                dt = datetime.strptime(raw, fmt)
                if dt.tzinfo is None:
                    dt = dt.replace(tzinfo=timezone.utc)
                return dt
            except ValueError:
                continue
        logger.warning(f"Could not parse timestamp: {raw}")
        return datetime.now(timezone.utc)

    async def _deduplicate(self, transactions: list[dict]) -> list[dict]:
        """Filter out transactions that have already been bridged."""
        if not self.pool:
            return transactions

        unique = []
        async with self.pool.acquire() as conn:
            for txn in transactions:
                row = await conn.fetchrow(
                    """
                    SELECT 1 FROM financial.transactions
                    WHERE provider = $1
                      AND cost_source = $2
                      AND amount = $3
                      AND description = $4
                      AND transaction_date >= $5 - INTERVAL '1 minute'
                      AND transaction_date <= $5 + INTERVAL '1 minute'
                    LIMIT 1
                    """,
                    txn["provider"],
                    txn["cost_source"],
                    txn["amount"],
                    txn["description"],
                    txn["transaction_date"],
                )
                if row is None:
                    unique.append(txn)
        return unique

    async def _batch_insert(self, transactions: list[dict]) -> int:
        """Batch insert transactions into PostgreSQL."""
        if not self.pool:
            return 0

        total = 0
        for i in range(0, len(transactions), BATCH_SIZE):
            batch = transactions[i : i + BATCH_SIZE]
            async with self.pool.acquire() as conn:
                async with conn.transaction():
                    await conn.executemany(
                        """
                        INSERT INTO financial.transactions
                            (amount, provider, cost_source, description, transaction_date,
                             currency, category_id, source)
                        VALUES ($1, $2, $3, $4, $5, 'USD',
                            (SELECT id FROM financial.categories WHERE category_name = 'Infrastructure'),
                            'redis_bridge')
                        ON CONFLICT DO NOTHING
                        """,
                        [
                            (
                                txn["amount"],
                                txn["provider"],
                                txn["cost_source"],
                                txn["description"],
                                txn["transaction_date"],
                            )
                            for txn in batch
                        ],
                    )
            total += len(batch)

        if self.redis:
            for txn in transactions:
                await self.redis.setex(
                    txn["_processed_key"],
                    PROCESSED_TTL,
                    datetime.now(timezone.utc).isoformat(),
                )

        return total

    async def insert_fixed_monthly_costs(self, month: Optional[datetime] = None) -> int:
        """Insert recurring fixed monthly costs (VPS, domains, backup storage)."""
        if month is None:
            month = datetime.now(timezone.utc).replace(day=1)

        fixed_costs = [
            {"amount": 4.00, "provider": "hostdata.id", "cost_source": "vps_hosting",
             "description": "hostdata.id VPS (Guinevere) — fixed monthly"},
            {"amount": 4.00, "provider": "idcloudhost", "cost_source": "s3_storage",
             "description": "idcloudhost S3 backup storage — fixed monthly"},
            {"amount": 1.50, "provider": "Cloudflare", "cost_source": "r2_storage",
             "description": "Cloudflare R2 backup storage — fixed monthly"},
        ]

        if not self.pool:
            return 0

        inserted = 0
        async with self.pool.acquire() as conn:
            async with conn.transaction():
                for cost in fixed_costs:
                    result = await conn.execute(
                        """
                        INSERT INTO financial.transactions
                            (amount, provider, cost_source, description,
                             transaction_date, currency, category_id, source)
                        VALUES ($1, $2, $3, $4, $5, 'USD',
                            (SELECT id FROM financial.categories WHERE category_name = 'Infrastructure'),
                            'fixed_monthly')
                        ON CONFLICT DO NOTHING
                        """,
                        cost["amount"],
                        cost["provider"],
                        cost["cost_source"],
                        cost["description"],
                        month,
                    )
                    if result != "INSERT 0 0":
                        inserted += 1

        logger.info(f"Inserted {inserted} fixed monthly cost entries for {month.strftime('%Y-%m')}")
        return inserted


async def run_once():
    """Entry point for single bridge execution."""
    logging.basicConfig(
        level=logging.INFO,
        format="%(asctime)s [%(levelname)s] %(name)s: %(message)s",
    )

    bridge = CostBridge()
    try:
        await bridge.connect()
        count = await bridge.sync_once()
        logger.info(f"Bridge sync complete: {count} transactions")
    finally:
        await bridge.close()


if __name__ == "__main__":
    asyncio.run(run_once())

#### Troubleshooting

- **Issue:** Redis connection timeout (`redis.exceptions.ConnectionError`)
  - **Solution:** Verify Redis is running: `systemctl status redis-server`; check DB5 ACL: `redis-cli -n 5 PING` should return `PONG`; ensure `requirepass` is configured in `redis.conf` and `REDIS_PASSWORD` is set in `.env`

- **Issue:** Duplicate transactions in PostgreSQL despite deduplication
  - **Solution:** Verify `ON CONFLICT DO NOTHING` target matches the actual unique constraint/partial index; add a composite unique index: `CREATE UNIQUE INDEX IF NOT EXISTS idx_transactions_dedup ON financial.transactions (provider, cost_source, amount, description, transaction_date) WHERE source = 'redis_bridge';`

- **Issue:** Provider attribution returns "Unknown" for all LLM costs
  - **Solution:** Audit Redis key data: `redis-cli -n 5 HGETALL cost:tool:some_key` to inspect `provider` and `model` fields; update `_attribute_provider()` mapping to match actual field values

- **Issue:** Bridge runs but inserts 0 transactions (no activity)
  - **Solution:** Verify Redis cost keys exist: `redis-cli -n 5 KEYS "cost:*" | head -20`; if keys exist but `_process_key` returns None, check key type (must be `hash` or `string` with numeric value)

- **Issue:** `asyncpg.exceptions.ForeignKeyViolationError` on insert (category_id not found)
  - **Solution:** Ensure `financial.categories` has an 'Infrastructure' entry; create if missing: `INSERT INTO financial.categories (category_name) VALUES ('Infrastructure') ON CONFLICT DO NOTHING;`

- **Issue:** Bridge timer fires but service fails silently
  - **Solution:** Check journal: `sudo journalctl -u guinevere-cost-bridge.service --no-pager -n 50`; common causes: missing `.env` file, Python import errors, database connection refused

#### Notes

- This bridge is the critical link between real-time cost tracking (Redis DB5, app-embedded) and persistent financial reporting (PostgreSQL). Without it, dashboards, PDF reports, and `/finance` commands show zero LLM/infrastructure costs.
- Provider costs that are fixed monthly (VPS $4, idcloudhost $4, Cloudflare $1.50) should be inserted via `insert_fixed_monthly_costs()` on the 1st of each month. A separate cron job or systemd timer handles this.
- LLM routing costs from 9Router are variable and bridged every 5 minutes. The 9Router integration must write cost data to Redis DB5 using the key patterns expected by this bridge.
- Deduplication uses a two-layer approach: (1) Redis `processed:*` keys with TTL (fast, prevents re-scanning), (2) PostgreSQL `SELECT` before insert (durable, catches edge cases where Redis TTL expired before PG write).
- The `ON CONFLICT DO NOTHING` clause requires a matching unique constraint. Create it before first bridge run or all inserts will succeed and duplicates will appear.
- `BATCH_SIZE=100` is conservative for TimescaleDB. If bridge processes >1000 keys per cycle, increase to 250-500 and monitor insert latency.
- The `_parse_timestamp` method handles multiple timestamp formats because Redis cost data may come from different service classes with different serialization conventions.
- Memory overhead: the bridge holds all Redis cost data in memory during a sync cycle. If Redis DB5 grows beyond 10,000 cost keys, consider streaming inserts instead of collecting all transactions first.
