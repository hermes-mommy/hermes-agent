**Type:** Application

#### Context

This is the ENTRY POINT for the entire financial tracking pipeline. Tasker on Faiz's Android phone intercepts bank SMS notifications and forwards them via HTTP POST to this endpoint. No e-wallet scraping occurs (per AC-FIN-005 — bank notifications only). The endpoint must: accept POST with SMS body and metadata, authenticate via HMAC-SHA256 using a shared secret, rate-limit to 60 SMS/minute (reasonable for bank notifications — prevents abuse), push raw SMS to Redis queue (`financial.sms_queue`) for async parsing in P9-005, store raw SMS in `financial.transactions` with source='tasker', and return 202 Accepted. The endpoint is exposed only via Tailscale (no public port per ADR-019). Consent: this captures Faiz's own bank notifications on his own device, per surveillance consent policy.

Complete implementation for `src/financial/webhook.py`:

```python
"""Financial SMS webhook endpoint — receives bank notifications from Tasker.

Architecture:
  Tasker (Android) → HTTPS POST → this endpoint → Redis queue → P9-005 parser

Authentication: HMAC-SHA256 with timestamp + nonce + body. 5-min time window.
Rate limiting: 60 SMS/min via Redis sliding window, per IP.
"""

import hashlib
import hmac
import os
import time
from datetime import datetime, timezone
from typing import Annotated
from uuid import uuid4

import structlog
from fastapi import APIRouter, Depends, Header, HTTPException, Request, status
from pydantic import BaseModel, ConfigDict, Field, field_validator
from redis.asyncio import Redis

logger = structlog.get_logger(__name__)

router = APIRouter(tags=["financial"])

# --- Configuration ---
HMAC_SECRET = os.environ.get("FINANCIAL_WEBHOOK_SECRET", "")  # loaded from SOPS at startup
TIME_WINDOW_SECONDS = 300  # 5 minutes
NONCE_TTL_SECONDS = 660     # 2x time window + 60s clock skew buffer
RATE_LIMIT_MAX = 60         # max SMS per minute
RATE_LIMIT_WINDOW = 60      # seconds
SMS_QUEUE_KEY = "financial.sms_queue"
RATE_LIMIT_PREFIX = "financial.rate_limit:"


# --- Models ---
class SmsWebhookPayload(BaseModel):
    """Payload from Tasker SMS forwarding.

    Tasker SMS variables: %SMSRF (sender), %SMSRB (body), %SMSRD (date), %SMSRT (time).
    Alternative AutoNotification: %antitle / %antext / %anapp.
    """

    model_config = ConfigDict(
        extra="forbid",
        strict=True,
        frozen=True,
        str_strip_whitespace=True,
    )

    bank_name: str = Field(
        min_length=2,
        max_length=64,
        description="Bank identifier extracted from SMS sender (e.g., BCA, Mandiri, BNI)",
    )
    account_number: str = Field(
        min_length=4,
        max_length=32,
        pattern=r"^[0-9]+$",
        description="Bank account number from SMS",
    )
    sms_body: str = Field(
        min_length=1,
        max_length=1024,
        description="Raw SMS text body for parsing in P9-005",
    )
    sms_sender: str = Field(
        max_length=64,
        description="SMS sender number/name from %SMSRF",
    )
    sms_date: str = Field(
        max_length=10,
        description="SMS date from %SMSRD (format: YYYY-MM-DD or DD/MM/YYYY)",
    )
    sms_time: str = Field(
        max_length=8,
        description="SMS time from %SMSRT (format: HH:MM:SS)",
    )
    message_hash: str | None = Field(
        default=None,
        max_length=64,
        pattern=r"^[a-f0-9]{64}$",
        description="SHA-256 hash of SMS body for idempotency (prevents duplicate insert)",
    )

    @field_validator("sms_body")
    @classmethod
    def sms_body_not_empty(cls, v: str) -> str:
        stripped = v.strip()
        if not stripped:
            raise ValueError("sms_body must not be empty or whitespace-only")
        return stripped


class WebhookResponse(BaseModel):
    """Standard webhook acknowledgment response."""

    status: str = "accepted"
    message_id: str
    queued: bool = True


# --- Redis Dependency ---
async def get_financial_redis(request: Request) -> Redis:
    """Return Redis connection for financial operations."""
    redis_client: Redis = request.app.state.redis_financial
    return redis_client


# --- HMAC Authentication ---
async def verify_hmac_signature(
    request: Request,
    x_hmac: Annotated[str, Header(alias="X-HMAC")],
    x_nonce: Annotated[str, Header(alias="X-Nonce")],
    x_timestamp: Annotated[str, Header(alias="X-Timestamp")],
    redis: Redis = Depends(get_financial_redis),
) -> None:
    """Verify HMAC-SHA256 signature with replay protection.

    Signature string: timestamp + nonce + raw_request_body
    Header format: X-HMAC: <hex_signature>, X-Nonce: <uuid>, X-Timestamp: <unix_seconds>
    """
    log = logger.bind(
        client_ip=request.client.host if request.client else "unknown",
        endpoint="POST /financial/sms-webhook",
    )

    if not HMAC_SECRET:
        log.error("hmac_secret_not_configured")
        raise HTTPException(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
            detail="Webhook secret not configured",
        )

    # 1. Validate timestamp (must be integer within time window)
    try:
        ts = int(x_timestamp)
    except (ValueError, TypeError):
        log.warning("hmac_auth_failure", reason="invalid_timestamp_format")
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Invalid timestamp format",
        )

    now = int(time.time())
    if abs(now - ts) > TIME_WINDOW_SECONDS:
        log.warning("hmac_auth_failure", reason="expired_timestamp",
                     request_ts=ts, server_ts=now)
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Request timestamp expired",
        )

    # 2. Nonce replay protection (atomic SET NX EX in Redis)
    nonce_key = f"nonce:financial:{x_nonce}"
    is_new = await redis.set(nonce_key, str(ts), nx=True, ex=NONCE_TTL_SECONDS)
    if not is_new:
        log.warning("hmac_replay_detected", nonce_prefix=x_nonce[:8])
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT,
            detail="Nonce already used — replay detected",
        )

    # 3. Verify HMAC signature (constant-time comparison)
    body = await request.body()
    sign_data = f"{ts}{x_nonce}".encode() + body
    expected = hmac.new(
        HMAC_SECRET.encode(), sign_data, hashlib.sha256
    ).hexdigest()

    if not hmac.compare_digest(x_hmac, expected):
        log.warning("hmac_auth_failure", reason="signature_mismatch")
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Invalid HMAC signature",
        )


# --- Rate Limiting ---
async def check_rate_limit(
    request: Request,
    redis: Redis = Depends(get_financial_redis),
) -> None:
    """Sliding window rate limiter: max 60 SMS/min per client IP."""
    client_ip = request.client.host if request.client else "unknown"
    key = f"{RATE_LIMIT_PREFIX}{client_ip}"
    current = await redis.get(key)

    if current is not None and int(current) >= RATE_LIMIT_MAX:
        logger.warning("rate_limit_exceeded", client_ip=client_ip,
                        current_count=current)
        raise HTTPException(
            status_code=status.HTTP_429_TOO_MANY_REQUESTS,
            detail="Rate limit exceeded — max 60 SMS per minute",
            headers={"Retry-After": str(RATE_LIMIT_WINDOW)},
        )

    pipe = redis.pipeline()
    pipe.incr(key)
    pipe.expire(key, RATE_LIMIT_WINDOW)
    await pipe.execute()


# --- Idempotency: SMS Duplicate Detection ---
async def is_duplicate_sms(
    payload: SmsWebhookPayload,
    redis: Redis,
) -> bool:
    """Check if this SMS has already been processed (by SHA-256 hash).

    Returns True if duplicate detected, False if new.
    """
    if not payload.message_hash:
        return False

    dedup_key = f"financial.sms_dedup:{payload.message_hash}"
    is_new = await redis.set(dedup_key, "1", nx=True, ex=86400)  # 24h TTL
    return not is_new


# --- Endpoints ---
@router.get("/financial/health")
async def health_check(redis: Redis = Depends(get_financial_redis)) -> dict:
    """Health check for financial webhook endpoint."""
    try:
        await redis.ping()
        redis_ok = True
    except Exception:
        redis_ok = False

    return {
        "status": "healthy",
        "redis_connected": redis_ok,
        "queue_length": await redis.llen(SMS_QUEUE_KEY) if redis_ok else -1,
    }


@router.post(
    "/financial/sms-webhook",
    response_model=WebhookResponse,
    status_code=status.HTTP_202_ACCEPTED,
)
async def receive_sms_notification(
    payload: SmsWebhookPayload,
    request: Request,
    redis: Redis = Depends(get_financial_redis),
    _auth: None = Depends(verify_hmac_signature),
    _rate: None = Depends(check_rate_limit),
) -> dict:
    """Receive a bank SMS notification from Tasker on Faiz's phone.

    Authentication: HMAC-SHA256 via X-HMAC/X-Nonce/X-Timestamp headers.
    Rate limit: 60 SMS/minute per IP.
    Processing: SMS is queued to Redis LPUSH for async parsing in P9-005,
                and a raw record is inserted into financial.transactions.
    """
    message_id = str(uuid4())

    # Idempotency check — skip if duplicate SMS
    if await is_duplicate_sms(payload, redis):
        logger.info("duplicate_sms_skipped",
                      bank=payload.bank_name,
                      account=payload.account_number[-4:])
        return {
            "status": "duplicate",
            "message_id": message_id,
            "queued": False,
        }

    # Queue to Redis for async parsing (P9-005 consumer reads from this list)
    raw_entry = payload.model_dump_json()
    await redis.lpush(SMS_QUEUE_KEY, raw_entry)
    # Cap queue at 10,000 entries to prevent unbounded growth
    await redis.ltrim(SMS_QUEUE_KEY, 0, 9999)

    # Store raw SMS in transactions table for audit trail
    from src.database import get_async_session
    session_gen = get_async_session()
    session = await anext(session_gen)
    try:
        await session.execute(
            """
            INSERT INTO financial.transactions (
                bank_name, account_number, raw_sms_text, source,
                raw_timestamp, classification_level, data_owner,
                created_at
            ) VALUES (
                :bank_name, :account_number, :sms_body, 'tasker',
                :raw_ts, 'CRITICAL', 'faiz', NOW()
            )
            """,
            {
                "bank_name": payload.bank_name,
                "account_number": payload.account_number,
                "sms_body": payload.sms_body,
                "raw_ts": datetime.now(timezone.utc),
            },
        )
        await session.commit()
    finally:
        await session.close()

    logger.info("sms_received",
                 bank=payload.bank_name,
                 account_masked=payload.account_number[-4:],
                 message_id=message_id,
                 queue_depth=await redis.llen(SMS_QUEUE_KEY))

    return {
        "status": "accepted",
        "message_id": message_id,
        "queued": True,
    }
```

#### Troubleshooting
- **Issue:** HMAC validation always fails — signature mismatch on every request
  - **Solution:** Verify the secret matches between Tasker and the server: `echo -n "TIMESTAMP_NONCE_BODY" | openssl dgst -sha256 -hmac "$SECRET"`. Check that the signing string format is identical — Tasker uses `timestamp + nonce + body` with NO delimiters
- **Issue:** Tasker cannot reach the webhook endpoint (connection refused)
  - **Solution:** Verify Tailscale is connected on both phone and VPS: `tailscale status`. The endpoint listens on `0.0.0.0` but is only reachable via Tailscale IP (no public port). Check that Tasker uses the Tailscale IP, not localhost or public DNS
- **Issue:** Duplicate SMS detection not working — same SMS inserted twice
  - **Solution:** Verify Tasker is computing and sending `message_hash`. The hash must be SHA-256 of the SMS body in hex. If Tasker does not send it, the deduplication is skipped (no error — duplicates are eventually deduplicated by P9-005 parser)
- **Issue:** Redis rate limit key never expires, permanently blocking requests
  - **Solution:** Check `EXPIRE` was called in the pipeline. Verify Redis version >= 2.6 (EXPIRE in pipeline supported). Manual fix: `redis-cli -p 6380 KEYS "financial.rate_limit:*" | xargs redis-cli -p 6380 DEL`
- **Issue:** `ModuleNotFoundError: No module named 'src.database'`
  - **Solution:** The `from src.database import get_async_session` import assumes the project uses the existing database module. If the database module uses a different import path, adjust accordingly. The raw SQL INSERT should use the project's existing SQLAlchemy async session pattern

#### Notes
- Endpoint exposed only via Tailscale (no public port per ADR-019). The FastAPI server listens on `0.0.0.0:8000` but firewall rules restrict access to Tailscale IPs only
- SMS parsing happens in P9-005, NOT here — this step ONLY captures raw data and queues it. The separation ensures that capture can continue even if the parser is temporarily broken
- HMAC secret must be the SAME on both Tasker and the server. Generate once via `openssl rand -hex 32`, store in SOPS on server, enter as Tasker global variable `%GUINEVERE_FINANCIAL_SECRET` on phone
- `message_hash` for idempotency: Tasker computes SHA-256 of the raw SMS body, sends it as `message_hash`. If Tasker cannot compute SHA-256 natively, use the simpler Java bridge pattern from `research-reports/P7/tasker-hmac-patterns.md` Section 5
- Rate limiting at 60 SMS/min is generous for bank notifications (realistically < 10/day). The limit prevents abuse if the endpoint is accidentally exposed or if Tasker goes into a retry loop
- Raw SMS text is stored in `financial.transactions` for audit trail. The `raw_sms_text` column stores the complete message. Sensitive data (account numbers, amounts) will be encrypted at rest via SOPS+age in P9-011
- Tasker configuration reference: use the `SMS Received` event trigger with variables `%SMSRF` (sender), `%SMSRB` (body), `%SMSRD` (date), `%SMSRT` (time). The JavaScriptlet should compute HMAC using Java's `javax.crypto.Mac` (no CryptoJS dependency needed — see P7 tasker-hmac-patterns.md Section 5 for the complete pattern)
- Consent boundary: this captures Faiz's OWN bank notifications on his OWN device. No third-party data. This falls within the surveillance consent policy for operator self-monitoring. If this ever extends to another person's bank data, explicit consent must be obtained and documented
