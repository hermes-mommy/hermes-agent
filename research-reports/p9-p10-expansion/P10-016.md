### Step P10-016: Graceful Shutdown (SIGTERM + Drain)

**Type:** Application
**Status:** Not Started
**Risk:** Medium
**Git Commit:** `feat(P10): pending`

**Goal:** Implement graceful shutdown handling: SIGTERM signal triggers stop accepting new requests, drain in-flight requests (max 30s), close PgBouncer and Redis connections, flush pending logs and metrics, then exit cleanly with code 0.
**Dependencies:** P10-004 (systemd Hardening) — systemd service units defined. P10-015 (Health Check) — draining status endpoint. P0-P8 MVP services: FastAPI app with lifespan, PgBouncer pool, Redis connection pool, Discord.py bot running.
**Cost Impact:** $0/month (embedded in application lifecycle, no additional infrastructure)
**ADR References:** ADR-014 (Containerization and Deployment)
**Acceptance Criteria:** AC-CORE-001 (Daemon runs continuously with systemd supervision), AC-CORE-006 (Runtime config fails closed — draining fails new requests with 503)
**Estimated Time:** 3 hours

#### Context

Without graceful shutdown, systemd `stop` kills the process mid-request with SIGKILL after TimeoutStopSec, causing: lost database transactions, incomplete Discord message sends, orphaned PgBouncer connections, stale Redis key-value writes, and corrupted cost tracking state. Proper shutdown sequence: 1) Catch SIGTERM/SIGINT, 2) Set health check to "draining" (load balancers and systemd see 503, stop routing new traffic), 3) Wait for in-flight requests to complete (max 30s drain timeout), 4) PAUSE + DISCONNECT PgBouncer pool, 5) Close Redis connection pool, 6) Flush pending cost tracker writes to Redis, 7) Log shutdown metrics (requests completed, requests dropped, drain duration), 8) Exit 0. systemd TimeoutStopSec must be > drain timeout + buffer (45s total: 30s drain + 15s safety margin). SIGKILL cannot be caught — if TimeoutStopSec is exceeded, graceful shutdown is bypassed.

"""Graceful shutdown handler for Guinevere production services.

Handles SIGTERM/SIGINT with a drain-and-close sequence:
1. Set draining flag (health check returns 503)
2. Wait for in-flight requests (max DRAIN_TIMEOUT seconds)
3. Close PgBouncer pool
4. Close Redis connection pool
5. Flush pending cost tracker data
6. Log shutdown summary
7. Exit 0

SIGKILL bypasses this handler — TimeoutStopSec must exceed DRAIN_TIMEOUT + buffer.
"""
from __future__ import annotations

import asyncio
import logging
import os
import signal
import sys
import time
from contextlib import asynccontextmanager
from typing import Optional

logger = logging.getLogger("guinevere.shutdown")

# Maximum time to wait for in-flight requests to complete
DRAIN_TIMEOUT: float = float(os.environ.get("GUINEVERE_DRAIN_TIMEOUT", "30.0"))

# Global state for graceful shutdown coordination
_shutting_down: bool = False
_shutdown_event: asyncio.Event = asyncio.Event()
_active_requests: int = 0
_active_requests_lock: asyncio.Lock = asyncio.Lock()
_shutdown_started_at: Optional[float] = None

# References to connection pools (set during app startup)
_pg_pool = None
_redis_pool = None
_cost_tracker = None


def is_shutting_down() -> bool:
    """Check if the server is in draining/shutdown state.

    Used by health check endpoint to return 503 during drain phase.
    """
    return _shutting_down


def is_draining() -> bool:
    """Alias for is_shutting_down — used by load balancer health checks."""
    return _shutting_down


async def increment_active_requests() -> None:
    """Track a new in-flight request.

    Called by middleware at request start.
    """
    global _active_requests
    async with _active_requests_lock:
        _active_requests += 1


async def decrement_active_requests() -> None:
    """Track completion of an in-flight request.

    Called by middleware at request end.
    """
    global _active_requests
    async with _active_requests_lock:
        _active_requests -= 1


async def get_active_requests() -> int:
    """Get current count of in-flight requests."""
    async with _active_requests_lock:
        return _active_requests


def _handle_signal(sig: int, frame: object) -> None:
    """Synchronous signal handler — schedules async shutdown."""
    sig_name = signal.Signals(sig).name
    logger.warning(
        "Received signal %s (%d). Initiating graceful shutdown (drain timeout: %.1fs)...",
        sig_name,
        sig,
        DRAIN_TIMEOUT,
    )
    # Set the shutdown event so the async handler wakes up
    _shutdown_event.set()


def setup_signal_handlers() -> None:
    """Register SIGTERM and SIGINT handlers.

    Called once during application startup.
    """
    signal.signal(signal.SIGTERM, _handle_signal)
    signal.signal(signal.SIGINT, _handle_signal)
    logger.info("Registered SIGTERM and SIGINT handlers")


async def _close_pgbouncer() -> None:
    """Pause and disconnect PgBouncer pool.

    PAUSE stops accepting new connections. DISCONNECT closes active ones.
    This prevents new PostgreSQL connections while draining completes.
    """
    try:
        import asyncpg
        conn = await asyncio.wait_for(
            asyncpg.connect(
                host="127.0.0.1",
                port=6432,
                user="pgbouncer",
                database="pgbouncer",
            ),
            timeout=5.0,
        )
        try:
            await conn.execute("PAUSE guinevere")
            logger.info("PgBouncer pool PAUSED for guinevere database")
            await conn.execute("DISCONNECT guinevere")
            logger.info("PgBouncer pool DISCONNECTED for guinevere database")
        finally:
            await conn.close()
    except ImportError:
        logger.warning("asyncpg not available — skipping PgBouncer shutdown")
    except asyncio.TimeoutError:
        logger.error("PgBouncer PAUSE/DISCONNECT timed out after 5s")
    except Exception as exc:
        logger.error("Failed to close PgBouncer pool: %s", exc)


async def _close_redis() -> None:
    """Close Redis connection pool gracefully."""
    global _redis_pool
    if _redis_pool is not None:
        try:
            await asyncio.wait_for(_redis_pool.disconnect(), timeout=5.0)
            logger.info("Redis connection pool closed")
        except asyncio.TimeoutError:
            logger.error("Redis pool close timed out after 5s")
        except Exception as exc:
            logger.error("Failed to close Redis pool: %s", exc)


async def _flush_cost_tracker() -> None:
    """Flush pending cost tracking data to Redis before shutdown.

    Prevents loss of unbilled tool/task costs during shutdown.
    """
    global _cost_tracker
    if _cost_tracker is not None:
        try:
            if hasattr(_cost_tracker, "flush"):
                await asyncio.wait_for(_cost_tracker.flush(), timeout=5.0)
                logger.info("Cost tracker flushed to Redis")
        except asyncio.TimeoutError:
            logger.error("Cost tracker flush timed out after 5s")
        except Exception as exc:
            logger.error("Failed to flush cost tracker: %s", exc)


async def _shrink_to_zero() -> None:
    """Stop accepting new requests and drain in-flight requests.

    Called after SIGTERM/SIGINT is received.
    """
    global _shutting_down, _shutdown_started_at
    _shutting_down = True
    _shutdown_started_at = time.monotonic()

    logger.info("Draining in-flight requests (max %.1fs)...", DRAIN_TIMEOUT)

    completed_requests = 0
    dropped_requests = 0

    deadline = time.monotonic() + DRAIN_TIMEOUT
    while time.monotonic() < deadline:
        active = await get_active_requests()
        if active == 0:
            completed_requests = 0  # All finished cleanly
            break
        # Log progress every 5 seconds for observability
        if int(time.monotonic()) % 5 == 0:
            logger.info("Still draining: %d active requests remaining...", active)
        await asyncio.sleep(0.1)

    # After deadline: count any requests that didn't complete
    active = await get_active_requests()
    if active > 0:
        dropped_requests = active
        logger.warning(
            "Drain timeout reached after %.1fs — %d request(s) did not complete, proceeding with forced shutdown",
            DRAIN_TIMEOUT,
            dropped_requests,
        )

    drain_duration = time.monotonic() - _shutdown_started_at
    logger.info(
        "Drain complete: %d completed, %d dropped (duration: %.2fs)",
        completed_requests,
        dropped_requests,
        drain_duration,
    )


async def _graceful_shutdown() -> None:
    """Execute full graceful shutdown sequence.

    Called by FastAPI lifespan shutdown event and the signal watcher coroutine.
    """
    logger.info("Starting graceful shutdown sequence...")

    # Phase 1: Stop accepting new traffic
    logger.info("Phase 1/4: Setting draining flag...")
    await _shrink_to_zero()

    # Phase 2: Close database and cache connections
    logger.info("Phase 2/4: Closing connection pools...")
    await asyncio.gather(
        _close_pgbouncer(),
        _close_redis(),
        return_exceptions=True,
    )

    # Phase 3: Flush pending state
    logger.info("Phase 3/4: Flushing pending state...")
    await _flush_cost_tracker()

    # Phase 4: Final cleanup
    logger.info("Phase 4/4: Shutdown complete. Exiting.")
    logger.info("Graceful shutdown finished successfully")

    # Give logs a moment to flush to journald
    await asyncio.sleep(0.5)
    sys.exit(0)


async def shutdown_watcher() -> None:
    """Background coroutine that waits for shutdown signal.

    Run as an asyncio task during application startup.
    When SIGTERM/SIGINT is received, this wakes up and executes
    the graceful shutdown sequence.
    """
    await _shutdown_event.wait()
    logger.info("Shutdown event triggered — beginning graceful shutdown")
    await _graceful_shutdown()


@asynccontextmanager
async def lifespan(app):
    """FastAPI lifespan context manager with graceful shutdown support.

    Usage:
        app = FastAPI(lifespan=lifespan)

    Startup: registers signal handlers, starts shutdown watcher.
    Shutdown: triggers graceful shutdown if not already in progress.
    """
    # Startup
    logger.info("Application starting — registering shutdown handlers")
    setup_signal_handlers()
    watcher_task = asyncio.create_task(shutdown_watcher())
    logger.info("Shutdown watcher started")

    try:
        yield
    finally:
        # Shutdown (called by uvicorn when it receives the signal)
        logger.info("Lifespan shutdown triggered")
        if not _shutting_down:
            # If signal handler hasn't fired yet, trigger shutdown ourselves
            _shutdown_event.set()
            await _graceful_shutdown()
        watcher_task.cancel()
        try:
            await watcher_task
        except asyncio.CancelledError:
            pass
        except Exception:
            pass


def register_pools(
    pg_pool=None,
    redis_pool=None,
    cost_tracker=None,
) -> None:
    """Register connection pool references for shutdown handling.

    Call this during app startup after pools are initialized.
    """
    global _pg_pool, _redis_pool, _cost_tracker
    _pg_pool = pg_pool
    _redis_pool = redis_pool
    _cost_tracker = cost_tracker
    logger.info("Connection pools registered for graceful shutdown")

"""Middleware to track in-flight requests for graceful shutdown."""
from __future__ import annotations

from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request
from starlette.responses import JSONResponse

from src.core.shutdown import (
    decrement_active_requests,
    increment_active_requests,
    is_draining,
)

SHUTDOWN_RESPONSE = JSONResponse(
    status_code=503,
    content={"detail": "Server is shutting down. Please retry later."},
)


class ShutdownMiddleware(BaseHTTPMiddleware):
    """Track active requests and reject new ones during shutdown."""

    async def dispatch(self, request: Request, call_next):
        # Reject new requests if draining
        if is_draining():
            return SHUTDOWN_RESPONSE

        await increment_active_requests()
        try:
            response = await call_next(request)
            return response
        finally:
            await decrement_active_requests()

import asyncio
import httpx
import subprocess
import time


async def test_graceful_shutdown():
    """Test that SIGTERM allows in-flight requests to complete."""
    # Start server in background
    proc = subprocess.Popen(
        ["uv", "run", "uvicorn", "src.core.app:app", "--host", "127.0.0.1", "--port", "9999"],
        stdout=subprocess.PIPE,
        stderr=subprocess.PIPE,
    )
    time.sleep(3)  # Wait for startup

    try:
        # Send a slow request (10s sleep)
        async with httpx.AsyncClient() as client:
            slow_task = asyncio.create_task(
                client.get("http://127.0.0.1:9999/test/sleep?seconds=10", timeout=30)
            )

            await asyncio.sleep(1)  # Let request start processing

            # Send SIGTERM
            proc.terminate()

            # Wait for slow request — should complete before process exits
            try:
                resp = await slow_task
                print(f"PASS: Slow request completed during drain: {resp.status_code}")
            except httpx.ConnectError:
                print("FAIL: Slow request was dropped during SIGTERM")

            # Verify process exits cleanly
            try:
                proc.wait(timeout=50)
                print(f"PASS: Process exited with code {proc.returncode}")
            except subprocess.TimeoutError:
                print("FAIL: Process did not exit within TimeoutStopSec")
                proc.kill()
    finally:
        if proc.poll() is None:
            proc.kill()


if __name__ == "__main__":

#### Troubleshooting
- **Issue:** Process killed by SIGKILL before drain completes
  - **Solution:** Increase TimeoutStopSec beyond DRAIN_TIMEOUT + buffer. Check that DRAIN_TIMEOUT env var is set correctly (default 30s). Verify no long-running requests exceed drain timeout — add request timeout middleware if needed
- **Issue:** PgBouncer PAUSE hangs indefinitely
  - **Solution:** Check for long-running PostgreSQL transactions: `SELECT pid, now() - xact_start AS duration, query FROM pg_stat_activity WHERE state = 'active' ORDER BY duration DESC`. Kill blocking transactions if safe, then retry PAUSE. Add a timeout wrapper around PAUSE call (already in code — 5s timeout)
- **Issue:** systemd kills before TimeoutStopSec (immediate SIGKILL)
  - **Solution:** Verify `SendSIGKILL=yes` is NOT overriding the timeout. Check that `TimeoutStopSec` is in the `[Service]` section, not `[Unit]`. Run `systemctl show guinevere-gateway | grep -E "TimeoutStop|KillSignal|SendSIGKILL"` to verify current settings. systemd version must be >= 220 for TimeoutStopSec support
- **Issue:** Discord.py bot rejects shutdown coordination
  - **Solution:** Discord.py (discord.ext.commands.Bot) has its own close() method. Call `await bot.close()` during shutdown phase 2, before closing Redis (Discord.py may use Redis for its own state). Register the bot reference via `register_pools(bot=bot)` and add bot close to `_graceful_shutdown()`
- **Issue:** Active request counter becomes negative (underflow)
  - **Solution:** This happens if `decrement_active_requests()` is called without matching `increment`. Check middleware ordering — ensure ShutdownMiddleware is the outermost middleware. Verify no exceptions skip the decrement (the try/finally should prevent this)
- **Issue:** 503 response during drain doesn't include Retry-After header
  - **Solution:** Add `Retry-After: 30` header to SHUTDOWN_RESPONSE so clients know to retry after drain timeout. Update the JSONResponse in shutdown_middleware.py to include the header

#### Notes
- SIGKILL cannot be caught by any handler — it's enforced by the kernel. If systemd sends SIGKILL (because TimeoutStopSec expired), graceful shutdown is bypassed completely. Always ensure TimeoutStopSec > DRAIN_TIMEOUT + 15s buffer
- The `DRAIN_TIMEOUT` environment variable allows per-environment tuning without code changes. Production: 30s (generous). Development: 5s (fast iteration)
- Discord.py has its own event loop and shutdown handling. Coordinate with it by calling `await bot.close()` during the connection close phase. If Discord.py is running in a separate process, coordinate via a shared Redis key or systemd PartOf relationship
- The shutdown middleware must be the FIRST middleware registered (outermost layer) so it intercepts all requests before other middleware processing
- Request timeout middleware (not included here) should be added separately to prevent long-running requests from blocking shutdown indefinitely. Set request timeout to < DRAIN_TIMEOUT (e.g., 25s)
- Pool references are set via `register_pools()` rather than global imports to avoid circular dependencies and make testing easier
- The test script (`test_shutdown.py`) is a manual test — integrate into automated CI as part of P10-020 (Hardening Verification)
