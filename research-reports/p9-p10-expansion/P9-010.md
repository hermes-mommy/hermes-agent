#### Context

Research findings confirm WeasyPrint (HTML/CSS-to-PDF rendering, used by French government and multiple EU agencies) as the PDF engine, Jinja2 for HTML templating, and matplotlib with Agg (non-interactive) backend for chart generation. The report includes: executive summary with total spend vs $30 cap, category breakdown pie chart, daily spending trend line chart, top 10 merchants horizontal bar chart, budget utilization gauge per category, and a full transaction table. The pipeline runs via a systemd timer (`guinevere-monthly-report.timer`) at 06:00 WIB on the 1st of each month. Generated PDFs are uploaded to idcloudhost S3 (ADR-032) and delivered to Faiz via Discord DM with the PDF file attachment. Memory usage peaks at ~200MB during chart rendering and PDF generation; schedule during low-usage window.

"""Monthly financial PDF report generator — WeasyPrint + Jinja2 + matplotlib."""

import asyncio
import io
import base64
import logging
import os
from datetime import datetime, timedelta
from pathlib import Path
from typing import Optional

import asyncpg
import boto3
import matplotlib
matplotlib.use("Agg")  # Non-interactive backend — MUST come before pyplot import
import matplotlib.pyplot as plt
import matplotlib.ticker as mticker
from dateutil.relativedelta import relativedelta
from jinja2 import Environment, FileSystemLoader
from weasyprint import HTML

from src.financial.queries import (
    get_category_breakdown,
    get_top_merchants,
    get_daily_spending_trend,
    get_budget_utilization,
)

logger = logging.getLogger(__name__)

TEMPLATE_DIR = Path(__file__).parent / "templates"
MONTHLY_BUDGET_CAP = 30.00
CHART_DPI = 150
CHART_FIGSIZE = (8, 4.5)


class MonthlyPDFReportGenerator:
    """Generates, uploads, and delivers the monthly financial PDF report."""

    def __init__(
        self,
        pool: asyncpg.Pool,
        s3_endpoint: str,
        s3_access_key: str,
        s3_secret_key: str,
        s3_bucket: str,
        discord_user_id: int,
        discord_bot=None,
    ):
        self.pool = pool
        self.s3_endpoint = s3_endpoint
        self.s3_bucket = s3_bucket
        self.discord_user_id = discord_user_id
        self.discord_bot = discord_bot
        self.jinja_env = Environment(
            loader=FileSystemLoader(str(TEMPLATE_DIR)),
            autoescape=True,
        )
        self.s3_client = boto3.client(
            "s3",
            endpoint_url=s3_endpoint,
            aws_access_key_id=s3_access_key,
            aws_secret_access_key=s3_secret_key,
        )

    async def generate_and_deliver(self, target_month: Optional[datetime] = None) -> str:
        """Main pipeline: query -> charts -> HTML -> PDF -> S3 -> Discord."""
        if target_month is None:
            target_month = datetime.utcnow().replace(day=1) - timedelta(days=1)
            target_month = target_month.replace(day=1)

        start = target_month.replace(hour=0, minute=0, second=0, microsecond=0)
        end = (start + relativedelta(months=1)) - timedelta(seconds=1)

        async with self.pool.acquire() as conn:
            cat_breakdown = await get_category_breakdown(conn, start, end)
            top_merchants = await get_top_merchants(conn, start, end, limit=10)
            daily_trend = await get_daily_spending_trend(conn, start, end)
            budget_util = await get_budget_utilization(conn, start, end)

        total_spend = sum(row["total_amount"] for row in cat_breakdown)

        charts = self._generate_charts(cat_breakdown, daily_trend, top_merchants, budget_util)
        html_content = self._render_html(start, total_spend, cat_breakdown, top_merchants, daily_trend, budget_util, charts)
        pdf_bytes = self._generate_pdf(html_content)
        s3_key = self._upload_to_s3(pdf_bytes, start)
        await self._deliver_discord(pdf_bytes, start, total_spend)

        return s3_key

    def _generate_charts(
        self,
        cat_breakdown: list[dict],
        daily_trend: list[dict],
        top_merchants: list[dict],
        budget_util: list[dict],
    ) -> dict[str, str]:
        """Generate matplotlib charts, return dict of base64 PNG strings."""
        charts = {}

        # Pie chart — category breakdown
        fig, ax = plt.subplots(figsize=CHART_FIGSIZE)
        labels = [row["category_name"] for row in cat_breakdown if row["total_amount"] > 0]
        values = [row["total_amount"] for row in cat_breakdown if row["total_amount"] > 0]
        if values:
            wedges, texts, autotexts = ax.pie(
                values, labels=labels, autopct="%1.1f%%",
                startangle=140, pctdistance=0.85,
            )
            for t in autotexts:
                t.set_fontsize(8)
            ax.set_title("Spending by Category")
        else:
            ax.text(0.5, 0.5, "No data", ha="center", va="center", transform=ax.transAxes, fontsize=14)
            ax.set_title("Spending by Category")
        charts["category_pie"] = self._fig_to_base64(fig)
        plt.close(fig)

        # Line chart — daily spending trend
        fig, ax = plt.subplots(figsize=CHART_FIGSIZE)
        if daily_trend:
            dates = [row["date"] for row in daily_trend]
            amounts = [row["daily_total"] for row in daily_trend]
            ax.plot(dates, amounts, marker="o", linewidth=1.5, markersize=3, color="#00D2FF")
            ax.fill_between(range(len(dates)), amounts, alpha=0.1, color="#00D2FF")
            ax.yaxis.set_major_formatter(mticker.FormatStrFormatter("$%.0f"))
            ax.set_title("Daily Spending Trend")
            ax.set_xlabel("Day of Month")
            ax.set_ylabel("Amount (USD)")
            ax.tick_params(axis="x", rotation=45, labelsize=7)
            fig.tight_layout()
        else:
            ax.text(0.5, 0.5, "No data", ha="center", va="center", transform=ax.transAxes, fontsize=14)
            ax.set_title("Daily Spending Trend")
        charts["daily_trend"] = self._fig_to_base64(fig)
        plt.close(fig)

        # Horizontal bar chart — top merchants
        fig, ax = plt.subplots(figsize=CHART_FIGSIZE)
        if top_merchants:
            names = [row["merchant_name"][:20] for row in reversed(top_merchants)]
            amounts_list = [row["total_amount"] for row in reversed(top_merchants)]
            colors = ["#00D2FF" if a < 10 else "#FF6B6B" for a in amounts_list]
            bars = ax.barh(names, amounts_list, color=colors, height=0.6)
            ax.xaxis.set_major_formatter(mticker.FormatStrFormatter("$%.0f"))
            for bar, val in zip(bars, amounts_list):
                ax.text(bar.get_width() + 0.2, bar.get_y() + bar.get_height() / 2,
                        f"${val:,.2f}", va="center", fontsize=7)
            ax.set_title("Top 10 Merchants by Spend")
            fig.tight_layout()
        else:
            ax.text(0.5, 0.5, "No data", ha="center", va="center", transform=ax.transAxes, fontsize=14)
            ax.set_title("Top 10 Merchants")
        charts["top_merchants"] = self._fig_to_base64(fig)
        plt.close(fig)

        # Bar chart — budget utilization
        fig, ax = plt.subplots(figsize=CHART_FIGSIZE)
        if budget_util:
            names_b = [row["category_name"][:15] for row in budget_util]
            utils = [min(row["utilization_pct"], 120) for row in budget_util]
            colors_b = ["#00D2FF" if u < 80 else "#FFD93D" if u < 100 else "#FF6B6B" for u in utils]
            bars_b = ax.bar(names_b, utils, color=colors_b, width=0.5)
            ax.axhline(y=100, color="#FF6B6B", linestyle="--", linewidth=1, alpha=0.7, label="100% cap")
            ax.axhline(y=80, color="#FFD93D", linestyle="--", linewidth=1, alpha=0.7, label="80% warning")
            ax.set_ylabel("Utilization %")
            ax.set_title("Budget Utilization by Category")
            ax.legend(fontsize=7)
            ax.set_ylim(0, 130)
            ax.tick_params(axis="x", rotation=45, labelsize=7)
            fig.tight_layout()
        else:
            ax.text(0.5, 0.5, "No data", ha="center", va="center", transform=ax.transAxes, fontsize=14)
            ax.set_title("Budget Utilization")
        charts["budget_util"] = self._fig_to_base64(fig)
        plt.close(fig)

        return charts

    def _fig_to_base64(self, fig) -> str:
        buf = io.BytesIO()
        fig.savefig(buf, format="png", dpi=CHART_DPI, bbox_inches="tight")
        buf.seek(0)
        encoded = base64.b64encode(buf.read()).decode("utf-8")
        buf.close()
        return f"data:image/png;base64,{encoded}"

    def _render_html(self, start, total_spend, cat_breakdown, top_merchants, daily_trend, budget_util, charts) -> str:
        template = self.jinja_env.get_template("monthly_report.html")
        return template.render(
            report_month=start.strftime("%B %Y"),
            generated_at=datetime.utcnow().strftime("%Y-%m-%d %H:%M UTC"),
            total_spend=total_spend,
            budget_cap=MONTHLY_BUDGET_CAP,
            remaining=MONTHLY_BUDGET_CAP - total_spend,
            percent_used=(total_spend / MONTHLY_BUDGET_CAP * 100) if MONTHLY_BUDGET_CAP > 0 else 0,
            category_breakdown=cat_breakdown,
            top_merchants=top_merchants,
            daily_trend=daily_trend,
            budget_utilization=budget_util,
            charts=charts,
        )

    def _generate_pdf(self, html_content: str) -> bytes:
        doc = HTML(string=html_content)
        return doc.write_pdf(
            presentational_hints=True,
            optimize_images=True,
        )

    def _upload_to_s3(self, pdf_bytes: bytes, report_month: datetime) -> str:
        key = f"reports/financial/{report_month.strftime('%Y-%m')}_guinevere_financial_report.pdf"
        self.s3_client.put_object(
            Bucket=self.s3_bucket,
            Key=key,
            Body=pdf_bytes,
            ContentType="application/pdf",
            CacheControl="max-age=2592000",
        )
        logger.info(f"PDF uploaded to s3://{self.s3_bucket}/{key}")
        return key

    async def _deliver_discord(self, pdf_bytes: bytes, report_month: datetime, total_spend: float) -> None:
        if self.discord_bot is None:
            logger.warning("Discord bot not available, skipping DM delivery")
            return

        user = await self.discord_bot.fetch_user(self.discord_user_id)
        if user is None:
            logger.error(f"Discord user {self.discord_user_id} not found")
            return

        embed = discord.Embed(
            title=f"Monthly Financial Report — {report_month.strftime('%B %Y')}",
            description=(
                f"**Total Spend:** ${total_spend:,.2f} / ${MONTHLY_BUDGET_CAP:,.2f}\n"
                f"**Remaining:** ${MONTHLY_BUDGET_CAP - total_spend:,.2f}"
            ),
            color=0x00D2FF if total_spend <= MONTHLY_BUDGET_CAP else 0xFF0000,
        )
        embed.set_footer(text="Guinevere FinOps — Automated Monthly Report")

        pdf_file = discord.File(
            io.BytesIO(pdf_bytes),
            filename=f"guinevere_financial_{report_month.strftime('%Y_%m')}.pdf",
        )

        await user.send(embed=embed, file=pdf_file)
        logger.info(f"Report delivered to Discord user {self.discord_user_id}")

"""CLI entry point to trigger a monthly report manually."""

import asyncio
import logging
import os
from datetime import datetime

import asyncpg

from src.financial.reports.pdf_generator import MonthlyPDFReportGenerator

logging.basicConfig(level=logging.INFO, format="%(asctime)s [%(levelname)s] %(name)s: %(message)s")


async def main():
    pool = await asyncpg.create_pool(
        dsn=os.environ["DATABASE_URL"],
        min_size=1,
        max_size=2,
    )

    generator = MonthlyPDFReportGenerator(
        pool=pool,
        s3_endpoint=os.environ["S3_ENDPOINT"],
        s3_access_key=os.environ["S3_ACCESS_KEY"],
        s3_secret_key=os.environ["S3_SECRET_KEY"],
        s3_bucket=os.environ["S3_BUCKET"],
        discord_user_id=int(os.environ["FAIZ_DISCORD_USER_ID"]),
        discord_bot=None,  # Manual run — no Discord delivery
    )

    target = datetime.utcnow().replace(day=1) - __import__("datetime").timedelta(days=1)
    target = target.replace(day=1)

    s3_key = await generator.generate_and_deliver(target_month=target)
    logging.getLogger(__name__).info(f"Report generated: {s3_key}")

    await pool.close()


if __name__ == "__main__":
    asyncio.run(main())

#### Troubleshooting

- **Issue:** WeasyPrint raises `OSError: cannot load library 'libpango-1.0-0'`
  - **Solution:** Install missing system font/render packages: `sudo apt-get install -y libpango-1.0-0 libpangocairo-1.0-0 libcairo2 fonts-noto`

- **Issue:** PDF has blank/empty charts (white boxes instead of images)
  - **Solution:** Verify `matplotlib.use("Agg")` is called before any `import matplotlib.pyplot`; add `assert matplotlib.get_backend() == "agg"` in generator `__init__`

- **Issue:** Matplotlib `RuntimeError: main thread is not in main loop`
  - **Solution:** Replace any interactive pyplot calls; use only `Figure` + `Axes` objects; always call `plt.close(fig)` after `savefig`

- **Issue:** S3 upload fails with `EndpointConnectionError`
  - **Solution:** Verify `S3_ENDPOINT` URL includes protocol (`https://`); test connectivity: `curl -I $S3_ENDPOINT`; implement retry with exponential backoff (3 retries, 2s/4s/8s)

- **Issue:** Discord DM fails because user has DMs closed

#### Notes

- WeasyPrint renders CSS `@page` rules for headers/footers and page numbering. The template uses `@bottom-center` for "Page X of Y".
- Chart images are embedded as base64 data URIs in the HTML — no external image file dependencies. This keeps the PDF self-contained.
- The `boto3` S3 client uses `endpoint_url` for idcloudhost compatibility (not AWS native). Verify the endpoint accepts path-style or virtual-hosted-style addressing.
- Systemd `RandomizedDelaySec=300` staggers execution within a 5-minute window to avoid thundering herd with other cron jobs.
- Budget utilization gauge in HTML uses CSS `div` bars with dynamic width percentages — no JavaScript needed.
- Font fallback chain: `Noto Sans` -> `DejaVu Sans` -> `sans-serif`. `fonts-noto` covers Latin + CJK characters for merchant names in any language.
- The manual test command (`systemctl start guinevere-monthly-report.service`) uses `RemainAfterExit=no` (oneshot default), so it can be triggered multiple times for testing without cleanup.
