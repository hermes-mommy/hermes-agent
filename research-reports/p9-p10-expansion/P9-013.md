        async with httpx.AsyncClient(base_url=API_BASE, timeout=30) as client:

            for bank, samples in SYNTHETIC_SMS_FIXTURES.items():
                for sample in samples:
                    resp = await client.post(
                        "/api/webhooks/tasker/sms",
                        json={
                            "sender": bank,
                            "message": sample["raw"],
                            "received_at": datetime.utcnow().isoformat(),
                            "source": TEST_SOURCE,
                        },
                    )
                    assert resp.status_code in (200, 201, 202), (
                        f"{bank}: webhook rejected ({resp.status_code}): {resp.text[:200]}"
                    )
                    count += 1
        assert count == TOTAL_SMS_COUNT, f"Expected {TOTAL_SMS_COUNT}, processed {count}"

#### Troubleshooting

- **Issue:** Test isolation failure — test data from prior run contaminates current run
  - **Solution:** Ensure `cleanup_test_data` fixture runs before each class; add `DROP TABLE IF EXISTS financial.transactions_test_backup`; run with `--forked` if needed

- **Issue:** Flaky async tests — `httpx` requests sometimes timeout
  - **Solution:** Increase httpx timeout to 30: `httpx.AsyncClient(timeout=30)`; add retry decorator: `@pytest.mark.flaky(reruns=2)`; ensure webhook processing is async (not blocking the response)

- **Issue:** Discord command tests fail because bot is not running
  - **Solution:** Tests use database queries directly as fallback (no bot dependency); verify `DATABASE_URL` is set and pointing to a database with test data

- **Issue:** Grafana API returns 401 (unauthorized)
  - **Solution:** Generate Grafana API token: Grafana UI > Configuration > API Keys > Add API Key (role: Viewer); set `GRAFANA_API_TOKEN` in test environment

- **Issue:** PDF test fails with `PyPDF2.errors.PdfReadError: EOF marker not found`
  - **Solution:** Verify WeasyPrint generates valid PDF: check HTML content has no unclosed tags; test WeasyPrint standalone: `echo "<html><body><p>test</p></body></html>" | weasyprint - test.pdf && python -c "from PyPDF2 import PdfReader; PdfReader('test.pdf')"`

- **Issue:** Provider bridge test skips because Redis is not reachable
  - **Solution:** Set up test Redis instance (Docker): `docker run -d --name redis-test -p 6380:6379 redis:7-alpine`; configure `REDIS_URL=redis://localhost:6380/5`; seed test cost keys before running bridge test

- **Issue:** Test suite runs too long (>120s)
  - **Solution:** Reduce synthetic SMS count from 50 to 25 for CI runs; mark slow tests with `@pytest.mark.slow` and exclude in CI: `-m "not slow"`; use `pytest-xdist` for parallel execution: `pytest -n auto`
