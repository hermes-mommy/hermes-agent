### Step P9-011: FinOps Dashboard — grafanalib + Grafana File Provisioning

**Type:** Application
**Status:** ⬜ Not Started
**Risk:** Medium
**Git Commit:** `feat(P9): FinOps Grafana dashboard via grafanalib`

**Goal:** Provision a Grafana dashboard for financial metrics using grafanalib (Python-to-JSON) with file-based provisioning, showing total spend, trends, category breakdowns, budget utilization, and cost projections.
**Dependencies:** P9-002 (transactions table populated), P9-007 (budget tracking operational), P8 complete (Grafana running with TimescaleDB datasource)
**Cost Impact:** $0/month (self-hosted Grafana, existing infrastructure)
**ADR References:** ADR-017, ADR-032
**Acceptance Criteria:** AC-FIN-001, AC-FIN-006, AC-OPS-002
**Estimated Time:** 4 hours

#### Context

Research recommendations from RisingWave, TiKV, and Scality production deployments confirm grafanalib as the standard approach for Python-defined Grafana dashboards. The library generates JSON dashboard models from Python code, which Grafana loads via file-based provisioning (no API calls needed). This step creates a `dashboards/financial.py` definition with 6 panels: total spend gauge vs $30 cap, daily spend timeseries, category breakdown pie chart, budget utilization horizontal bar, alert status stat panel, and month-end cost projection with linear forecast. The datasource is PostgreSQL `financial` schema with TimescaleDB extension. Dashboard is provisioned via a YAML provider config that Grafana's file provisioner watches. Access is via Tailscale only at `https://grafana.guinevere.ts.net/d/financial/finops`.

#### Pre-flight Checks

- [ ] Grafana service is running: `systemctl status grafana-server` shows `active (running)`

- [ ] Grafana provisioning directory exists: `/etc/grafana/provisioning/dashboards/`
- [ ] `grafana.ini` has `[dashboards]` and `[paths]` provisioning config enabled

"""Grafana FinOps dashboard — generated via grafanalib."""

from grafanalib.core import (
    Dashboard,
    Row,
    GaugePanel,
    Graph,
    PieChart,
    BarGauge,
    Stat,
    TimeSeries,
    SingleStat,
    Target,
    SqlTarget,
    Threshold,
    GridPos,
    YAxis,
    Time,
)
from grafanalib._gen import DashboardEncoder
import json

DATASOURCE_UID = "timescaledb-financial"
DASHBOARD_UID = "financial-finops"
BUDGET_CAP = 30

dashboard = Dashboard(
    title="Guinevere FinOps",
    description="Financial tracking dashboard for Guinevere autonomous system. Budget cap: $30/month.",
    tags=["guinevere", "finops", "financial", "costs"],
    timezone="browser",
    uid=DASHBOARD_UID,
    editable=False,
    refresh="5m",
    time=Time("now-30d", "now"),
    panels=[
        Row(title="Overview", gridPos=GridPos(h=1, w=24, x=0, y=0)),
        GaugePanel(
            title="Total Spend vs $30 Cap",
            dataSource=DATASOURCE_UID,
            targets=[
                SqlTarget(
                    rawSql="""
                    SELECT
                        'spend' AS metric,
                        COALESCE(SUM(amount), 0) AS value
                    FROM financial.transactions
                    WHERE transaction_date >= date_trunc('month', now())
                    """
                ),
            ],
            gridPos=GridPos(h=8, w=8, x=0, y=1),
            minValue=0,
            maxValue=BUDGET_CAP + 5,
            thresholds=[
                Threshold("green", 0, 20),
                Threshold("yellow", 20, 28),
                Threshold("orange", 28, 30),
                Threshold("red", 30, 35),
            ],
            valueMappings=[],
            unit="currencyUSD",
        ),
        Stat(
            title="Alert Status",
            dataSource=DATASOURCE_UID,
            targets=[
                SqlTarget(
                    rawSql="""
                    SELECT
                        CASE
                            WHEN SUM(amount) >= 30 THEN 'BUDGET EXCEEDED'
                            WHEN SUM(amount) >= 24 THEN 'WARNING: 80%+'
                            WHEN SUM(amount) >= 20 THEN 'MONITORING'
                            ELSE 'HEALTHY'
                        END AS status
                    FROM financial.transactions
                    WHERE transaction_date >= date_trunc('month', now())
                    """
                ),
            ],
            gridPos=GridPos(h=4, w=4, x=8, y=1),
            thresholds=[
                Threshold("#299c46", 0, 1),  # HEALTHY
                Threshold("#f2c96d", 1, 2),  # MONITORING
                Threshold("#e0752d", 2, 3),  # WARNING
                Threshold("#c4162a", 3, 4),  # EXCEEDED
            ],
            reduceCalc="lastNotNull",
            colorMode="background",
            graphMode="none",
            textMode="value",
            valueMappings=[
                {"type": "value", "value": "HEALTHY", "text": "HEALTHY"},
                {"type": "value", "value": "MONITORING", "text": "MONITORING"},
                {"type": "value", "value": "WARNING: 80%+", "text": "WARNING: 80%+"},
                {"type": "value", "value": "BUDGET EXCEEDED", "text": "EXCEEDED"},
            ],
        ),
        SingleStat(
            title="Daily Avg Spend",
            dataSource=DATASOURCE_UID,
            targets=[
                SqlTarget(
                    rawSql="""
                    SELECT
                        ROUND(COALESCE(AVG(daily_total), 0), 2) AS avg_daily
                    FROM (
                        SELECT
                            transaction_date::date AS day,
                            SUM(amount) AS daily_total
                        FROM financial.transactions
                        WHERE transaction_date >= date_trunc('month', now())
                        GROUP BY transaction_date::date
                    ) daily
                    """
                ),
            ],
            gridPos=GridPos(h=4, w=4, x=12, y=1),
            thresholds="0:10,10:20,20:",
            unit="currencyUSD",
        ),
        SingleStat(
            title="Projected Month-End",
            dataSource=DATASOURCE_UID,
            targets=[
                SqlTarget(
                    rawSql="""
                    WITH daily_data AS (
                        SELECT
                            transaction_date::date AS day,
                            SUM(amount) AS daily_total
                        FROM financial.transactions
                        WHERE transaction_date >= date_trunc('month', now())
                        GROUP BY transaction_date::date
                    ),
                    stats AS (
                        SELECT
                            COUNT(*) AS days_elapsed,
                            COALESCE(SUM(daily_total), 0) AS total_so_far,
                            COALESCE(AVG(daily_total), 0) AS avg_daily
                        FROM daily_data
                    )
                    SELECT
                        ROUND(total_so_far + avg_daily * (
                            EXTRACT(DAY FROM (date_trunc('month', now()) + INTERVAL '1 month' - INTERVAL '1 day'))
                            - days_elapsed
                        ), 2) AS projected
                    FROM stats
                    """
                ),
            ],
            gridPos=GridPos(h=4, w=4, x=16, y=1),
            thresholds="0:20,20:28,28:30,30:",
            unit="currencyUSD",
        ),
        SingleStat(
            title="Transactions This Month",
            dataSource=DATASOURCE_UID,
            targets=[
                SqlTarget(
                    rawSql="""
                    SELECT COUNT(*) AS count
                    FROM financial.transactions
                    WHERE transaction_date >= date_trunc('month', now())
                    """
                ),
            ],
            gridPos=GridPos(h=4, w=4, x=20, y=1),
            unit="short",
        ),
        Row(title="Trends", gridPos=GridPos(h=1, w=24, x=0, y=9)),
        TimeSeries(
            title="Daily Spend (This Month)",
            dataSource=DATASOURCE_UID,
            targets=[
                SqlTarget(
                    rawSql="""
                    SELECT
                        transaction_date::date AS time,
                        SUM(amount) AS "Daily Spend"
                    FROM financial.transactions
                    WHERE transaction_date >= date_trunc('month', now())
                    GROUP BY transaction_date::date
                    ORDER BY time
                    """
                ),
                SqlTarget(
                    rawSql="""
                    SELECT
                        transaction_date::date AS time,
                        AVG(SUM(amount)) OVER (ORDER BY transaction_date::date ROWS BETWEEN 6 PRECEDING AND CURRENT ROW) AS "7-Day Avg"
                    FROM financial.transactions
                    WHERE transaction_date >= date_trunc('month', now())
                    GROUP BY transaction_date::date
                    ORDER BY time
                    """
                ),
            ],
            gridPos=GridPos(h=10, w=12, x=0, y=10),
            yAxes=[
                YAxis(format="currencyUSD", label="USD"),
            ],
            nullPointMode="connected",
            tooltip={"mode": "multi", "sort": "desc"},
        ),
        PieChart(
            title="Spending by Category",
            dataSource=DATASOURCE_UID,
            targets=[
                SqlTarget(
                    rawSql="""
                    SELECT
                        fc.category_name AS metric,
                        COALESCE(SUM(ft.amount), 0) AS value
                    FROM financial.transactions ft
                    JOIN financial.categories fc ON ft.category_id = fc.id
                    WHERE ft.transaction_date >= date_trunc('month', now())
                    GROUP BY fc.category_name
                    ORDER BY value DESC
                    """
                ),
            ],
            gridPos=GridPos(h=10, w=12, x=12, y=10),
            pieType="pie",
            legend={"show": True, "placement": "right", "values": ["value", "percent"]},
        ),
        Row(title="Budget and Costs", gridPos=GridPos(h=1, w=24, x=0, y=20)),
        BarGauge(
            title="Budget Utilization by Category",
            dataSource=DATASOURCE_UID,
            targets=[
                SqlTarget(
                    rawSql="""
                    SELECT
                        fc.category_name AS metric,
                        ROUND(
                            COALESCE(SUM(ft.amount), 0) / NULLIF(fb.monthly_limit, 0) * 100,
                            1
                        ) AS value
                    FROM financial.categories fc
                    LEFT JOIN financial.budgets fb ON fc.id = fb.category_id
                    LEFT JOIN financial.transactions ft
                        ON ft.category_id = fc.id
                        AND ft.transaction_date >= date_trunc('month', now())
                    WHERE fb.monthly_limit IS NOT NULL
                    GROUP BY fc.category_name, fb.monthly_limit
                    ORDER BY value DESC
                    """
                ),
            ],
            gridPos=GridPos(h=10, w=12, x=0, y=21),
            minValue=0,
            maxValue=120,
            thresholds=[
                Threshold("green", 0, 60),
                Threshold("yellow", 60, 80),
                Threshold("orange", 80, 90),
                Threshold("red", 90, 120),
            ],
            unit="percent",
            orientation="horizontal",
            displayMode="gradient",
        ),
        TimeSeries(
            title="Month-End Projection with Forecast",
            dataSource=DATASOURCE_UID,
            targets=[
                SqlTarget(
                    rawSql="""
                    SELECT
                        transaction_date::date AS time,
                        SUM(amount) OVER (ORDER BY transaction_date::date) AS "Cumulative Spend"
                    FROM financial.transactions
                    WHERE transaction_date >= date_trunc('month', now())
                    ORDER BY time
                    """
                ),
            ],
            gridPos=GridPos(h=10, w=12, x=12, y=21),
            yAxes=[
                YAxis(format="currencyUSD", label="Cumulative USD", min=0, max=35),
            ],
            thresholds=[
                Threshold("green", 0, 20),
                Threshold("yellow", 20, 28),
                Threshold("red", 28, 35),
            ],
            nullPointMode="connected",
            tooltip={"mode": "single"},
        ),
    ],
).auto_panel_ids()

# Generate JSON
if __name__ == "__main__":
    dashboard_json = dashboard.to_json_data()
    print(json.dumps(dashboard_json, indent=2, cls=DashboardEncoder))

#### Troubleshooting

- **Issue:** Dashboard shows "Datasource not found" error on all panels
  - **Solution:** Verify `DATASOURCE_UID` in `dashboards/financial.py` matches the actual TimescaleDB datasource UID in Grafana; check via `curl https://grafana.guinevere.ts.net/api/datasources` with admin auth

- **Issue:** `grafanalib` import fails with `ModuleNotFoundError: No module named 'grafanalib._gen'`
  - **Solution:** Install exact version: `pip install grafanalib==0.7.1`; the `_gen` module moved in 0.8.x — if using 0.8+, update imports: `from grafanalib.core import DashboardEncoder`

- **Issue:** TimescaleDB SQL queries timeout (>30s)
  - **Solution:** Add TimescaleDB chunk exclusion hints: `WHERE transaction_date >= now() - INTERVAL '30 days' AND transaction_date >= _timescaledb_internal.get_partition_for_key_val(...)`; ensure chunks are created for current month

- **Issue:** Dashboard not appearing after reload (provisioning not picking up file)
  - **Solution:** Check Grafana logs: `sudo journalctl -u grafana-server -f | grep provisioning`; verify provider YAML path, file permissions (`grafana:grafana`), and `updateIntervalSeconds` has elapsed

- **Issue:** `grafana_reader` user cannot access `financial` schema
  - **Solution:** Grant permissions: `GRANT USAGE ON SCHEMA financial TO grafana_reader; GRANT SELECT ON ALL TABLES IN SCHEMA financial TO grafana_reader;` and verify with `psql -U grafana_reader -c "SELECT COUNT(*) FROM financial.transactions;"`

- **Issue:** Gauge panel shows zero despite transactions existing
  - **Solution:** Verify `transaction_date >= date_trunc('month', now())` uses the correct timezone; add explicit `AT TIME ZONE 'Asia/Jakarta'` if server runs UTC: `WHERE transaction_date AT TIME ZONE 'Asia/Jakarta' >= date_trunc('month', now() AT TIME ZONE 'Asia/Jakarta')`

#### Notes

- The dashboard uses `editable=False` to prevent UI modifications from diverging from the grafanalib source of truth. All changes must go through the Python file and be regenerated.
- `allowUiUpdates: false` in the provider YAML reinforces immutable provisioning. If debugging is needed, temporarily set to `true`, make UI changes, then backport to grafanalib.
- The month-end projection SQL computes `total_so_far + avg_daily * days_remaining`. This is a naive linear projection — it does not account for end-of-month billing patterns.
- Grafana refresh is set to `5m` (5 minutes). For near-real-time cost tracking, the Redis bridge (P9-012) syncs every 5 minutes, so this interval matches the data pipeline.
- Dashboard UID (`financial-finops`) is hardcoded in both the Python definition and provider config. If the UID needs to change, update both locations.
- SQL queries use `date_trunc('month', now())` which respects the database server timezone. Ensure `timezone = 'Asia/Jakarta'` in `postgresql.conf` or use explicit casting.
- The `grafana_reader` role should have minimal permissions: `CONNECT` on database, `USAGE` on `financial` schema, `SELECT` on tables. Never grant `INSERT/UPDATE/DELETE`.
