## Out of Scope

The following were observed but are NOT part of this Tier 1 completeness audit:

1. **Section content quality** — Presence of sections is verified, not whether commands are correct, verification criteria are sufficient, or diagnostic output is realistic.
2. **File sizes and line counts** — Some files are significantly longer than others (P10-018: ~800 lines; P10-004: ~300 lines; P9-006: ~130 lines). This reflects the inherent complexity of each step, not a structural deficiency.
3. **Dependency graph correctness** — Whether the listed dependencies between steps are logically sound is not audited here.
4. **ADR reference accuracy** — Whether the cited ADR numbers actually address the claims made is not verified.
5. **Evidence path validity** — Whether the documented evidence paths (`docs/setup-evidence/P9|P10/STEP-...`) will actually exist at runtime is not checked.
6. **Tier 2/Tier 3 criteria** — This audit only covers Tier 1 (section presence). Deeper content validation (command correctness, security completeness, cross-reference accuracy) would require Tier 2/3 auditing.
7. **P10-018 sub-runbook structure** — The 11 embedded runbook sections within P10-018 are treated as one composite step file. Individual runbook Tier 1 compliance would require a separate audit.
8. **_assemble.py** — This Python script at the root of the directory is a build/assembly utility, not a step prompt file. Excluded from audit scope.

## Methodology Notes

- **Tooling**: Section presence was verified via `grep` pattern matching across all 34 files, cross-referenced against the full file read of P9-001 through P9-004 for spot-check verification.
- **Pattern accuracy**: The initial `**Goal**` search returned zero results due to the colon being inside the markdown bold markers (`**Goal:**`). Corrected to `\*\*Goal:\*\*` which returned 34/34 matches.
- **False positives checked**: P10-020 line 407 (`# Verification is read-only`) and P10-018 line 633 (`# Commands to confirm`) were verified as comments within rollback/troubleshooting sections, not separate section headings. These do not affect section presence counts.
- **Heading level consistency**: All 34 files at root use `####` level headings for sections. P10-018 sub-runbook sections use `##` which is structurally valid but stylistically inconsistent with the rest of the set.
